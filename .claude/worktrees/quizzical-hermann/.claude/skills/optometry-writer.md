# Optometry Writer（目鏡大叔文章撰寫 Skill）

## 啟動前必讀（每次都要執行）

在開始撰寫任何文章之前，請依序讀取以下參考檔案，讓你充分理解風格與限制：

1. **核心工作流**：讀取 `skills/optometry-writer/SKILL.md`
2. **排版規範**（H2/H3 符號、CSS 類別、文風）：讀取 `skills/optometry-writer/references/style-guide.md`
3. **法律紅線**（療效宣稱、醫療廣告規範）：讀取 `references/驗光師文案法律須知.md`
4. **已發布文章清單**（避免重複選題）：讀取 `skills/optometry-writer/data/blog-index.json`

## 撰寫流程

### Step 1：確認選題與角度
- 確認主題後，查閱 `blog-index.json` 確認尚未發布過類似文章
- 優先從「場景故事」或「生活痛點」切入，而非直接從專業術語開始

### Step 2：套用風格規範
- 嚴格遵守 `style-guide.md` 的排版規範（H2/H3 符號、▮ / ▸ 標題格式）
- 口吻：沉穩、專業、幽默、微帶台灣在地感（三峽/鶯歌）
- 禁用破折號「——」做解釋或語氣停頓，改用逗號、冒號或短句

### Step 3：法規自查
- 文章完成後，對照 `驗光師文案法律須知.md` 進行法規掃描
- 特別注意：療效宣稱、15歲以下學童配鏡法規提醒、醫療廣告紅線

### Step 4：輸出格式
- 主體：符合 style-guide 的 HTML 結構
- 結構化資料：附上 `Article` 與 `FAQ` 的 JSON-LD schema
- 同時提供純文字預覽版（方便校閱）

## 注意事項
- 文章長度：一般衛教文章 1,200–2,000 字；深度專欄可到 3,000 字
- 引用數據時務必標註來源（如 PMID 或研究名稱）
- 禁止使用 AI 感強烈的措辭（空洞結尾、過度列點、廢話開場）
