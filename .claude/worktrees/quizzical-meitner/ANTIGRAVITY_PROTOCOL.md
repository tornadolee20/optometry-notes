## 文章粗處理標準格式

大叔丟來文章時，輸出以下格式，追加到 `Inbox/待深處理.md`：

```markdown
## [文章標題]
- **來源**：[URL 或標題]
- **類型**：[論文 / 科普 / 行銷 / 其他]
- **核心主張**：[1–3 句，不超過 60 字]
- **關鍵數據**：[數字、樣本數、統計結果，無則填「無」]
- **初判連結**：[可能相關的知識卡片名稱，不確定填「不確定」]
- **建議模板**：[文獻卡 / 概念卡 / 行銷卡]
- **備注**：[特別注意點，無則填「無」]

> [待 Claude 深處理]
```

**重要**：不要加入自己的深度分析。骨架就好，Claude Code 來長肉。

---

## Inbox 整理標準格式

處理 `Inbox/手機收集箱.md` 時：

1. 分類每筆內容：`金句` / `想法` / `資料` / `待研究`
2. 加上標籤：`#金句` `#想法` `#資料` `#待研究`
3. 超過 3 筆「待研究」→ 加上 `[待 Claude 深處理]`
4. 不要自行移動到 Obsidian，Claude Code 負責最終寫入

---

## Handoff 標記規範

遇到以下任何情況，在對應內容末尾加上標記：

```
> [待 Claude 深處理] 原因：[一句話說明為什麼]
```

觸發條件：
- 需要深度文獻分析
- 需要建立知識卡片
- 需要判斷矛盾或連結
- 需要更新 MEMORY.md
- 任何你不確定的決策

## 記憶協定

- 可以讀 `MEMORY.md` 和 `memory/` 目錄
- **不可以寫入** `MEMORY.md`（Claude Code 擁有寫入權）
- 可以寫入 `memory/YYYY-MM-DD.md`（每日工作日誌）
- 寫入日誌時標註 `[Antigravity]` 前綴，以便區分

## 週檢任務（每週執行）

1. 掃描 `Inbox/待深處理.md`，確認佇列沒有積壓超過 7 天的項目
2. 若有積壓，推送提醒給大叔：「有 X 篇文章等待 Claude 深處理」
3. 掃描 `obsidian-vault/04-知識卡片/` 中 `maturity: 🌱` 超過 14 天的卡片
4. 推送提醒：「有 X 張知識卡片需要連結」
5. 不要自行處理，只負責提醒
