# 📖 眼頸連動三路徑模型（Eye-Neck Synergy）

> 蒸餾自三篇文獻：Domkin 2019 · Richter 2015 · Manna 2026（整合回顧）

---

## 🧠 概念定義

**眼頸連動**是指視覺系統的生理負荷，透過神經機制傳遞至頸肩肌群（主要是斜方肌），造成肌肉持續張力上升的現象。這不是姿勢問題，而是神經生理的**功能性耦合**。

目前有三條已驗證的觸發路徑，彼此**加成而非互斥**：

---

## 三條路徑

```
路徑一：調節-輻輳不一致（Vergence-Accommodation Incongruence）
┌─────────────────────────────────────────────┐
│ 雙眼看近 + 光學設計造成輻輳/調節需求錯位     │
│ → 眼肌衝突訊號 → 眼頸協同啟動               │
│ → 斜方肌共活化                               │
│                                              │
│ 來源：Zetterberg 2013 / Manna 2026 ref.56   │
│ 臨床情境：不適切近用眼鏡、螢幕+近用複雜任務 │
└─────────────────────────────────────────────┘

路徑二：睫狀肌負荷閾值（Ciliary Muscle Load）
┌─────────────────────────────────────────────┐
│ 近距工作（≤25 cm）→ 調節量超過臨界閾值      │
│ → 睫狀肌收縮力超閾 → 同側斜方肌共活化       │
│                                              │
│ 來源：Domkin 2019 / Manna 2026 ref.57       │
│ 臨床情境：手機過近、老花未矯正、近視度數不足 │
│ 閾值參考：調節負荷 >約 20–26% 最大調節力    │
└─────────────────────────────────────────────┘

路徑三：持續視覺注意力（Sustained Visual Attention）
┌─────────────────────────────────────────────┐
│ 高度視覺注意力持續 → 心智疲勞累積           │
│ → 大腦增加補償性神經輸出                     │
│ → 斜方肌活性隨時間上升（與調節量無關）       │
│                                              │
│ 來源：Richter 2015 / Manna 2026 ref.58/70   │
│ 臨床情境：任何吸引注意力的長時間螢幕工作     │
│ 關鍵：即使調節輕鬆（+3.5D 鏡片），也會發生  │
└─────────────────────────────────────────────┘
```

## 🎯 為什麼重要（臨床/衛教意義）

### 1. 解釋「換了椅子還是痠」的現象
患者改善坐姿後頸肩仍痠痛，往往是因為視覺路徑未被處理。驗光師有能力處理路徑一和路徑二，這是其他醫療人員做不到的。

### 2. 衛教邏輯重構
- 傳統說法：「姿勢不好 → 肩頸痠」（只談路徑外因）
- 精確說法：「**眼睛的神經活動 → 肩頸肌肉張力**，和姿勢疊加，才是真正的兩手互博」

### 3. 介入優先順序
| 優先 | 介入 | 針對路徑 |
|------|------|---------|
| 高 | 矯正視距（手機 >30 cm）、適當屈光矯正 | 路徑一、二 |
| 高 | 排程主動休息（走動 > 靜態閉眼）| 路徑三 |
| 中 | 視覺訓練（輻輳不足、調節不足）| 路徑一 |
| 中 | 螢幕距離與大小優化（49吋曲面 > 雙螢幕）| 路徑一、二 |
| 低 | 20-20-20（被動）| 路徑三（部分）|

## ⚖️ 實戰立場與應用

**驗光診間問診增加一句**：「你頸肩痠的時間，是連續工作多久後開始？」——用來區分路徑一/二（固定閾值觸發）vs. 路徑三（累積時間觸發）。

**衛教重點拆分**：
- 路徑一/二適合用「引爆點」比喻：調節負荷超過身體的承受線
- 路徑三適合用「帳戶提款」比喻：持續透支注意力，肩頸自動扣款

**寫文章時的立場**：
三條路徑都成立，不必非此即彼。對讀者說「你的肩頸痠，可能來自眼睛的三個地方」比說「是因為 A」更準確，也更能建立專業信任感。

**注意避免的誤讀**：
- ❌「近視度數越高，肩頸越痠」→ 調節量（effort）≠ 屈光度數
- ❌「只要看遠就沒事」→ 路徑三說明即使放鬆調節，持續注意力仍會造成上升
- ❌「是體質問題，沒辦法」→ 三條路徑都是可介入的生理機制
