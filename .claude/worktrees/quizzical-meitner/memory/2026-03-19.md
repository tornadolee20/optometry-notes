# 2026-03-19 目鏡大叔 AI 工作日誌：Prompt 庫解析與繁化工程

## 1. 探索與解析 `prompts.chat-main`
- **發現**：`AI之眼/prompts.chat-main` 是一個 Next.js 專案（開源的 prompts.chat 複製版），內含數千個社群貢獻的通用 Prompt。
- **行動**：不架設網站，直接從源碼 `PROMPTS.md` 提取所有指令，效益最大化。
- **成果**：寫腳本提取出 **1,487** 個 Prompt，並存入大腦 `AI之眼/prompts-index.json` 及 `prompts-titles.txt`。

## 2. 建立自動化 Prompt 技能庫
- 將 1,487 個 Prompt 透過關鍵字歸類成 13 個領域（包含 `content-writing`, `seo-marketing`, `medical-health`, `education-teaching` 等適合視光使用的領域），存入 `AI之眼/prompts-categorized.json`。
- 建立 `skills/prompts-library/SKILL.md` 讓 Antigravity 可在未來對話中自動查詢，並將國外的框架無縫轉為「目鏡大叔/視光」專用版本。

## 3. 全局繁體中文翻譯工程（進行中）
- **背景**：原 Prompt 庫全為英文，為方便日後隨時調用，啟用全量 GPT 翻譯。
- **實作細節**：
  - 腳本：`scripts/translate_prompts.js`
  - 使用模型：`gpt-4o-mini`，支援防錯與斷點續傳。
  - **進度追蹤**：目前正在背景執行中（共分 149 個 Batch，紀錄存於 `AI之眼/translate-progress.json`）。
  - 若意外中斷，只需重新執行 `node scripts/translate_prompts.js` 即可自動從上次斷點接續。
- **最終產出預期**：完成後將生成繁體中文完整索引 `AI之眼/prompts-index-zh-tw.json`。
