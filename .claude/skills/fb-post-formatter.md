# FB Post Formatter（目鏡大叔臉書排版 Skill）

## 核心呼吸規則（所有模式通用）

一句話由一個或多個「，」加上「。」組成。

- **句內**：每個逗號子句可獨立一行
- **句後**：句號後空一行
- **段落間**：空兩行
- **每行上限**：約 15 字（手機一行為準，看感覺斷，不死守數字）
- **長文沒問題**：不需刻意縮短，完整表達優先

---

## 五種排版模式

### 模式一：段落標題型
**適用**：衛教長文、政策說明、知識輸出完整版
**特徵**：`▌小標` 分區導覽，結構清晰，適合有多個知識點的文章

```
【標題句，15字以內】

第一段情境或引言句。

第二句鋪陳。


▌小標一

說明句一。

說明句二，
延伸子句。


▌小標二

說明句。


▌小標三

說明句。


👇 結尾行動句或問句
```

---

### 模式二：故事敘事型
**適用**：診間案例、真實對話、感性分享
**特徵**：無小標，純口語流，場景開場，結尾才點主題

```
場景開場句。

對話或描述，
細節鋪陳。


轉折或發現。

關鍵事實句。


結論點題句。

行動邀請句。
```

---

### 模式三：數字清單型
**適用**：懶人包、條列重點、讓人存圖分享
**特徵**：數字符號 `①②③`，每點有子說明，結構清晰

```
開場設定預期的句子。


① 項目名稱

說明句，
補充子句。


② 項目名稱

說明句，
補充子句。


③ 項目名稱

說明句。


結尾收攏句。

行動句。

👇 CTA
```

---

### 模式四：問句帶入型
**適用**：目標族群明確、引發共鳴、讓人覺得「在說我」
**特徵**：連續問句開場，讀者對號入座，中段給答案

```
對目標族群的問句？


延伸問句一？

延伸問句二？

延伸問句三？


這些，不是正常現象。

是某件事在發出警告。


中段說明句。

核心事實句。


結論行動句，
讓讀者下一步清楚。
```

---

### 模式五：金句衝擊型
**適用**：衝分享率、觀念翻轉、短而有力的爆文
**特徵**：反常識開場，極短句堆疊，情緒衝擊，不過度解釋

```
反常識開場句。

補充說明一句。


衝擊點一。

衝擊點二。

衝擊點三。


轉折收束句。


結論行動句。
```

---

## 使用流程

1. **接收輸入**：URL 或長文貼入
2. **判斷模式**：
   - 使用者指定模式 → 直接用
   - 未指定 → 根據內容性質判斷（見下表）
3. **轉換輸出**：套用呼吸規則 + 對應模式骨架
4. **儲存**（若為部落格文章）：存至 `content-planning/{文章名稱}-FB版.txt`

### 模式判斷邏輯

| 內容特徵 | 建議模式 |
|---------|---------|
| 有多個知識點、政策說明 | 模式一 |
| 有真實案例、診間故事 | 模式二 |
| 條列式重點、懶人包 | 模式三 |
| 目標族群明確（長輩/家長/學生） | 模式四 |
| 想衝分享、觀念翻轉 | 模式五 |

---

## 禁忌

- 禁用 Markdown 符號（**粗體**、`---`、`>`）
- 禁用破折號「——」
- 禁用空洞套話（「希望對你有幫助」「以上就是今天的分享」）
- 禁用超過 3 行不換行的文字牆
- emoji 全篇不超過 5 個，只放結尾或標題

## 與 optometry-writer 整合

若不確定，預設用**模式一（段落標題型）**輸出。
