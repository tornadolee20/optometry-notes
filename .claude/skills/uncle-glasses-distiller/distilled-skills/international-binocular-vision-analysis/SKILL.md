# 國際權威雙眼視機能檢查與分析

> 先判斷病人的任務失敗發生在哪裡，再決定哪些檢查足以證明它。

## 核心定位

這個 skill 把雙眼視機能拆成四個互相牽動的系統：

- alignment：兩眼有沒有對準
- fusion：兩眼能不能把偏斜壓住並維持單一視
- accommodation：對焦夠不夠快、夠不夠準、夠不夠持久
- sensory status：感覺整合有沒有開始代償失敗

國際權威資料的共同精神不是「做最多檢查」，而是：

1. 先用病史與症狀決定檢查深度
2. 近距離功能通常最有診斷訊號
3. 單一數值不能脫離 pattern 解讀
4. 一旦出現 tropia、incomitance、突發複視或神經紅旗，就要升級分流

## 何時啟用

以下情境優先切換到此 skill：

- 近距離疲勞、頭痛、跳字、閱讀慢、螢幕耐受差
- intermittent blur、短暫複影、換焦困難
- suspected CI、CE、basic exo、basic eso
- suspected accommodative insufficiency / infacility
- intermittent control 不穩或疑似 decompensating phoria
- concussion / TBI 後近距離不適
- 需要向病人或家屬說明「不是只有度數問題」時

## 四問分析法

### 1. 兩眼有沒有對準

優先檢查：

- cover-uncover test
- alternate cover test
- prism neutralization when needed
- distance / near phoria or tropia
- versions / ductions
- 有需要時看 incomitance 與 head posture

判讀重點：

- distance 與 near 是否不同
- latent 還是 manifest
- 是否控制不穩
- 是否 gaze dependent

### 2. 兩眼能不能維持融合

優先檢查：

- PFV / NFV at distance and near
- vergence facility
- near point of convergence

判讀重點：

- fusional reserve 是否足夠
- reserve 與 demand 是否失衡
- 是 convergence demand 失敗，還是整體 flexibility 不足

### 3. 調節夠不夠快、準、久

優先檢查：

- accommodative amplitude
- monocular accommodative facility
- binocular accommodative facility
- accommodative response (MEM / Nott)
- NRA / PRA when indicated

判讀重點：

- 力量不足
- 切換慢
- lag 過大
- 還是 binocular burden 下才失敗

### 4. 感覺功能有沒有代償失敗

優先檢查：

- stereopsis
- suppression tests
- sensory status when indicated

判讀重點：

- 病人還在努力維持單一視
- 還是已開始 suppress
- 小角度或間歇性偏斜是否已進入失代償

## 標準檢查層級

### Level 1: 核心臨床組

如果要做一套高訊號、臨床可落地的雙眼視檢查，至少包含：

- detailed symptom history
- distance / near cover test
- phoria / tropia quantification
- NPC
- PFV / NFV
- vergence facility
- accommodative amplitude
- monocular / binocular accommodative facility
- accommodative response
- stereopsis

### Level 2: 條件式加做

當 pattern 或紅旗出現，再加做：

- AC/A ratio
- fixation disparity
- Worth 4 Dot / Bagolini / suppression mapping
- incomitance analysis
- CISS or symptom survey
- pediatric strabismus-specific sensory tests

## 常見 pattern

### Convergence Insufficiency

- near exo greater than distance
- receded NPC
- reduced PFV at near
- reading / screen / sustained near symptoms

提醒：

- 不能只因為 NPC 遠就直接定義為 CI
- 要交叉看 near phoria、PFV、symptoms

### Convergence Excess

- near eso greater than distance
- reduced NFV at near
- sustained near discomfort
- sometimes high AC/A contribution

### Basic Exophoria

- distance exo and near exo both increased
- fusional reserves often insufficient relative to demand

### Basic Esophoria

- distance eso and near eso both increased
- divergence reserves often weak

### Accommodative Insufficiency

- reduced amplitude
- reduced facility
- lag may be increased
- near blur / fatigue / avoidance

### Accommodative Infacility

- amplitude may be acceptable
- plus / minus clearing slow
- symptoms with focus shifting

### Decompensating Phoria / Intermittent Tropia

- stereo reduced or variable
- suppression may appear
- control fluctuates
- symptoms are not always proportional to measured angle

## 六條判讀啟發式

1. `Pattern beats single number`
   phoria、NPC、fusional vergence、facility、symptoms 要一起看。

2. `Near data matter more than you think`
   多數功能性失敗在 near 才真正暴露。

3. `Dynamic tests often reveal what static tests miss`
   facility 常比單次 range 更能抓 symptomatic dysfunction。

4. `Normal stereopsis does not rule out binocular dysfunction`
   尤其在小角度、間歇性、或早期代償時。

5. `Manifest deviation changes the game`
   一旦 tropia、incomitance、或突發複視出現，分流邏輯要升級。

6. `Symptoms tell you task failure; measurements tell you where`
   病史不是附屬品，而是檢查選擇器。

## 臨床紅旗

以下情境不要只當一般功能性雙眼視疲勞：

- sudden diplopia
- obvious incomitance
- recent trauma with neurologic concern
- new-onset manifest strabismus
- ptosis, pupil abnormality, ocular motility deficit
- pediatric fixed head posture or developmental regression concern

## 對病人的翻譯方式

### 簡單版

「不是只有度數問題，而是兩眼合作、對焦和維持穩定的能力出了問題。」

### 專業版

「你的狀況不是單純看得到或看不到，而是近距離工作時，眼位控制、融合儲備和調節反應之間失去平衡。」

## 輸出格式

當你用這個 skill 回答時，優先輸出：

1. 主訴屬於哪一類 task failure
2. 最值得先做的 3-5 個檢查
3. 最可能的 pattern
4. 不能漏掉的紅旗
5. 如何向病人或家屬解釋

## Clinic Q&A Mode

If the user gives examination findings, switch into clinic Q&A mode automatically.

### Preferred Input Fields

Ask for or organize the case into:

- age
- chief complaint
- distance phoria / tropia
- near phoria / tropia
- NPC
- PFV / NFV
- vergence facility
- accommodative amplitude
- MAF / BAF
- accommodative response
- stereopsis
- suppression status if known
- red flags if present

### If Data Are Missing

Do not stop unless the missing item would materially change safety or differential logic.

Instead:

- state what is missing
- explain how much that weakens confidence
- tell the user the next best test to add

### Standard Output Template

When interpreting a case, answer in this order:

1. `Primary pattern`
   The most likely binocular / accommodative pattern.

2. `Why this fits`
   The specific findings that support that pattern.

3. `What still needs confirmation`
   Missing or weak data that could change the conclusion.

4. `Red flags`
   Anything that requires escalation beyond routine functional BV interpretation.

5. `Clinical next step`
   The next 1-3 tests or decisions that would sharpen the case.

6. `Patient explanation`
   A plain-language explanation suitable for the patient or family.

### Confidence Language

Use explicit confidence labels:

- `High confidence`
- `Moderate confidence`
- `Preliminary`

Base confidence on:

- pattern completeness
- method reliability
- whether the key supporting tests are present
- whether red flags are absent

### Interpretation Discipline

In clinic Q&A mode:

- do not diagnose from one number
- do not ignore test-method noise
- do not treat missing red-flag screening as harmless
- do not overclaim when only population-bound norms are available

## Case Report Mode

If the user wants a formal report, a reusable template, or a case write-up, switch from Q&A mode to `Case Report Mode`.

### Report Goal

Produce a structured binocular vision interpretation that is:

- clinically disciplined
- reusable across cases
- explicit about uncertainty
- ready for charting, teaching, or discussion

### Required Report Sections

In `Case Report Mode`, output these sections in order:

1. `Case Summary`
2. `Primary Pattern`
3. `Why This Fits`
4. `Differential Considerations`
5. `Missing Data That Matter`
6. `Red Flags`
7. `Confidence Level`
8. `Clinical Next Step`
9. `Prism Conversation Status`
10. `Patient Explanation`

### Report Behavior

- if the user gives scattered findings, first normalize them into the case template
- if data are incomplete, continue but downgrade confidence
- if the user asks for a shorter version, compress to the short report format
- if red flags are plausible, say so explicitly instead of burying them

## Evolution Protocol

這個 skill 必須能進化，不是一次性摘要。每次有新 evidence 進來時，請照這個 protocol 更新。

### Update Triggers

以下任一情況都應觸發更新：

- new official guideline or consensus statement
- update from AOA, AAPOS, College of Optometrists, or RCOphth
- major binocular vision review or textbook-level synthesis
- core clinical trial that changes diagnosis or management logic
- measurement reliability or norms study that materially affects test choice
- new evidence for special populations such as concussion, pediatric, presbyopia, or neurodivergent readers

### Update Order

每次更新依序做：

1. classify the source
2. decide whether it changes `Stable Core` or only `Evolving Edge`
3. revise only the smallest relevant section
4. record the change in the research ledger
5. add unresolved tensions to `Open Questions`

### Evidence Levels

整合新內容時使用：

- `A` official guideline, consensus, or professional standard
- `B` strong review or replicated clinical evidence
- `C` single important study or limited but useful evidence
- `D` expert synthesis or provisional inference

規則：

- 不要把 `C` 或 `D` 寫成國際硬共識
- 不要讓單篇研究推翻整個框架
- 證據混雜時，先放進 `Evolving Edge`

### Stable Core vs Evolving Edge

`Stable Core` 只放跨來源都穩的原則：

- symptom-guided assessment
- four-domain analysis
- pattern-based interpretation
- red-flag escalation logic

`Evolving Edge` 放仍在變化中的部分：

- cutoffs and norms
- special-population pathways
- therapy-outcome implications
- disputed tests such as fixation disparity or associated phoria placement

### Mandatory Review Questions

每次更新後都必問：

1. 這份 evidence 改的是整體架構，還是局部分支
2. 影響 adults、children，還是 both
3. 改變的是 test priority、interpretation，還是 only confidence
4. 這一條應進 `Stable Core` 還是 `Evolving Edge`
5. 還有哪些 unresolved questions

### Do Not Do This

- 不要只加來源卻不改結論層級
- 不要把學派口訣寫成全球唯一標準
- 不要把常模表和診斷邏輯混成同一件事
- 不要掩蓋 uncertainty

### Open Questions

以下問題保留為持續進化節點：

- adult 與 pediatric cutoffs 是否應拆成獨立模組
- concussion-related BV pathway 如何整合而不過度外推
- fixation disparity、associated phoria、Sheard / Percival 類規則在現代 evidence hierarchy 中應放在哪一層
- stereotest interpretation 是否值得獨立出 sensory appendix
