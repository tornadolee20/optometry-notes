## 老花動作邏輯更新

今天針對「老花」影片提示詞，補強了比單純 `瞇眼` 更真實的動作邏輯。之後只要是老花題材，應優先從「補償動作」出發，而不是直接寫症狀。

### 老花核心原則

- 老花的核心動作不是先瞇眼，是先把近物拿遠。
- 老花的真實感很多時候不在「看不清」，而在「怎麼補救」。
- 很多視力片真正的戲，不是看不清，是假裝看清楚。

### 老花常見真實補償動作

- 手臂微微往前伸，把手機、菜單、帳單、標籤拿遠一點看。
- 頭微微往後，想找一個比較看得清楚的距離。
- 眼神用力對焦，停一拍，之後才輕微瞇眼。
- 若戴的是看遠眼鏡，可能會先把眼鏡拿下來。
- 或把眼鏡往上推，直接掛到頭頂。
- 或頭低下來，眼睛從鏡框上方去看近物。
- 看完後常裝作若無其事，不主動說自己看不清楚。

### 老花的現代補償動作

- 先直接看近物，發現不夠清楚。
- 停一下，不想問人。
- 拿出手機打開相機。
- 對準菜單、標籤、藥袋、收據或小字。
- 用手指把畫面放大後再看。
- 看完後裝作沒事，像只是順手操作。

### 老花提示詞的優先動作順序

1. 先看近物。
2. 發現不夠清楚。
3. 調整眼鏡或調整觀看距離。
4. 拿遠 / 拿下眼鏡 / 掛頭頂 / 低頭越過鏡框看 / 用手機相機放大。
5. 停一秒重新對焦。
6. 最後才補一點輕微瞇眼或尷尬感。

### 之後寫老花提示詞時要避免

- 一上來就誇張大力瞇眼。
- 老花卻把東西拿更近。
- 沒有補償動作，只有單一表情。
- 演得太可憐，失去「撐著」的真實感。

### 後續默認規則

之後使用者只要丟出老花相關的一句話，優先考慮以下元素：

- 台灣生活化場景
- 老花補償動作
- 逞強感 / 若無其事感
- 短旁白
- 配音直接寫進提示詞
- 配樂方向一起補齊
