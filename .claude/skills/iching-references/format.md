# 易經解讀輸出格式規範

## 通用原則

- 全程用白話，禁止古文術語
- 每句話都要能直接行動
- 語氣：像聰明的朋友在聊天，不是算命師在唸咒
- 長度：夠用就好，不要為了「看起來專業」而堆字

---

## 情境一：每日易經路況（獨立使用）

```
---
📅 [日期] 易經路況

🎴 今日卦象：[卦號] [卦名]
[卦的符號或簡短象徵描述]

**現在的局面**
[1-2句，描述今天整體的能量狀態]

**核心提示**
[1句，最重要的一件事]

**建議行動**
- [具體行動1]
- [具體行動2]

**要注意**
[1句警示]

**動爻訊號**（第[N]爻動）
[1-2句，這個位置代表什麼在變化]

**走向預測**（變卦：[卦名]）
[1-2句，事情往哪個方向發展]

---
⚡ 今天的能量很適合：[3個關鍵詞]
🚫 今天要避免：[1-2件事]
```

---

## 情境一（整合版）：八字天氣 + 易經路況

在八字日報之後，加入以下區塊：

```
---
🔮 **今日易經路況加持**

起卦：[上卦][下卦] → **第[N]卦 [卦名]**（第[N]爻動）

[2-3句整合解讀，結合八字天氣的提示]

📌 八字＋易經雙重信號：
- 兩者一致 → [建議]
- 兩者相反 → [建議]

變卦走向：→ **[變卦卦名]**：[1句走向描述]
```

## 情境二：即時問卦

```
---
🎴 為你卜的這一卦

**問題**：[用戶的問題]
**起卦時間**：[日期時間]
**本卦**：第[N]卦 [卦名]（[上卦]上[下卦]下）
**動爻**：第[N]爻
**變卦**：第[N]卦 [卦名]

---

**現在這個局面**
[2-3句，用卦義回應用戶的具體問題]

**這件事的關鍵點**
[1-2句，動爻在說什麼]

**建議怎麼做**
1. [具體行動]
2. [具體行動]
3. [具體行動]

**要注意**
[1-2句警示]

**事情的走向**
[1-2句，從本卦到變卦，趨勢是什麼]

---
💬 [1句鼓勵性結語]

*易經是智慧參考，不是預言。人的選擇可以改變結果。*
```

```
---
🎴 深度卦析

**問題**：[用戶的決策問題]

━━━━━━━━━━━━
📌 本卦：第[N]卦 [卦名]
━━━━━━━━━━━━

**現況解讀**
[3-4句，深入描述當前處境]

**有利的方向**
[2-3點]

**潛在風險**
[2-3點]

━━━━━━━━━━━━
⚡ 動爻：第[N]爻（[代表層面]）
━━━━━━━━━━━━

[2-3句，這個動爻在這個問題上的具體意義]

━━━━━━━━━━━━
🔄 變卦：第[N]卦 [卦名]
━━━━━━━━━━━━

[2-3句，如果照著本卦的建議走，事情會演變成什麼]

━━━━━━━━━━━━
🎯 最終建議

💬 [1句有力的結語]

*命理分析僅供參考，重大決策請結合實際情況判斷。*
```

## 感情類問題補充格式

在「現況解讀」後加入：

```
**對方能量推測**
[根據卦象推測對方目前的狀態，用「可能」「感覺上」等措辭，不要斷言]
```

---

## 商業決策補充格式

在「最終建議」後加入：

```
**時間節點**
- 最快可動：[條件]
- 最佳視窗：[大約時間範圍]
- 要避開：[不利時機]
```

---

## 語氣禁止清單

❌ 不用這些詞：
- 「吉」「凶」「大吉」「大凶」（改用具體描述）
- 「此卦主...」「卦曰...」（古文口吻）
- 「命中注定」「無法改變」（宿命論）
- 「保證」「一定會」（斷言）
- 「建議您」「請您」（太客套）

✅ 改用這些：
- 「現在的狀態是...」
- 「這個時機適合...」
- 「有個地方要小心...」
- 「如果你...，結果可能往...走」
