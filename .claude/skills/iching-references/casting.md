# 梅花易數起卦法

## 核心原理

梅花易數由宋代邵雍所創，以數起卦，「萬物皆有數，以數推理」。
最適合用時間自動起卦，不需要銅錢，適合AI產品化應用。

---

## 時間起卦步驟

### 所需數字

| 數字 | 取法 |
|------|------|
| 年數 | 西元年尾兩碼（2026 → 26） |
| 月數 | 當月月份（4月 → 4） |
| 日數 | 當日日期（21日 → 21） |
| 時數 | 時辰地支序號（見下表） |

### 時辰對應數字

| 時辰 | 時間 | 數字 |
|------|------|------|
| 子時 | 23:00-01:00 | 1 |

| 巳時 | 09:00-11:00 | 6 |

## 計算公式

### 上卦（外卦）
```
上卦數 = (年數 + 月數 + 日數) mod 8
餘數為0時，取8
```

### 下卦（內卦）
```
下卦數 = (年數 + 月數 + 日數 + 時數) mod 8
餘數為0時，取8
```

### 動爻
```
動爻數 = (年數 + 月數 + 日數 + 時數) mod 6
餘數為0時，取6
```

## 動爻解讀

動爻代表卦中「正在變化」的那一爻。

| 動爻位置 | 代表層面 |
|---------|---------|
| 初爻（第1爻）| 事情的起點、基礎、下層 |
| 二爻（第2爻）| 內部情況、近期發展 |
| 三爻（第3爻）| 轉折點、內外交界 |
| 四爻（第4爻）| 外部環境、他人影響 |
| 五爻（第5爻）| 核心關鍵、主事者 |
| 上爻（第6爻）| 結果、極端、過渡 |

## 變卦

動爻的陰陽變化後，形成新的卦象（變卦）。
變卦代表事情的「走向」和「結果」。

解讀順序：本卦（現在狀態）→ 動爻（關鍵點）→ 變卦（走向）

---

## 範例計算

**例：2026年4月21日 未時（14:00）**

- 年數：26
- 月數：4
- 日數：21
- 時數：8（未時）

上卦：(26+4+21) mod 8 = 51 mod 8 = 3 → **離**
下卦：(26+4+21+8) mod 8 = 59 mod 8 = 3 → **離**
動爻：(26+4+21+8) mod 6 = 59 mod 6 = 5 → **第五爻動**

查表：上卦離(3) × 下卦離(3) = **第30卦 離為火**

解讀：雙火相疊，今日能量燃旺，第五爻動代表核心關鍵在主事者本身。
