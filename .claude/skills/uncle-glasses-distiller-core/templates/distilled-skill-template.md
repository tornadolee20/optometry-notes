# distilled-skill-template.md

Updated: 2026-04-15

## Purpose

This template provides the minimum stable structure for a distilled skill.

Use it after the target has already passed the decision and review stages.

## Template

```md
---
name: [skill-name]
description: |
  [one-paragraph operational description of what this skill helps do,
  when it should be used, and why it improves over generic reasoning]
---

# [Skill Title]

## Purpose

[What this skill is for.]

## Use This Skill When

- [trigger pattern 1]
- [trigger pattern 2]
- [trigger pattern 3]

## Do Not Use This Skill When

- [boundary 1]
- [boundary 2]
- [boundary 3]

## Core Responsibility

[What this skill owns.]

## Operating Model

[Core concepts, logic, or steps.]

## Support References

- [reference 1]
- [reference 2]

## Output Shape

```md
## [Output Name]
- [field]
- [field]
```

## Bottom Line

[One short paragraph that states what this skill should reliably help the system do.]
```

## Bottom Line

The template should stabilize quality, not force every skill to sound identical.
