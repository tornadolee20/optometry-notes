# Paper Triage（文獻快篩 Skill）

## 執行步驟

收到論文資訊後，10 秒內完成三維評分：

### 評分表

| 維度 | 你的評分 | 說明 |
|------|---------|------|
| 證據位階 | ★☆☆ ~ ★★★ | RCT/指引(3) / 世代研究(2) / 個案廠商(1) |
| 臨床牽引力 | ★☆☆ ~ ★★★ | 破壞做法(3) / 機制解釋(2) / 象牙塔(1) |
| 商業轉換力 | ★☆☆ ~ ★★★ | 痛點密碼(3) / 可圖卡化(2) / 枯燥(1) |
| **總分** | **/9** | |

### 分流決策

- **< 4 分**：輸出兩句 TL;DR，詢問是否略過歸檔
- **≥ 4 分**：放行，建議執行 `/uncle-glasses:ai-eye`

## 輸出格式

```
📊 快篩結果：[論文標題]
- 證據位階：★★☆（世代追蹤）
- 臨床牽引力：★★★（破壞現有做法）
- 商業轉換力：★★☆（可圖卡化）
- 總分：7/9 ✅ 放行

建議：值得完整拆解，主題與「近視控制機制」高度相關。
執行 /uncle-glasses:ai-eye 繼續？
```
