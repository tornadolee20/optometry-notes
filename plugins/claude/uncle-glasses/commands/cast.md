# /uncle-glasses:cast

啟動「C.A.S.T. 內容永動機」，以目鏡大叔人設撰寫部落格草稿。

## 用法

```
/uncle-glasses:cast <主題> [真人實例]
/uncle-glasses:cast 散光與夜間駕駛 上週有位客人說開車看燈都有光暈
/uncle-glasses:cast 兒童近視控制
```

## 輸出結構

- **C** Connect — 痛點切入（5 秒鉤子）
- **A** Amplify — 情感對焦（不恐嚇）
- **S** Solve — FABE 專業解方（白話文）
- **T** Transform — 務實收尾（帶出驗光所行動）

輸出包含：
- Markdown 正文草稿（1,500–2,000 字）
- 3 組備選標題 + 終極破表標題
- AI 配圖英文 Prompt
