# Work Queue

This folder tracks what should continue across tools and devices.

## Folders

- `inbox/`: captured ideas or unclear tasks.
- `active/`: work currently owned by a device or AI.
- `blocked/`: tasks waiting on access, decision, credentials, or owner review.
- `completed/`: finished tasks with enough evidence to avoid rework.

## Task Rules

- Every active task must name a current owner.
- Every task should include the current device.
- A task moves only when its file is updated with evidence.
- Do not use this folder as a dumping ground for raw AI transcripts.
