# Video QA Template

Case ID:

## A. Hook

- [ ] 0–2 秒內知道畫面重點
- [ ] 第一幕不是 generic title card
- [ ] Hook 與影片真正內容一致
- [ ] 不靠誇張承諾騙點擊

## B. Clarity

- [ ] 每幕只有一個主要資訊任務
- [ ] 不需要暫停才能理解核心
- [ ] 專有名詞已被視覺化或白話化
- [ ] 重要資訊有 HOLD_READ

## C. Pacing

- [ ] 沒有無目的空拍
- [ ] 沒有每 0.5 秒硬切造成疲勞
- [ ] 轉折 timing 清楚
- [ ] payoff 不被提早暴雷

## D. Motion

- [ ] 每個 motion 都有 purpose
- [ ] 沒有「因為能動所以動」
- [ ] camera motion 不搶文字閱讀
- [ ] transition style 數量受控
- [ ] easing 一致

## E. Visual

- [ ] 手機可讀
- [ ] safe area 正確
- [ ] 字體與品牌一致
- [ ] 元件風格一致
- [ ] 沒有廉價預設漸層 / generic AI UI

## F. Audio

- [ ] VO 與畫面 cue 對齊
- [ ] 重要語句有視覺呼應
- [ ] 音效沒有蓋掉語音
- [ ] pause 有被尊重

## G. Ending

- [ ] 最後 1–2 秒完成主要任務
- [ ] CTA 若存在，與內容自然連接
- [ ] 沒有突然結束或硬塞 CTA

## H. Technical

- [ ] duration 正確
- [ ] fps 正確
- [ ] aspect ratio 正確
- [ ] 無 asset missing
- [ ] 無文字裁切
- [ ] 無黑 frame / frozen frame
- [ ] audio 無 clipping

## Decision

- QA status: PASS / CONDITIONAL / FAIL
- Blocking defects:
- Non-blocking improvements:
- Approved version:
