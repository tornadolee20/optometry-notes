# Case 001 — 紅蘿蔔真的顧眼睛？

CASE_ID: CARROT-NIGHT-VISION-001
Status: PRE-PRODUCTION
Skill: Uncle Motion OS v0.2

## One Job

讓觀眾從「紅蘿蔔到底有沒有顧眼睛？」的真假二選一，
走到：

> 有生理基礎，不代表吃得越多，視力就越強。

## Memorable Punchline

> 紅蘿蔔不是夜視鏡。

## Audience

一般大眾；對「紅蘿蔔顧眼睛」有既有印象，但未必理解 Vitamin A、暗視覺與二戰宣傳脈絡。

## Desired Response

看完後產生：
「原來這句從小聽到大的話，背後同時有戰爭、雷達、營養學，而且不是全錯也不是超能力。」

## Story Architecture

MYSTERY
-> INFORMATION GAP
-> FALSE ANSWER
-> BELIEF
-> RADAR REVEAL
-> HISTORICAL CORRECTION
-> FALSE ENDING
-> SECOND HOOK
-> EXPERIENCE FIRST
-> SCIENCE
-> COMEDY TWIST
-> CALLBACK

## Six Hero Beats

1. 英軍為什麼能在夜間找到德軍？
2. 紅蘿蔔 Hero Reveal
3. Radar Hero Reveal
4. False Ending -> 「欸，等一下」
5. 第三根紅蘿蔔 -> Night Vision Comedy
6. German Bomber Callback

## Primary Constraint

不能拍成：
- 歷史課
- 衛教 PPT
- AI 圖片輪播
- 每句旁白配一張圖
- 每鏡都 AI 生成

## Target Duration

Working target: 105–115 sec.

Original script timeline extends to ~128 sec; compression should come mainly from explanatory bridges, not from hero reveals or pauses.

## Success Signal

Production-stage hypothesis:
- 0–10s clear mystery
- no major explanatory valley before first reveal
- second hook feels like a new video starting
- science section retains narrative momentum
- final callback resolves opening mystery as a joke

Real success must be validated from post-release retention / watch-time data.
