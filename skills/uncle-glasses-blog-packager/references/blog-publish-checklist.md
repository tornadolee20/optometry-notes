# blog-publish-checklist.md

Updated: 2026-04-15

## Purpose

This reference defines the minimum release-readiness check for blog packaging.

## Publish Checklist

- title is stable enough to publish
- article argument is clear
- HTML structure is readable
- canonical is present or explicitly flagged as provisional
- schema choice is justified
- no obvious AI-tone leakage remains in key sections
- no obviously broken section hierarchy remains
- any unresolved issue is surfaced before publishing

## Result Labels

Use:

- `pass`
- `revise`

### Use `pass` when

- the article is structurally and packaging-wise ready to publish

### Use `revise` when

- there are unresolved packaging issues
- canonical or schema decisions are not yet trustworthy
- the article still shows obvious structural or tonal weaknesses

## Output Guidance

The packager should report:

- final label
- key reasons
- exact issues that still need revision
