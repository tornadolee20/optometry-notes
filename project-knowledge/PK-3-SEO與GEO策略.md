# SEO 與 GEO 策略（行動速查版）

> GEO = 讓 ChatGPT、Gemini、Perplexity 在回答問題時主動說出你的名字。

---

## 核心概念

- **SEO**：讓 Google 把你的文章排到第一頁
- **GEO**：讓 AI 回答問題時直接引用你的內容，並附上你的名字

兩者都要做，但 GEO 是 2025–2026 年最重要的新戰場。

---

## 每篇文章必須有的三種 Schema

1. **Article Schema** — 告訴 AI：作者是誰、文章主題是什麼
2. **FAQPage Schema** — AI 最愛引用的格式，直接被摘要使用
3. **BreadcrumbList Schema** — 幫助 AI 理解網站架構

（Schema 的程式碼由 Claude Code 桌機版生成，這裡只需討論內容）

---

## E-E-A-T 四層權威（缺一不可）

| 層次 | 如何實作 |
|------|---------|
| **Experience（經驗）** | 每篇必含三峽店內的真實觀察/案例，有細節有畫面 |
| **Expertise（專業）** | 引用國際論文，標注 PMID 編號 |
| **Authoritativeness（權威）** | 作者介紹含三大頭銜：驗光師 + 元培講師 + 學會理事 |
| **Trustworthiness（信任）** | 加入免責聲明：「本文僅供衛教參考，不能取代專業面診」 |

---

## 寫作格式（讓 AI 更容易摘要你的內容）

### H2 段落開頭必有粗體總結句
每個 H2 的第一句，先給一句粗體總結，例如：
> **視力 1.0 只代表看遠的靜態解析度正常，但閱讀所需的調節穩定度是完全不同的事。**

### FAQ 的寫法
- 問題：完整、口語、貼近家長真實用語
- 回答：「簡短但完整」——50–150 字最佳

### 內連方式
- 每篇自然帶入 1–2 篇舊文連結
- 用對話式嵌入：「就像大叔之前提過的...」
- **禁止**「延伸閱讀：」這種硬梆梆的格式

## 在地 SEO 關鍵字（每篇帶入 2–3 次）

- 三峽驗光師、三峽配眼鏡
- 北大特區配眼鏡推薦
- 鶯歌驗光所、樹林兒童近視控制
- 土城多焦鏡片


## 發布前 GEO 檢查清單

- [ ] Article Schema 含完整作者（三大頭銜 + knowsAbout）
- [ ] FAQPage Schema 已加（4–6 題）
- [ ] BreadcrumbList Schema 已加
- [ ] 每個 H2 開頭有粗體總結句
- [ ] 內文引用至少一篇 PMID 論文
- [ ] 正文自然帶入 2–3 次在地關鍵字
- [ ] 有 1–2 篇對話式內連
- [ ] Meta Description 含地區關鍵字
