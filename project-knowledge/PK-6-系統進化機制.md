# 系統進化機制（行動版）

> 這個系統不只是累積知識，而是持續進化。

---

## 知識熟成度（每張卡片都有）

| 狀態 | 意義 |
|------|------|
| 🌱 新鮮 | 剛建立，還沒連結到其他知識 |
| 🔗 已連結 | 跟其他卡片建立了關聯 |
| 💡 已應用 | 洞見已寫成文章或實際應用 |
| 🏛️ 已蒸餾 | 精華已提煉進長期記憶 |

---

## 你可以說的話

| 指令 | 我做什麼 |
|------|---------|
| 「幫我做系統體檢」 | 掃描整個知識庫，出報告 |
| 「蒸餾 [主題]」 | 把多張卡片提煉成一段永久智慧 |
| 「知識庫有沒有矛盾？」 | 找出互相打架的卡片 |
| 「哪些知識該寫成文章了？」 | 找出成熟但還沒應用的知識 |
| 「幫我拆解這篇文章」 | 消化 → 知識卡片 + 優化建議 |

---

```
蒸餾候選：X 個主題夠成熟
行動提醒：X 張卡片該寫成文章了

本月建議：
1. ...
2. ...
3. ...
```

---

## 蒸餾的概念

當你在同一個主題累積了 3 張以上知識卡片：

```
卡片A + 卡片B + 卡片C
        ↓
    找共同核心
        ↓
  1句永久智慧
        ↓
  寫入長期記憶
```

蒸餾後的智慧不會隨對話消失——它進入系統的 DNA。

---

## 系統進化的四個循環

```
① 輸入  你 → 文章/論文/觀察 → 知識卡片
② 連結  新卡片 ↔ 舊卡片 → 知識圖譜
③ 蒸餾  多張卡片 → 高層洞見 → 長期記憶
④ 行動  洞見 → 文章/衛教/產品 → 現實回饋
```
