# 文章消化流程（行動版）

> 大叔貼上任何文章 → 我自動拆解 → 輸出可直接貼進 Obsidian 的知識卡片

---

## 你只需要說

- 「幫我拆解這篇」
- 「消化這個」
- 「吸收進系統」
- 或直接貼上文章 URL / 全文

---

## 我會自動做的事

### 1. 判斷類型 → 選模板

| 文章類型 | 我用的模板 |
|---------|-----------|
| 學術論文（有 PMID/DOI） | 文獻卡 |
| 視光/健康科普 | 概念卡 |
| 行銷/SEO/商業策略 | 行銷卡 |
| 一般知識/生活觀察 | 概念卡（簡化版）|

### 2. 深度拆解

**學術論文重點抓取：**
- 一句話結論（30 字以內）
- 研究問題 + 3 個核心結論
- 樣本數 / 研究方法快照
- 主要數據 + 統計顯著性
- 這個研究在哪些情況下不適用（失效邊界）
- 對家長說明近視的啟示
- 可以寫成文章的角度

**科普/概念重點抓取：**
- 祖母測試（比喻給 8 歲小孩聽）
- 底層邏輯
- 臨床/決策意義
- 關鍵數據

**行銷/SEO 重點抓取：**
- 可偷學的寫作框架或標題結構
- 可用在目鏡大叔文章的具體手法
- 相關關鍵字

### 3. 輸出可直接貼進 Obsidian 的卡片

格式：完整 Markdown，含 frontmatter
建議檔名：`YYYYMMDD-主題關鍵字.md`
存放位置：`obsidian-vault/04-知識卡片/`

### 4. 系統優化掃描（自動）

- 💡 **現有卡片需要更新？** → 標記哪張卡要補充
- 📝 **文章靈感？** → 標記對應 2026 選題哪個主題
- 🔄 **需更新長期記憶？** → 標記重大觀念轉變

---

## 輸出範例

```
知識卡片輸出完成

檔名：20260325-眼軸增長與戶外光照.md
位置：obsidian-vault/04-知識卡片/
類型：文獻卡

[卡片完整內容...]

---
💡 建議更新：[[近視控制機制]] — 新數據補充了光照劑量效應
📝 文章靈感：「孩子每天要曬多少太陽才夠？」→ 對應 P1 選題
```

## 桌機才能完成的事

若在手機上，卡片末尾會加上：
> [待 Claude Code 處理] 寫入 Obsidian + 建立雙向連結

桌機打開 Claude Code 時，我會自動找到這個標記並處理。

## 知識卡片模板速查

### 文獻卡欄位
TL;DR / 研究問題 / 核心結論 / 方法快照 / 結果數據 / 專家批判 / 失效邊界 / 臨床啟示 / 知識連結

### 概念卡欄位
概念定義（祖母測試）/ 底層邏輯 / 臨床意義 / 關鍵數據 / 實戰立場 / 文獻連結

### 行銷卡欄位
FABE 解構 / 搜尋意圖 / SEO 關鍵字 / CTA 撰寫 / 應用建議
