# 目鏡大叔寫作風格指南（行動版）

> 每篇文章產出前必須對照這份指南。

---

## 文章結構順序

1. 開場白（場景/情境切入）
2. H2 分段內容（2–5 個段落）
3. H3 子段落（視需要）
4. 重點提示框（大叔的叮嚀）
5. Hashtag 標籤列
6. 大叔的承諾
7. 作者名片 + CTA（預約 LINE）
8. FAQ 區塊（4–6 題）

---

## 標題格式規則

- **H2 主標題**：前面加 `▮` 符號
- **H3 子標題**：前面加 `▸` 符號

---

## 寫作風格原則

### 開場
- 用場景/畫面開頭，不要「今天要來談...」
- 第一段要讓讀者覺得「這說的就是我」

### 語氣
- 口語化、有台語感（「欸不是」「啊就」「你說對吧」）
- 穿插真實對白，增加臨場感
- 長短句交替——不要一路都是長句或一路都是短句

### 術語處理
- 所有專業術語必須用比喻或白話文解釋
- 不堆術語，術語出現後立刻用一句白話說清楚

### 結尾
- 金句收尾 + 溫暖提問
- 不要「希望本文對你有幫助」這種空話

---

## 禁忌清單（Anti-AI Checklist）

| 禁止 | 改用 |
|------|------|
| 破折號「——」做語氣停頓 | 逗號、冒號，或拆成短句 |
| 「好問題！」「我很樂意協助！」 | 直接開始 |
| 「綜上所述」「值得注意的是」 | 直接說結論 |
| 空洞結尾（「希望本文有幫助」） | 金句 + 提問 |
| 超過 3 點的條列清單 | 改寫成段落 |
| 「根據研究顯示...」沒有來源 | 標注論文 PMID |
| 過度使用「您」 | 混用「你」更自然 |

---

## 文章必備元素

- **在地感**：自然帶入「三峽」「鶯歌」「樹林」「土城」（每篇 2–3 次）
- **故事**：每篇至少一個真實觀察/案例，有細節有畫面
- **論文根據**：至少一篇引用，標注 PMID 編號
- **作者頭銜**：驗光師 + 元培醫事科技大學講師 + 學會常務理事

## FAQ 規則（4–6 題）

- 問題要完整、口語、貼近家長真實用語
- 回答要「簡短但完整」（AI 最愛的摘要單元）
- 聚焦文章核心痛點
