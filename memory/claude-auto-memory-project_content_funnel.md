完整工作流存於 `.agents/workflows/content-funnel.md`（2026-04-08 建立）。

**核心架構（7層）：**
1. SEO 關鍵字群（A/B/C 級）
2. 曼陀羅九宮格展開 × 受眾快篩（4維度12分制，≥8分才寫）
3. 文章產出（HTML + Article + FAQPage Schema）
4. Lead Magnet（每篇不同，加 LINE 才能取得）
5. LINE 歡迎序列（7天主線，Day 0 交付、Day 1 衛教、Day 3 文章、Day 5 故事、Day 7 軟CTA）
6. 轉換預約（軟性 CTA）
7. 飛輪閉環（評論輪 MYOWNREVIEWS → 新陌生人）

**Why:** 大叔同時經營眼鏡行（自己的眼鏡）和驗光所，內容行銷是開新客的核心飛輪，老客靠 LINE 留存。

**How to apply:**
- 新文章任務：先跑曼陀羅快篩，分數 < 8 不寫
- 每篇文章配對應 Lead Magnet（見 content-funnel.md Layer 4 映射表）
- 寫文時同步規劃 LINE 序列內容
- 選題庫：`content-planning/選題庫.md`；年度規劃：`content-planning/2026-選題規劃.md`
