## Codex plugin 工作流治理

大叔提出一個重要工作流修正：Codex plugin 不應該用「看到工具就全部安裝」的方式處理，而應該先盤點、評估、排序，再提出安裝建議。

已將「Plugin Fit Report」成功範式寫入 `.claude/skills/uncle-glasses-distiller/TOOLS.md`，作為之後評估 Codex plugins 的標準提示與安全閘門。

核心原則：
- 先檢查 repo 技術棧、部署、資料庫、測試、工作流與權限邊界。
- 先輸出建議安裝清單，分成立即建議、之後再裝、不建議安裝。
- 每個 plugin 必須說明用途、適合原因、權限、風險與安裝前檢查事項。
- 最後才由大叔確認是否逐一安裝。

安全提醒：
- 只從官方 Codex plugin directory、OpenAI 官方 GitHub repo，或明確信任來源安裝。
- 不因為套件名稱含 Codex / OpenAI 就信任，避免惡意套件竊取登入憑證或 token。
