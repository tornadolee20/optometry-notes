# 2026-03-31 進度日誌

## 10:30 — 修復 ANTIGRAVITY 無法正常運作問題

### 診斷

ANTIGRAVITY 在家電腦與公司電腦（不同 Windows 帳號）都無法正常運作，共通點是使用同一個 Dropbox 資料夾。

**根本原因一（主要）**：`.claude/scheduled_tasks.lock`
- 內容：`{"sessionId":"9dab3abe...","pid":24624,"acquiredAt":1774716898175}`
- 3/29 殘留的過期鎖定檔案，PID 早已不存在
- 此檔案被 git 追蹤且透過 Dropbox 同步到兩台電腦
- 導致 ANTIGRAVITY Remote Trigger 呼叫 Claude Code 時被鎖定機制攔截

**根本原因二（次要）**：`.claude/settings.local.json` 存有家電腦的硬編碼路徑 (`C:\Users\torna_3j3fz9h\...`)，透過 Dropbox 同步到公司電腦後路徑不存在。

### 修復動作

1. 刪除過期 `.claude/scheduled_tasks.lock`
2. 在 `.gitignore` 加入：
   - `.claude/scheduled_tasks.lock`
   - `.claude/settings.local.json.tmp.*`
3. `git rm --cached` 把 lock 和 tmp 從 git 追蹤移除
