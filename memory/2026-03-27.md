# 2026-03-27 工作日誌

## 14:00 — 視力家家簿 APP 概念設計完成

### 背景
從「家長在診間狼狽翻手機找孩子度數」這個核心痛點出發，
完整規劃一個三代家庭視力管理 APP。

### 核心定位
- **不是**視力訓練 APP（現有競品的賺錢方式）
- **不是**視力檢查 APP
- **是**：視覺健康護照（Visual Health Passport）
- **是**：台灣家庭視力資料庫的入口

### 商業模式
- 免費版：1 位家庭成員，基本紀錄
- 家庭方案：NT$99/月 或 NT$799/年（無限成員 + 完整功能）
- 去識別化資料授權（學術/產業第二收入）
- 用戶主動選擇貢獻資料，可獲點數回饋

### 三代差異化紀錄設計
| 角色 | 主軸 | 關鍵欄位 |
|------|------|---------|
| 孩子 | 近視控制 | 散瞳驗光、眼軸估算、控制方案 |
| 自己 | 維持+數位眼疲勞 | CISS V-15、乾眼、隱形眼鏡 |
| 長輩 | 退化性疾病追蹤 | 白內障分級、AMD、眼壓、慢性病 |

### 法規設計
- 6歲以下年齡門禁：依驗光人員法，強制引導至眼科
- 眼科 vs 驗光所：分開的紀錄欄位（散瞳驗光 vs 一般驗光）
- 個資法特種個資：明確書面同意機制，預設不上傳

### 眼軸估算公式
採用 **Queirós 2022** 作為 MVP 基礎：
```
AL = (0.019 × Age) + (2.271 × Km) − (0.444 × SE) + 5.414
Km = (K1 + K2) / 2
SE = sphere + cylinder / 2
```
- 樣本 1,783 人，年齡 6-25 歲
- 顯示時標註「△ 估算值，非儀器實測」
- 長期目標：累積台灣資料後建立本土公式（第一篇論文潛力）
