## Prompt 規則正式修正

- 生成工具用 prompt 必須短、硬、準
- 字數有限時，優先保留：
  - 角色
  - 場景
  - 核心動作
  - 結構限制
  - 配音
- 預設可以沒有字幕
- 預設不能沒有配音
- **配音必須直接內嵌在同一段完整指令裡**
- 固定句型：
  - `全片搭配我的中文旁白配音，旁白台詞如下：『......』`

## 爆款影片拆解 workflow 成形

- 可以直接收爆款影片來學
- 工作流已驗證可行：
  1. 讀影片 metadata
  2. 用 ffprobe / ffmpeg 抽關鍵影格
  3. 看開場 / 中段 / 結尾
  4. 拆鉤子、節奏、轉場、角色、配音、配樂
  5. 轉譯成「你的版本」
- 不是抄內容，而是學機制：
  - 鉤子
  - 節奏
  - 小事件
  - 角色能量
  - 配音語氣
  - 配樂功能
