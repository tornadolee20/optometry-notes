## Self-Correction Log

1. `rg.exe` 在目前 Windows 執行環境回傳 Access Denied，廣泛 `Get-ChildItem -Recurse` 又曾逾時。修正：改用 `git ls-files` 縮小 tracked 範圍，再以目標式 `Get-ChildItem`／`Select-String` 掃描需要的目錄。
2. 系統 `python` 不可用。修正：透過工作區依賴清單取得 bundled Python 的明確路徑；KDF validator 只用 standard library，沒有新增套件。
3. 大型 `apply_patch` 在桌面工具中曾長時間沒有輸出。修正：不重送相同 patch，先等待完成並逐檔驗證，避免重複內容。
4. 第一版 wikilink regex 無法正確解析檔名本身含 `]` 的既有卡片，validator 因而 fail。修正：既有卡連結加上 alias，parser 改為允許非終止的單一 `]`；重跑後 broken links 歸零。
5. 額外的 fail-closed 負向測試第一次把相對路徑傳進只接受 repo 絕對路徑的報錯格式化函式，測試 harness 先失敗。修正：測試輸入先 `.resolve()`，四個安全欄位的負向測試均成功拒絕錯誤資料；產品 validator 的正式 PASS 結果未受影響。
6. 批次正規化 Markdown EOF 時，shell 對 `.agents/workflows/` 的三個檔案回報拒絕存取，且 PowerShell 仍回傳整體 exit 0。修正：逐項看 stderr，不以 exit code 單獨判斷；這三個檔案原本沒有 EOF 問題，其餘明確 KDF 路徑完成正規化，之後以 `git diff --cached --check` 作最終依據。
