# 視網膜檢影鏡模擬器（Retinoscopy Simulator）設計文件

日期：2026-07-15
用途：繼續教育課程／元培兼課教材，教學生判讀視網膜檢影鏡（retinoscopy）的反光動態
參考範本：AAO Retinoscopy Simulator（`ret.html`，功能已實地操作確認）

## 1. 目標與範圍

做出功能完整復刻版，繁體中文介面（可切換簡體），單一 HTML 檔、零依賴、可雙擊開啟或嵌入課程網頁／投影片。

包含：
- Explore 模式（老師/自己設定病人真實屈光度）
- Test 模式（隱藏答案，學生輸入判讀結果，容差驗證＋回饋）
- Working distance 換算
- 滑鼠拖曳掃描光帶，即時呈現順動／逆動／中和
- 13 組預設臨床案例
- 正柱面／負柱面記法互換顯示

不包含（明確排除，避免範圍蔓延）：
- 使用者帳號、雲端儲存、多人連線
- 真實眼睛照片素材（用 Canvas 繪製的風格化插畫代替，避免版權與資產依賴問題）
- 自動連續掃描動畫模式（本版只做手動拖曳）

## 2. 檔案位置

`tools/retinoscopy-simulator/index.html`

repo 目前沒有「互動教學工具」的既有目錄，獨立教學小工具適合獨立分區存放，未來若有第二個模擬器也有地方擴充。

## 3. 架構

單一 HTML 檔案內分兩層，用註解區塊隔開，邏輯上獨立：

### 3.1 光學運算層（純函式，無 DOM 依賴）

```
meridianPower(sphere, cylinder, axisDeg, atAngleDeg) -> number   // 負柱面公式
workingDistanceD(cmDistance) -> number                            // 100 / cm
neutralPowerAt(patientSphere, patientCyl, patientAxis, wdD, atAngleDeg) -> number
compareReflex(lensPowerAtAngle, neutralPowerAtAngle, tolerance=0.25)
  -> { state: 'neutral' | 'with' | 'against', magnitude: number }
plusCylToMinusCyl(sphere, cyl, axis) -> {sphere, cyl, axis}       // 記法互換
```

這些函式獨立於畫面，可在瀏覽器 console 直接呼叫驗證數值正確性，不需要跑整個 UI。

### 3.2 渲染層

- Canvas 畫眼睛：鞏膜、虹膜（radial gradient 模擬紋理）、瞳孔、反光光帶
- 其餘控制面板（tabs、輸入框、按鈕、滑桿）用一般 HTML/CSS，不畫在 canvas 裡
- 一個 `requestAnimationFrame` 迴圈，只在使用者拖曳期間跑（放開滑鼠即停在當前畫面，不做閒置時的持續動畫）

## 4. 光學模型細節

- 子午線度數公式（負柱面慣例）：
  `power(θ) = Sphere + Cylinder × sin²(θ − axis)`
- Working distance 度數：`100 / 工作距離(cm)`，從病人真實度數扣除，得到「中和所需鏡片度數」
- 中和判斷：`|目前鏡片在掃描角度的度數 − 中和所需度數| ≤ 0.25D` 視為中和
- 順動／逆動：差值正負決定方向；差值絕對值決定光帶移動速度與亮度（差越大速度越快、光帶越亮寬；接近中和時變慢變窄，模擬剪動感）
- 掃描角度與病人真實散光軸沒對準時，反光帶會有「歪斜」視覺效果（簡化模擬，非嚴格幾何光學，會在 UI 說明文字註明）

## 5. 互動設計

- 滑鼠在眼睛 Canvas 區域按下並拖曳 → 依目前「streak angle」設定的軸向，光帶隨拖曳方向/速度即時渲染
- 拖曳中即時呼叫光學運算層重新計算，放開滑鼠後畫面停格在最後狀態
- 觸控裝置：同樣綁定 touch 事件（touchstart/touchmove/touchend），保留未來平板教學可能性

## 6. 介面配置

右側面板：
- **explore / test** 分頁 tab（點擊切換）
  - explore：病人 sphere / cylinder / axis 撥盤（供備課、示範）＋ 下方「refractive error」顯示區，同時顯示正柱面/負柱面兩種記法
  - test：病人真實度數完全隱藏；改為「你的判讀」輸入框（sphere -20~+20、cyl -6~+6、axis 0~180，數字輸入驗證），「檢查答案」按鈕，回饋文字（正確／接近／不正確，並顯示容差內的正確範圍）

左下：
- **lenses** 面板：sphere / cylinder / axis 撥盤（模擬試戴鏡片，學生用來中和反光）
- **streak angle** 控制：數值輸入框 + 45°/90°/135°/180° 快捷鍵按鈕 + 旋轉圖示重置
- **working distance** 控制：常用距離快捷按鈕（50cm=2.00D、67cm=1.50D、100cm=1.00D）+ 自訂數字輸入

頂部：
- **presets** 下拉選單（13 組臨床案例，見第 7 節）
- 語言切換（繁體 / 簡體）按鈕

## 8. 測試／驗證方式

- 這是純前端靜態頁面，不需要自動化測試框架
- 光學函式在 console 手動餵測資料驗證（例如：驗證 preset 7 在 90° 與 180° 的度數是否等於 0.00 / −2.00）
- 用瀏覽器實際操作驗證：切換 explore/test、13 組 preset、working distance 快捷、streak angle 快捷鍵、拖曳掃描是否呈現正確順動/逆動/中和、test 模式的容差驗證與回饋文字
- 手機/平板寬度做一次 resize 檢查（響應式非強制需求，但拖曳需在小螢幕仍可操作）

## 9. 排除的複雜度（明確簡化，避免誤解為 bug）

- 反光的「歪斜」效果是簡化視覺提示，不是嚴格幾何光學運算
- 光帶亮度/寬度與屈光不正程度的對應關係為教學示意，非物理精確亮度模型
- 不做瞳孔大小、調節、可變視網膜反光等進階變因
