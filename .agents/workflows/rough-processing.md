# 文章粗處理（Antigravity 專用）

## 你的角色

你負責**快速、高量**的初步萃取。
Claude Code 負責**深度、高品質**的精煉。
不要搶 Claude 的工作，你的任務是「備料」，不是「出菜」。

---

## 輸入

大叔丟來的任何一種：
- 文章 URL
- 全文貼上
- PDF
- 截圖 + 說「粗處理這個」

---

## 執行步驟（限時 60 秒思考）

1. **判斷類型**：論文 / 科普 / 行銷 / 其他
2. **抓核心主張**：1–3 句，不超過 50 字
3. **抓關鍵數據**：數字、百分比、樣本數（如有）
4. **猜連結**：可能與哪張知識卡片相關（不確定也寫）
5. **建議模板**：文獻卡 / 概念卡 / 行銷卡

---

## 輸出格式（固定，不要改）

```markdown
## [文章標題或你給的簡短名稱]
- **來源**：[URL 或標題]
- **類型**：[論文 / 科普 / 行銷 / 其他]
- **核心主張**：[1–3 句]
- **關鍵數據**：[數字或「無」]
- **初判連結**：[可能相關的知識卡，不確定就寫「不確定」]
- **建議模板**：[文獻卡 / 概念卡 / 行銷卡]
- **備注**：[特別要注意的點，或「無」]

> [待 Claude 深處理]
```

---

## 輸出位置

將結果**追加**到 `Inbox/待深處理.md`，用 `---` 分隔。

---

## 禁止事項

- ❌ 不要自己建知識卡片（那是 Claude 的工作）
- ❌ 不要做深度批判分析
- ❌ 不要填寫失效邊界、臨床啟示等深度欄位
- ❌ 不要修改現有知識卡片

---

## 範例輸出

```markdown
## 戶外活動與近視控制：2小時的意義
- **來源**：https://pubmed.ncbi.nlm.nih.gov/XXXXXXXX
- **類型**：論文
- **核心主張**：每日戶外活動 2 小時可顯著延緩兒童近視進展，效果獨立於近距離用眼時間
- **關鍵數據**：RCT, n=1903, 追蹤 3 年, 近視發生率降低 23%
- **初判連結**：可能相關 [[近視控制機制]] [[兒童戶外活動]]
- **建議模板**：文獻卡
- **備注**：注意台灣氣候（高溫潮濕）對戶外時間建議的適用性

> [待 Claude 深處理]
```
