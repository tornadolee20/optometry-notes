# /video-review-board (影片多維大師審核委員會工作流)

**執行者**：Antigravity (目鏡大叔 AI)  
**啟動時機**：在影片翻譯、配音、字幕壓製或剪輯完成後，當前輩要求「審核影片」、「看影片哪裡要調整」或「做爆款評估」時自動啟動。

---

## 🏛️ 5 位審查官與評審標準 (The 5 Video Reviewers)

```
                       ┌────────────────────────────────┐
                       │    /video-review-board 審核     │
                       └───────────────┬────────────────┘
                                       │
      ┌────────────────┬───────────────┼───────────────┬────────────────┐
      ▼                ▼               ▼               ▼                ▼
【MrBeast 留存】  【Atul 視光】   【費曼 白話】  【台灣法規】   【毫秒影音對齊】
 衡量前3秒與吸引力  衡量溫暖與臨床正確  衡量聽感與無名詞障礙 驗光師法與廣告紅線  極致影音字幕同步率
```

### 1. 🎬 MrBeast 注意力與留存率審查官 (Attention & Hook Auditor)
- **職責**：以爆款影片工程學，審核前 3 秒與留存率。
- **檢查點**：
  - [ ] 前 3 秒是否有強烈的「痛點 Hook」或「身份警示」？
  - [ ] 標題與封面圖是否有高對比數字與懸念？
  - [ ] 中段畫面是否缺乏節奏干擾 (Pattern Interrupt) 而導致聽覺疲勞？

### 2. 🩺 Atul Gawande 視光人文與照護審查官 (Optometry Care Auditor)
- **職責**：確保影片傳達的視光醫學觀點溫暖、精準、從生活功能出發。
- **檢查點**：
  - [ ] 翻譯是否擺脫機械醫學名詞，轉化為「生活半徑」、「大腦負擔」等白話照護感受？
  - [ ] 是否給予長輩與家屬極具同理心的解法，而非恐嚇式衛教？

### 3. 💡 理查・費曼 口語聽感審查官 (Feynman Audio Flow Auditor)
- **職責**：逐句評估語音聽感，去除俚俗簡寫與生硬口語。
- **檢查點**：
  - [ ] 語速是否過快？（atempo 是否超出 1.15x 限制？）
  - [ ] 台詞是否有不自然簡寫？（例如：`吃晚藥` 應修正為 `吃晚上的藥`；`定期眼檢` 應修正為 `定期檢查眼睛`）。
  - [ ] 句型是否長度適中、留白自然？

### 4. ⚖️ 台灣視光法規與在地詞彙守門人 (Taiwan Optometry Legal Guardian)
- **職責**：確保全片符合台灣驗光師法與在地用語習慣。
- **檢查點**：
  - [ ] 視光場所是否嚴格使用 **「驗光所」**（禁止誤用診所或眼鏡行）？
  - [ ] 期刊譯名是否符合台灣學術界標準（如：**《刺胳針》** 而非 大陸譯名《柳葉刀》）？
  - [ ] 是否符合驗光師法第 12 條（不宣稱醫療效果）？

### 5. ⏱️ 毫秒級影音與字幕同步工程師 (Frame-Sync Engineer)
- **職責**：對齊影像、配音與字幕的時間戳，徹底消除時間差。
- **檢查點**：
  - [ ] 前導 Hook 與主影片串接點是否達到毫秒級對齊（0 時間差）？
  - [ ] 音訊採樣率是否壓製為標準 **44.1kHz AAC**（防止通用播放器無聲）？
  - [ ] 浮水印去處 (Delogo) 是否殘留模糊遮擋字幕？

## 📋 審核結果輸出格式

每次審核完成後，輸出以下矩陣報告：

```markdown
### 🏛️ /video-review-board 審核結果矩陣

| 審查官 | 評分/狀態 | 發現問題 | 建議處置行動 |
|:---|:---:|:---|:---|
| **1. MrBeast 留存** | PASS / REVISE | 前 3 秒缺 Hook | 加入 8 秒警示爆款開頭 |
| **2. Atul 視光** | PASS | 觀點溫暖精準 | 無需調整 |
| **3. 費曼 聽感** | REVISE | 包含不自然用語 | 將「定期眼檢」改為「定期檢查眼睛」 |
| **4. 台灣法規** | PASS | 已合規 | 確定使用「驗光所」與「《刺胳針》」 |
| **5. 影音同步** | REVISE | 影音落差 9 秒 | 重新計算 offset 並完成毫秒對齊 |
```
