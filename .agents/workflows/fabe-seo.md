# FABE 戰略選題矩陣工作流 /fabe-seo

當大叔輸入 `/fabe [檔名或主題]`，表示要把某個知識點（如一篇文獻）轉化成可落地變現的商業彈藥。

### 🎯 任務目標
不只是單一分析，而是要建立一個橫跨「痛點聲量」與「獨家優勢」的戰略選題矩陣，一次擠出 3 個以上的高含金量選題。

### 🧠 執行步驟 (矩陣四大層次)

1. **讀取內容**：查看使用者指定的知識卡片或檔案內容。
2. **第一層：痛點掃描**：
   - 想像 30 位家長模擬器中的客群，抓出他們遇到這個主題時最痛的 3~4 個痛點。
   - 標示對應的家長類型以及聲量強度（高/中/低）。
3. **第二層：FABE 破甲彈裝填**：
   - **Feature (特色)**：知識點的客觀事實（如：山桑子 240mg）。
   - **Advantage (優勢)**：與競品或傳統作法（如點散瞳）相比，我們的優勢在哪？
   - **Benefit (利益)**：具體描述客戶使用後的生活畫面與心理變化。
   - **Evidence (證據)**：臨床數據、醫學文獻或大叔的驗光經驗背書。
4. **第三層：SEO 搜尋意圖推演**：
   - 根據痛點，推演客戶會 Google 什麼？（包含核心、問句、痛點、情境、商業關鍵字）。
5. **第四層：選題輸出 (自動生成 CTA)**：
   - 綜合以上三層，產出至少 3 個「建議標題」，並為每個標題指定「主攻痛點客群」與「專屬 CTA (行動呼籲)」。
6. **建立行銷卡**：將分析出來的完整矩陣，依照 `行銷卡-MarketingNote.md` 格式存入 `obsidian-vault/04-知識卡片/`。
