# content-funnel.md
# 目鏡大叔內容行銷漏斗工作流
> 建立：2026-04-08｜從陌生人到熟悉客人的完整內容產出系統

---

## 工作流總覽

```
Layer 1：找缺口     SEO 關鍵字群（A/B/C 級）
Layer 2：展開題材   曼陀羅九宮格 × 受眾篩選 → 快篩審核閘門
Layer 3：產出文章   HTML + FAQ Schema + Article Schema
Layer 4：接住讀者   文章底部 CTA → 專屬 Lead Magnet（每篇不同）
Layer 5：進入名單   加 LINE → 歡迎序列（7天自動推送）
Layer 6：轉換預約   軟性 CTA → 到店服務
Layer 7：飛輪閉環   滿意 → 評論輪（MYOWNREVIEWS）→ 新陌生人進站
```

---

## Layer 1：SEO 關鍵字群

參考：`content-planning/2026-選題規劃.md`

分級標準：
- **A 級**：搜尋量高 × 競爭中 × 你有專業優勢 → 優先寫
- **B 級**：搜尋量中高，既有草稿或知識基礎
- **C 級**：長尾、在地、低競爭

---

## Layer 2：曼陀羅展開 + 快篩審核閘門

### Step 1：展開
取一個核心關鍵字 → 曼陀羅九宮格展出 8 個子題目

### Step 2：受眾篩選
標記每題主要受眾：家長群 / 成人 / 銀髮駕駛

### Step 3：快篩審核（4 維度，12 分滿分）

| 維度 | 問題 |
|------|------|
| 搜尋意圖 | 真的有人 Google 這個嗎？ |
| 實用性 | 看完能解決問題嗎？ |
| 轉換力 | 看完會想預約或加 LINE 嗎？ |
| 差異性 | 大叔比別人更有資格寫？ |

**門檻**：≥8 分 → ✅ 進排程｜6-7 → 👀 觀察｜≤5 → ❌ 砍掉

### 審核人格（取最相關的 2 個跑）

| 人格 | 背景 |
|------|------|
| 小美媽媽 | 38歲，孩子剛被通知視力不良 |
| 阿傑 | 32歲，3C重度使用者 |
| 李伯伯 | 62歲，老花換照困擾 |
| SEO編輯 | 代表搜尋演算法邏輯 |

### 通過後自動標記
- 主要受眾標籤
- 對應 Lead Magnet 編號
- 排入寫作佇列

---

## Layer 3：文章產出規範

- 格式：HTML（參考散光夜間駕駛文章為模板）
- Schema：Article + FAQPage（必備）
- 結構：開場故事 → 核心知識 → 表格 → FAQ → CTA 卡片
- 口吻：沉穩、專業、幽默、三峽在地感
- 禁忌：破折號「——」、空洞結尾、過度列點、AI 感套話
- 在地錨文字（每篇結尾必加）：三峽／鶯歌／樹林／土城

---

## Layer 4：Lead Magnet 映射表

每篇文章對應一份專屬 Lead Magnet，加 LINE 才能取得。

| 文章主題 | Lead Magnet |
|---------|------------|
| 驗光所 vs 眼鏡行 | 驗光前必問的 5 個問題 PDF |
| 配鏡流程圖解 | 配鏡當天準備清單（可列印）|
| 第一次配眼鏡 FAQ | 20 個配鏡常見問題完整版 PDF |
| 學校視力通知單怎麼處理 | 帶孩子配鏡前 10 件事確認清單 |
| 假性近視要配眼鏡嗎 | 孩子近視風險自我評估表 |
| 度數越來越深 / 配足配淺 | 兒童近視控制進度記錄表 |
| 阿托品停藥策略 | 阿托品使用與停藥完整指南 PDF |
| 藍光眼鏡有用嗎 | 護眼習慣 20 條懶人清單 |
| 鏡片品牌怎麼選 | 鏡片選購對照表 |
| 什麼時候該換眼鏡 | 眼鏡健康壽命自我檢查表 |

---

## Layer 5：LINE 歡迎序列（7天主線）

所有 Lead Magnet 入口合流至同一條序列，Day 0 訊息依 Lead Magnet 不同客製。

```
Day 0  加好友當下 → 交付 Lead Magnet（PDF 連結）
Day 1  一則衛教小知識（與 Lead Magnet 主題相關）
Day 3  一篇部落格文章連結（對應搜尋意圖）
Day 5  真實客人故事
Day 7  軟性 CTA：「有問題歡迎直接問我」或本週預約空檔
```

每則訊息：100 字以內，一個重點，一個行動。

---

## 執行天條

1. 快篩 < 8 分不寫，省算力給高分題目
2. 每篇文章配一個專屬 Lead Magnet，不用通用版
3. 文章底部 CTA 必須指向 LINE，不只是電話
4. Schema 每篇必備，不省略
