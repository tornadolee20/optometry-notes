# Dayan Yarrow Procedure

Use this file for questions about 大衍筮法, 蓍草起卦, or the logic behind `6/7/8/9`.

## Minimal Conceptual Frame

- Start from `50`
- Set aside `1`
- Operate with `49`
- Each line requires `3` changes
- A completed line resolves into one of `6, 7, 8, 9`
- Build six lines from bottom to top

## Why It Matters

Dayan is not just a randomizer. It encodes a ritualized numerical process tied to classical Yijing cosmology.

## One-Line Procedure Summary

For each line:

1. split the stalks into two heaps
2. take one stalk from the right heap and hold it aside
3. count each heap by fours and keep the remainder
4. remove the counted remainder set
5. repeat until three changes are complete
6. resolve the result into `6, 7, 8, or 9`

## Line Values

- `6`: old yin, changing
- `7`: young yang, stable
- `8`: young yin, stable
- `9`: old yang, changing

## Interpretation Relevance

- `6` and `9` are moving lines
- moving lines generate the transformed hexagram
- the main reading still starts from the original hexagram and relevant line texts

## Contrast With Three-Coin Method

Do not treat them as equivalent.

- both produce `6/7/8/9`
- their procedural logic differs
- their probability distribution differs
- three coins are practical and common
- dayan is more classical and structurally elaborate

## Safe Claims

You can safely say:

- the standard explanatory frame links this procedure to the 繫辭 tradition
- the method uses `50` symbolically but `49` operationally
- the line-generation probabilities are not identical to the three-coin method

Avoid claiming:

- that every later reconstruction of exact physical handling is historically identical
- that one modern demonstration is the only authentic version
