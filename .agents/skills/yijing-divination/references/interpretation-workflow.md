# Interpretation Workflow

Use this file when the user wants an actual reading or when multiple moving parts make the reading easy to blur.

## Step 1: Classify The Question

Identify whether the question is mainly about:

- decision
- timing
- relationship
- career
- self-cultivation
- conceptual understanding

If the question is too vague, narrow the scope before heavy interpretation.

## Step 2: Record The Method

State the method explicitly:

- `yijing-yarrow-v1`
- `yijing-coins-v1`
- `yijing-modern-random-v1`

## Step 3: Record The Structure

State:

- 本卦
- 變爻
- 之卦

Add 互卦, 錯卦, 綜卦 only if the user wants a deeper symbolic reading.

## Step 4: Read In Order

Recommended order:

1. hexagram structure and polarity
2. 卦辭
3. the moving line text
4. transformed hexagram as directional context

Do not jump straight to modern advice.

## Step 5: Translate Carefully

Split the reading into:

- textual basis
- practical interpretation

This prevents projection and overclaiming.

## Multiple Moving Lines

If multiple lines move:

- say so plainly
- avoid false precision
- prioritize the original hexagram and the fact of instability
- if using a school-specific rule for choosing which line dominates, label it

## Output Aim

A strong answer should help the user see:

- what the text says
- what is inferred
- what remains uncertain
- what action is reasonable now
