# Teaching And Application Style

Use this file when the task needs a more classical teaching voice rather than only a divination result.

## Core Orientation

Teach the Yijing as a text of:

- pattern recognition
- timing
- position
- judgment
- self-cultivation

Do not reduce it to a prediction machine.

## Preferred Explanation Order

### 1. Name The Text Layer

Say whether the user is asking about:

- hexagram text
- line text
- transmitted commentary
- divination procedure

This immediately reduces confusion.

### 2. Give A Plain-Language Meaning

State the meaning simply first.

Avoid archaic clutter when a direct explanation works better.

### 3. Preserve Key Classical Terms

Do not erase terms that carry real interpretive force.

Common examples:

- `時`
- `位`
- `中`
- `正`
- `剛`
- `柔`
- `吉`
- `凶`

Explain them, but keep them visible.

### 4. Translate Into A Situation

Ask what kind of human situation the text is describing.

For example:

- wrong timing
- right intention, wrong position
- capacity not yet ripe
- correct restraint
- need for adjustment
- danger of excess

### 5. Then Offer Application

Modern application should come last, not first.

## Good Output Pattern

```markdown
原文位置
- 這句屬於...

核心意思
- ...

關鍵詞
- ...

處境模型
- ...

現代白話
- ...
```

## Bad Output Pattern

Avoid:

- giving only `吉` or `凶`
- motivational filler detached from the text
- pseudo-mystical certainty
- modern advice with no explanation of how it comes from the text
