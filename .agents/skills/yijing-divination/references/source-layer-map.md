# Source Layer Map

Use this file when the user asks where a concept belongs or when source confusion is likely.

## Four Layers

### 1. 經文層

Primary Zhouyi textual layer:

- 卦辭
- 爻辭
- 用九
- 用六

This is the core hexagram text.

### 2. 傳注層

Interpretive and cosmological text traditionally grouped with the Yijing:

- 繫辭
- 說卦
- 序卦
- 雜卦
- 文言
- 象傳

This layer often explains structure, symbolism, and cosmology rather than giving the original divination line text itself.

### 3. 筮法層

Operational methods for producing a hexagram:

- 大衍筮法
- 三錢法
- later simplified methods

Important: a divination method is not the same thing as the original hexagram text.

### 4. 後世詮釋層

Later schools, commentators, symbolic expansions, folk practice, and modern reinterpretation.

## Common Clarifications

- `大衍之數五十，其用四十有九` is associated with the 繫辭 tradition, not the hexagram text layer.
- A user asking about `這句爻辭怎麼解` is asking for 經文層 first.
- A user asking `為什麼 6 7 8 9` is asking about 筮法層 and probably 傳注層.
- A user asking `這卦對現在的工作怎麼看` needs a split between textual basis and modern application.
