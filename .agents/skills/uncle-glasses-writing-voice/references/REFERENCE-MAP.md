# REFERENCE-MAP.md

Updated: 2026-04-15

## Purpose

This file explains which writing-voice reference should be loaded for which need.

The goal is to keep the voice core small while preserving access to useful support material.

## Reference Routing

### `voice-model.md`

Use when the task needs the deepest explanation of the voice itself:

- tonal center
- emotional posture
- restraint
- human texture

### `opening-hooks.md`

Use when the main problem is:

- weak opening
- no pull in the first lines
- starting too abstractly

### `transition-lines.md`

Use when the draft feels:

- jumpy
- mechanically segmented
- stitched together instead of flowing

### `closing-lines.md`

Use when the ending feels:

- abrupt
- limp
- over-explained
- emotionally unresolved

### `ending-modules.md`

Use when the piece needs a clearer ending shape, not just one sentence.

This is useful for:

- reflective endings
- practical endings
- invitation endings
- restrained emotional endings

### `hybrid-patterns.md`

Use when the system needs to calibrate the Uncle Glasses / Wu Nien-jen blend more carefully.

### `article-type-formulas.md`

Use when the task is not only "sound right" but also:

- choose the right article shape
- structure a story article
- structure a belief-shift article
- structure an explanatory article

### `article-scoring-checklist.md`

Use mainly for review or self-check.

Prefer `uncle-glasses-writing-qa` as the leading layer if the main task is evaluation.

## Loading Rule

Do not load all references by default.

Load only the smallest reference set that helps the current task.

## Bottom Line

The references are support gear.

`uncle-glasses-writing-voice` remains the core skill.
