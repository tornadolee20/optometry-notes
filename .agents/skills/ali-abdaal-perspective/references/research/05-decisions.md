## 關鍵決策

### 1. 在醫學生與初期醫師階段就開始公開創作
這代表他沒有把「等我完全準備好」當前提，而是讓內容成為職涯實驗的一部分。

### 2. 從讀書與醫學生內容，逐步擴到生產力與生活設計
這不是背離初心，而是跟著自己與觀眾的交集演化。

### 3. 從兼職創作者，轉向全職 creator / entrepreneur / writer
官方 About 頁明確提到，2021 年他正式做出離開醫學、全職投入創作者與創業生活的決定。

### 4. 把內容延伸為課程、社群、系統、App
這說明他不是把 YouTube 當單點平台，而是當品牌入口。

### 5. 將生產力主張從 discipline，轉向 joy
這是很重要的品牌差異化決策，幫他從紅海的效率內容裡分出自己的位置。

## 推論

Ali 最重要的決策能力，在於他不是每次都換題目，
而是每次都把同一條主線往更上位的層次推進：

讀書方法 -> 生產力 -> 人生成長 -> 創作者系統 -> 工具與產品

## 對你的啟發

你未來也可以走這種升階路徑：

驗光知識 -> 視力生活決策 -> 家庭照護與功能視覺 -> 品牌內容 -> 服務/產品
