# 05 Decisions

## 代表性決策與其意義

### 1. 選擇持續寫醫療的不完美，而非只寫成功

意義：
- 建立了「可信專業」的寫作路線
- 讓讀者願意相信他，不是因為他最強，而是因為他誠實

### 2. 把清單帶進高風險場景

意義：
- 證明「簡單工具」在複雜環境中可以有巨大影響
- 不是追求聰明，而是降低遺漏

### 3. 把老化與臨終照護寫進主流公共討論

意義：
- 不再只談救命，而是談什麼樣的生活值得被保護
- 對視光與長輩題材非常有啟發性

### 4. 從臨床延伸到公共系統改革

意義：
- 顯示他不是只看個案，也一直關心系統設計
- 很適合借用來寫「不是某個人不努力，而是整個系統讓人容易失敗」

## 決策偏好

- 偏好具體可執行的改進
- 偏好能降低傷害的流程
- 偏好誠實揭露限制
- 偏好價值對齊，不偏好強制說服
