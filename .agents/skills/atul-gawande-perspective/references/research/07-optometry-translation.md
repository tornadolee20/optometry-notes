# 07 Optometry Translation

## 這份轉譯檔的用途

這不是在證明 Atul Gawande 有寫過視光。

而是把他的框架，轉譯成最適合你部落格與門市工作的版本。

核心目標：

- 讓專業更有人味
- 讓照護選擇更能被理解
- 讓視光內容不只停在度數與鏡片，而能進入生活功能、尊嚴、拖延、照顧與取捨

## 一、Atul 框架最適合你處理的視光題材

### 1. 長輩一直說「還可以」

Atul 式切法：

- 表面問題：眼鏡太舊、老花加深、看不清楚
- 深層問題：不想承認退化、不想麻煩孩子、不想被當成老了
- 真正問題：生活功能已經慢慢被吃掉，但本人還在用忍耐維持尊嚴

適合文章方向：

- 為什麼很多長輩總說「還可以」
- 不想配眼鏡，真的只是節省嗎
- 看不清楚背後，常常不是眼睛，是尊嚴

### 2. 家屬陪同配鏡

Atul 式切法：

- 表面問題：要不要配、要配哪一副、什麼時候處理
- 深層問題：照顧責任、內疚、補償、恐懼、角色反轉
- 真正問題：這不只是配鏡，而是家人怎麼一起面對老化與限制

適合文章方向：

- 幫爸媽配眼鏡的那一天
- 孩子帶媽媽來配鏡，真正想處理的是什麼
- 一副眼鏡背後，其實是一場照顧的交接

### 3. 孩子近視控制

Atul 式切法：

- 表面問題：度數增加、3C、睡前用眼
- 深層問題：親子對立、罪惡感、控制與合作
- 真正問題：家長不是缺規則，而是缺一個可長期執行的生活協議

適合文章方向：

- 近視控制不是單一技術，而是家庭系統題
- 家長真正怕的，不只是多一百度
- 合作式用眼，比對抗式控管更能長久

### 4. 配鏡不適與多焦點適應

Atul 式切法：

- 表面問題：眼鏡不舒服、戴不久、頭暈、壓力感
- 深層問題：捨不得承認花錯錢、怕自己難搞、怕麻煩人
- 真正問題：人常會把不適合理解成自己要忍耐，而不是系統需要修正

適合文章方向：

- 不是你太難搞，是這副眼鏡不適合你
- 多焦點不是不能適應，而是要先問值不值得你這樣適應
- 真正好的方案，不是最貴，是最能讓生活運作

## 二、最適合你借用的 Atul 核心提問

這 6 題幾乎可以變成你寫文前的內部問卷：

1. 這個人現在最痛的，不是眼睛，而是生活哪一塊？
2. 他嘴上說的，和他真正怕失去的，是不是同一件事？
3. 這裡最大的問題是拖延、誤解、流程、還是病理？
4. 有沒有一個最小但能改善生活的下一步？
5. 家屬與本人，在追求的是同一個結果嗎？
6. 這篇如果只講專業，不講照護，會不會太扁？

## 三、Atul 版文章的最佳結構

### 結構 A：照護選擇型

1. 一個人來了，嘴上說「還可以」
2. 生活裡其實已經很多地方不方便
3. 家人與本人想法不同
4. 專業介入，重新定義問題
5. 回到：什麼對他真正重要

### 結構 B：風險溝通型

1. 一個大家都很怕的數字或變化
2. 先處理情緒與誤解
3. 再拆風險不是單一敵人
4. 給一個做得到的路徑
5. 收在合作而不是命令

### 結構 C：生活功能型

1. 不是哪個參數變了
2. 是這個人開始不能好好生活了
3. 把問題翻譯成吃飯、走路、看手機、工作、看人臉
4. 再帶出專業方案
5. 收在尊嚴、自主與放心

## 四、Atul 模式最能補你的地方

你原本已經很強的：

- 故事
- 親情
- 門市現場感
- 被理解感

Atul 幫你補的是：

- 對限制與取捨的誠實
- 風險溝通的可信度
- 生活功能導向的專業框架
- 清單化與可執行改進
- 照護哲學的穩定底盤

## 五、最重要的一句總結

Atul Gawande for Optometry 的重點不是：

「把視光寫得像醫療。」

而是：

「把視光寫成一種照護選擇，讓人知道自己不是只在處理眼睛，而是在守住生活。」
