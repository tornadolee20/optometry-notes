# Threads Account Research

## 目的

這個 Skill 的用途不是單純摘要幾篇貼文，
而是把一個 Threads 帳號拆成可行動的內容模型。

輸出重點應該包含：

- 帳號定位
- 目標受眾
- 內容支柱
- 常見爆點與鉤子
- 文風與敘事節奏
- 轉換與變現線索
- 哪些可借、哪些不要照抄

## 先做什麼

先判斷資料可見度，分成三種模式：

### 模式 A：可直接讀公開 Threads 內容
如果帳號頁或貼文頁能直接打開，優先直接讀原文，再補外部資料。

### 模式 B：原文部分可見
如果只有少數貼文連結、或搜尋引擎有片段收錄，就用片段 + 外部引用頁拼接。

### 模式 C：Threads 原文讀不到
如果遇到登入限制、429、動態頁無法抓取，改走「外圍重建法」：

1. 搜尋該帳號的公開連結與介紹頁
2. 找 Podcast、活動頁、商品頁、課程頁、Portaly、Link-in-bio
3. 找被別人引用或轉述的貼文片段
4. 從內容主題、產品、訪談摘要反推內容策略

不要因為讀不到全文就停止分析，但要明確標示哪些是直接證據，哪些是推論。

## 研究流程

### Step 1：帳號基本盤
先確認：

- 帳號名稱 / handle
- 自我介紹
- 連出去的網站或產品
- 主要主題
- 看起來在賣什麼，或想建立什麼形象

### Step 2：收集素材
優先順序：

1. Threads 帳號首頁與單篇文
2. 搜尋引擎收錄的 Threads 片段
3. Portaly / Linktree / 官網 / 商品頁
4. Podcast / 訪談 / 活動頁
5. 其他社群平台對同一人的描述

把來源分成：

- 直接來源
- 間接來源
- 推論來源

### Step 3：做內容拆解
至少整理這 6 件事：

1. 這個帳號最常講哪 3-5 類主題
2. 貼文常用什麼開頭鉤子
3. 是偏故事、偏觀點、偏教學、還是偏情緒共鳴
4. 怎麼把流量導向產品、服務或個人品牌
5. 哪些內容看起來最容易被轉發或收藏
6. 帳號的人設是什麼

### Step 4：輸出判斷
最後一定要回答：

- 他為什麼能吸引人
- 他真正賣的是什麼
- 他的策略哪些有效
- 哪些只是風格，不一定適合複製
- 對使用者有什麼可執行啟發

## 建議輸出格式

### 簡版
適合快速研究：

1. 帳號定位
2. 三大內容支柱
3. 三個爆點機制
4. 三個可借鏡之處
5. 三個不該照抄之處

### 完整版
適合深度研究：

1. 帳號概況
2. 受眾與承諾
3. 內容支柱
4. 鉤子與文風
5. 商業路徑
6. 代表貼文樣式
7. 對使用者的轉譯建議
8. 證據與推論區分

## 分析原則

### 要做的

- 區分「原文可見」與「外部重建」
- 從商業與內容兩邊一起看
- 關注長期重複出現的 pattern，不只看單篇爆文
- 把觀察轉成可執行建議

### 不要做的

- 不要把少量片段誤判成整體風格
- 不要把別人的人格包裝直接照搬給使用者
- 不要把「高流量」等同於「適合複製」
- 不要在證據不足時講得過度肯定

## 給這個工作區的轉譯

套用到這裡時，這個 Skill 最有用的場景是：

### 研究視光/健康創作者帳號
- 拆解台灣視光師、眼科醫師、健康科普帳號的內容策略
- 找出他們怎麼把專業轉成讓人願意看的 Threads 貼文
- 分析他們的鉤子、爆點結構、是否有 CTA 與轉換路徑

### 研究品牌/門市帳號
- 拆解眼鏡品牌（Gentle Monster、JINS、Owndays）在台灣 Threads 怎麼操作
- 找出在地服務業如何用 Threads 建立信任與引流門市

### 轉譯到大叔的內容系統
- 觀察別人爆文結構 → 提煉出可用的「鉤子句型」→ 加入 `.agents/skills/uncle-glasses-writing-voice/references/opening-hooks.md`
- 發現競品沒做的內容空白 → 補入 `content-planning/選題庫.md`
- 研究別人的轉換路徑 → 對照大叔的 Russell Brunson Funnel 找缺口

### 大叔版研究原則
- 優先研究「專業者如何做 Threads」，不是純娛樂帳號
- 重點看：如何把複雜專業概念在 500 字內讓外行人感興趣
- 研究完要有一個「這裡有什麼我可以用」的行動清單，不只是描述
