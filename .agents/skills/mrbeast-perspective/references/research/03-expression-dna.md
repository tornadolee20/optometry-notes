# Agent 3：MrBeast 表達DNA
> 調研日期：2026-04-11 | 來源：36頁泄露手冊、Lex Fridman #351、JRE #1788、Colin & Samir、Diary of a CEO、X/Twitter原文、733個影片逆向工程

## 標題公式（Top 100共同結構）

| 模式 | 出現率 | 結構公式 |
|------|--------|---------|
| 金錢錨定 | 52% | `$[具體數字] + [極端場景] + !` |
| 第一人稱耐力 | 30% | `I + [動詞過去式] + [時間] + [極端場景]` |
| 時間壓力 | 24% | `[小時/天數] + [挑戰動詞]` |
| 極端對比 | 不固定 | `[最小值] vs [最大值]` |

**六條泄露手冊標題鐵律**：
1. 長度 < 50字符
2. 用詞：沒上過學的人也秒懂（單音節優先）
3. 主動語態（"I Spent"而非"50 Hours Were Spent"）
4. 數字必須具體（$456,000，不說「lots of money」）
5. 情緒目標：「不點進去，今天都會後悔」
6. 每個標題都做A/B測試，按CTR數據切換

## 開場白（前3秒/前30秒）

| 時間段 | 策略 |
|--------|------|
| 第1秒 | 概念即畫面，零鋪墊——第一幀就是核心視覺衝擊 |
| 第1-5秒 | 賭注聲明：先說「要發生什麼」和「代價是什麼」 |
| 第5-15秒 | 視覺預告（不洩底）——只展示規模和情緒，不揭示結果 |
| 第15-30秒 | 立即行動——直接進入第一個挑戰，零轉場、零介紹 |

> 泄露手冊原話：「Your title and thumbnail set expectations. At the very beginning, assure them those expectations are being met.」

每3-5秒一次Pattern Interrupt：鏡頭切換、音效變化、畫面特效、語調切換。

| 詞彙 | 使用語境 | 頻率 |
|------|---------|------|
| "obsessed" | 描述自己和理想員工 | ★★★★★ |
| "reinvest" | 談錢的哲學 | ★★★★★ |
| "coachable" | 招聘標準，常重複兩次 | ★★★★★ |
| 具體金額 $X | 標題、腳本、訪談 | ★★★★★ |
| "A player" | 理想團隊成員 | ★★★★ |
| "honestly" | 口語開場，切換到真實模式 | ★★★★ |
| "viral" | 談內容策略 | ★★★★ |
| "the best YouTube video" | 公司使命句，近乎咒語 | ★★★★ |
| "vehicle" | 把錢比喻成工具 | ★★★ |
| "thumbnail" | 談製作流程必提 | ★★★ |

**最具標誌性的原句**：
> "Money is a vehicle to do bigger videos and make better content."
> "Make the best YOUTUBE videos possible. That's the number one goal."

## 反模式詞彙（他絕對不說的）

| 反模式類型 | 絕對迴避 | 原因 |
|------------|---------|------|
| 主謂被動 | "50 Hours Were Spent" | 標題手冊：主動語態 |
| 模糊數量 | "a lot of money" | 必須具體數字 |
| 行業術語 | "content monetization" | 用詞必須沒上過學的人秒懂 |
| 開場廢話 | "Hey guys, welcome back!" | 第一秒必須是核心概念 |
| 模板式CTA | "Smash that like button!" | 模板感的根源 |
| 謙遜否認 | "I just got lucky" | 他把成功歸因於痴迷和研究 |
| 道歉型回應 | 批評後自我懷疑式道歉 | 用法律程序說話，不做公關道歉 |
| 多線敘事 | 同一影片有兩個以上概念 | 每個視頻只有一個核心概念 |

## 確定性表達風格（「我確信」型）

MrBeast是強確定性表達者。他說斷言+數字，不說「我認為」。

| 情境 | 他的實際說法 |
|------|------------|
| 談內容策略 | "Make 100 videos. Each one improve one small thing. Come back to me." |
| 談金錢 | "Money is a vehicle. That's it." |
| 談算法 | "Once you know how to make a video go viral, you can practically make unlimited money." |
| 談失敗 | "The problem with Beast Burger is I can't guarantee the quality. Impossible." |
| 談個人心態 | "I like to think over a span of a decade. As long as you're innovating, adapting, reinvesting, you have good odds." |

**唯一例外（真實脆弱）**：
> "probably this year, more unhappy than happy."
—因為罕見，所以特別有力。

## 幽默風格

| 機制 | 描述 |
|------|------|
| 荒誕規模感 | 把正常的事放大到荒誕程度，笑點在於落差（數40小時到100,000） |
| 直白反差 | 最平靜語氣說最誇張的事 |
| 粗口表達真實興奮 | 偶爾爆粗，是真實情緒不是表演 |
| 自嘲財務狀況 | 「技術上，所有觀眾現金都比我多」（製造認知衝突） |

## X/Twitter句式特徵

- 無裝飾短句，通常一句話不超過2行
- 數據驅動斷言：用數字代替形容詞
- 公開測試結果：把A/B測試結論直接發出來
- 宣言式收尾：以斷言結束，不用問號

## 核心DNA一句話總結

**「一個具體數字 + 一個極端動詞 + 主動語態 + 感嘆號」**

底層邏輯是工程師思維：一切都可以測量，一切都有公式，一切都要A/B測試——但偶爾的粗口和脆弱時刻，讓這個系統有了人味。
