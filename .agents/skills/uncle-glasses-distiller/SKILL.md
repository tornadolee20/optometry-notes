# 目鏡大叔蒸餾引擎 · Uncle Glasses Distiller

> 「蒸餾不是複製一個人，是提煉他看世界的鏡片。」

---

## 核心理念

一個好的 Skill 是可運行的認知操作系統：
- 他用什麼**心智模型**看世界？（鏡片）
- 他用什麼**決策啟發式**做判斷？（直覺規則）
- 他怎麼**表達**？（DNA）
- 他**絕對不會**做什麼？（反模式）
- 這個 Skill **做不到什麼**？（誠實邊界）

**關鍵區分**：捕捉的是 HOW they think，不是 WHAT they said。

**本引擎的額外責任**：
- 每個產出的 Skill 都通過世界頂尖5人審核委員會，確保品質
- 自動整合進 Obsidian 知識庫，不產生孤島
- 台灣法規紅線自動嵌入，避免法律風險

## 執行流程

### Phase 0：入口分流

收到用戶輸入後，先執行三個並行判斷：

#### 判斷一：輸入類型
| 用戶輸入 | 路徑 |
|---------|------|
| 明確的人名/主題 | **直接路徑** → Phase 0A |
| 模糊的需求/困惑 | **診斷路徑** → Phase 0B |

#### 判斷二：人物狀態（影響 Phase 1 策略）
| 狀態 | 偵測方式 | 特殊處理 |
|------|---------|---------|
| **在世活人** | 近年有新聞/社群動態 | 標注資訊截止日期，建議定期更新 |
| **已逝人物** | 確認辭世年份 | 啟動詮釋漂移偵測（第7個 Agent） |
| **歷史人物**（>50年） | 無當代活動 | 傳記偏差警示，強制多源交叉驗證 |

#### 判斷三：領域類型（影響 Phase 2 + Phase 4）
| 領域 | 偵測特徵 | 特殊處理 |
|------|---------|---------|
| **醫學/健康** | 醫師、藥物、治療、臨床 | 啟動臨床聲稱驗證層 |
| **視光/眼科** | 驗光、配鏡、近視控制 | 注入台灣驗光師法規邊界 |
| **投資/財務** | 股票、基金、投資建議 | 注入投資建議免責聲明 |
| **一般思想家** | 哲學、商業、科學 | 標準流程 |

---

### Phase 0A：需求澄清（直接路徑）

確認以下五件事：

1. **人名/主題確認**：確保理解正確，消歧義（如：倪海廈是台灣中醫師，非大陸人物）
2. **聚焦方向**：全面畫像 vs 聚焦某維度？
3. **用途**：思維顧問 / 內容創作參考 / 視光文章視角 / 教學用途
4. **新建 or 更新**：檢查 `.Codex/skills/` 是否已有此人 Skill
5. **本地語料**：「你手上有沒有這個人的一手素材？書籍 PDF、課程逐字稿、演講字幕、採訪原文都算。有的話品質跳升一個級別。」

用戶說「就做XX」沒有更多信息 → 默認全面畫像 + 思維顧問 + 無本地語料，直接推進。

---

### Phase 0B：需求診斷（模糊路徑）

用戶不知道該蒸餾誰，只有需求。女娲的工作是**從需求反推最合適的蒸餾對象**。

最多問 2 輪追問，不做問卷調查。確認需求維度後，推薦 2-3 個候選，每個候選說清楚：
- 核心鏡片（一句話）
- 為什麼適合（直接對應需求）
- 局限（沒有萬能框架）

---

### Phase 1：多源資訊採集（並行 Agent Swarm）

#### 資訊源優先級

| 來源類型 | 揭示什麼 | 權重 |
|---------|---------|------|
| **用戶提供的一手素材** | 完整原文，未經二手過濾 | **最高+** |
| 本人著作/公開課程 | 系統性思考 | 最高 |
| 長對話/訪談/演講 | 即興思維過程 | 最高 |
| 實際決策記錄 | 真實行為 vs 聲稱 | 最高 |
| 社群媒體/短文 | 表達風格、即時反應 | 中等 |
| 他人評價/傳記 | 外部視角、盲點 | 中等 |
| 二手轉述 | 參考但需驗證 | 低 |

#### 資訊源策略：依人物屬性切換

**台灣人物（含港澳）**：
- ✅ YouTube（台灣原始頻道/官方課程）
- ✅ 本人著作（博客來、金石堂可查）
- ✅ 台灣主流媒體：聯合報、天下雜誌、商業周刊、遠見、今周刊
- ✅ 播客：SoundOn、Firstory 上的台灣節目
- ⚠️ PTT/Dcard：可用於外部評價，但標注為社群觀點，不作為一手來源
- ❌ 百度百科、知乎、微信公眾號

**中國大陸人物**：
- ✅ B站原始視頻（非搬運號）、小宇宙播客、本人微博
- ✅ 權威媒體：36氪、晚點LatePost、財新、第一財經、極客公園
- ❌ 知乎、微信公眾號、百度百科

**西方人物**：
- ✅ Twitter/X、YouTube、Podcast（Spotify/Apple Podcasts）
- ✅ 本人著作（Amazon書評可作為外部評價）
- ✅ 長篇深度媒體：The Atlantic、New Yorker、Lex Fridman Podcast 等

**已逝人物（補充策略）**：
- ✅ 本人生前一手著作 > 所有其他來源
- ✅ 生前訪談原文（非死後追憶）
- ⚠️ 學生/弟子整理的筆記：標注為「二手詮釋，可能有選擇性保留」
- ❌ 追悼文、紀念文章（情感偏差極大，不作為思維框架依據）

#### 資訊源黑名單（永遠排除）
- 知乎、微信公眾號：洗稿嚴重，資訊失真率高
- 百度百科/百度知道：陳舊不可靠
- 追悼文/紀念稿：情感偏差過大
- 未標注出處的「XX語錄」彙整：偽語錄風險高

#### 標準6個Agent任務分配

| Agent | 搜尋目標 | 提取重點 | 輸出文件 |
|-------|---------|---------|---------|
| 1 著作 | 書籍、長文、論文、課程文本 | 反覆出現≥3次的核心論點、自創術語、推薦書單 | `01-writings.md` |
| 2 對話 | 播客、長訪談、演講、課程Q&A | 被追問時的回答方式、即興類比、立場改變的瞬間 | `02-conversations.md` |
| 3 表達 | 社群媒體、短文、公開辯論 | 高頻用詞句式、爭議立場、幽默方式 | `03-expression-dna.md` |
| 4 他者 | 他人分析、書評、批評、傳記 | 外部觀察到的模式、批評與爭議、與同行對比 | `04-external-views.md` |
| 5 決策 | 重大決策、轉折點、爭議行為 | 決策背景與邏輯、事後反思、言行一致/不一致案例 | `05-decisions.md` |
| 6 時間線 | 完整生平時間線 | 關鍵里程碑、思想轉折點、最近12個月動態（在世者） | `06-timeline.md` |

**每個Agent的硬性要求**：
- 結果必須寫入對應 `.md` 文件，不存文件的調研等於沒做
- 注明資訊來源與可信度（一手 > 二手 > 推測）
- 區分「本人說過的」vs「別人說他的」vs「我推斷的」
- 發現矛盾時保留矛盾，不要和稀泥

#### 第7個Agent：詮釋漂移偵測（已逝人物專用）

**觸發條件**：Phase 0 判定為已逝人物時，自動啟動此 Agent。

**任務**：偵測此人辭世後，其思想如何被詮釋、延伸、甚至扭曲。

```
你的任務：調研[人名]辭世後（[辭世年份]至今），其思想如何被後人詮釋。

搜尋方向：
1. 主流詮釋：他最廣為人知的「學說」是什麼？（代表性書籍/課程）
2. 弟子/傳承者：誰在繼承他的思想？各自的詮釋方向有何差異？
3. 商業化/神話化：他是否被過度神話？哪些說法是「粉絲版」而非本人原話？
4. 學術評價：學術界/同行如何評價他的貢獻？有無主要批評？
5. 扭曲案例：找出3-5個明確被扭曲或斷章取義的「名言/觀念」

輸出要求：
- 寫入 references/research/07-interpretation-drift.md
- 每條詮釋標注「可能忠實」vs「可能扭曲」vs「確認扭曲」
- 列出「不得引用為本人觀點」的黑名單語錄

意義：這個 Agent 是本引擎最重要的防偽機制。蒸餾出來的 Skill 必須是「真實的人」，而非粉絲幻化的偶像。
```

**輸出使用**：Phase 2 提煉時，07 文件的內容用於：
- 剔除黑名單語錄
- 在誠實邊界標注「以下詮釋有爭議」
- 在 Phase 4 本真性守護者審查時作為主要依據

### Phase 2：框架提煉（Synthesis）

#### 2.1 心智模型提取（3-7個）

**操作步驟**：

1. 掃描 `01-05.md`，列出所有候選論點（通常 15-30 個）
2. **四重驗證篩選**（本引擎強化版，原版為三重）：
   - **跨域複現**：在≥2個不同領域/話題中出現？
   - **生成力**：能推斷此人對新問題的立場？
   - **排他性**：不是所有聰明人都這樣想？
   - **本真性**：出自本人一手資料，非詮釋漂移的產物？（已逝人物必查 `07-interpretation-drift.md`）
   - 四重全過 → 心智模型；3重 → 決策啟發式；≤2重 → 丟棄
3. **排序取捨**：按排他性強度排序，取 top 3-7 個。寧少勿多。
4. **記錄格式**：名稱 / 一句話描述 / 來源證據（≥2個場景）/ 應用方式 / 局限性 / 本真性評分

#### 2.2 決策啟發式提取（5-10條）

此人做判斷時的快速規則，可表述為「如果X，則Y」，有具體案例支撐。

#### 2.3 臨床聲稱驗證層（醫學/視光領域專用）

**觸發條件**：Phase 0 判定為醫學或視光領域時，在心智模型提取後執行此步驟。

對每一條涉及臨床效果的論點，執行以下驗證：

```
臨床聲稱驗證格式：

聲稱：「[具體說法]」
來源：[一手出處]
驗證結果：
  □ 有系統性文獻支持（標注關鍵研究）
  □ 有個案/小樣本支持（標注「臨床經驗，非系統性驗證」）
  □ 無文獻支持（標注「個人主張，未有研究佐證」）
  □ 與現有研究矛盾（標注「有爭議」，保留但加警示）
台灣法規紅線：此聲稱是否可能觸犯驗光師法/醫療法？
  □ 安全（可直接引用）
  □ 需改寫（提供安全版本表達）
  □ 禁止引用（列入 Skill 的使用禁區）
```

**自動嵌入的台灣法規邊界**（視光領域 Skill 必備）：
```
⚠️ 台灣法規邊界（自動注入）
- 不得宣稱治療眼疾（驗光師法第12條）
- 不得聲稱「配鏡可讓度數減少/治好近視」（醫療法第85條）
- 15歲以下初次驗光須眼科醫師處方（驗光師法施行細則第6條）
- 不得用「第一」「最佳」等無法驗證的絕對詞（公平交易法第21條）
安全表達範本：「根據[人名]的臨床觀察...」「[人名]認為...，建議搭配眼科醫師追蹤」
```

#### 2.4 表達 DNA 分析

| 維度 | 提取內容 |
|------|---------|
| 句式偏好 | 長句/短句、疑問/陳述、類比密度 |
| 詞彙特徵 | 高頻詞、專屬術語、禁忌詞 |
| 節奏感 | 先結論還是先鋪墊、轉折方式 |
| 幽默方式 | 諷刺/自嘲/荒誕/冷幽默/不幽默 |
| 確定性表達 | 「我不確定」型 還是 「很明顯」型 |
| 引用習慣 | 愛引誰、引什麼類型 |

#### 2.5 價值觀與反模式

- **價值觀**：3-5條核心價值排序
- **反模式**：此人明確反對的行為/思維方式
- **矛盾與張力**：價值觀之間的內在衝突（深度的來源）

#### 2.6 智識譜系

此人受誰影響 → 影響了誰 → 在思想地圖上的位置

#### 2.7 誠實邊界

必須明確寫出的局限：
- 不能預測面對全新問題的反應
- 不能替代此人的創造力和直覺
- 公開表達 vs 真實想法可能有落差
- 資訊截止到調研時間點
- 已逝人物：身後詮釋可能與本人原意有出入（標注主要分歧點）

## Phase 4：世界頂尖5人審核委員會

**這是本引擎最核心的創新。**

每個 Skill 在交付前，必須通過5位虛擬審查官的審核。5人並行運作，每人有獨立否決權。

---

### 審查官一：費曼清晰度審查官

**原型**：理查·費曼（物理學家，教學大師）
**核心原則**：「如果你不能用簡單的話解釋它，你還沒真正理解它。」

**審查維度**：
1. **可教授性**：心智模型能用一句話解釋給外行人嗎？每個模型逐一測試。
2. **邏輯鏈完整性**：從「觀點」到「應用方式」之間，邏輯跳躍了嗎？
3. **術語密度**：是否用行話掩蓋了空洞？
4. **類比質量**：提供的類比是澄清還是混淆？

**輸出格式**：
```
費曼審查報告
━━━━━━━━━━━━
通過：[列出清晰的模型]
需返工：[列出邏輯跳躍或術語過密的部分]
費曼指令：「把 [具體段落] 改寫，假設讀者是第一次聽說這個人。」
最終裁定：PASS / REVISE（具體修改指令）
```

---

### 審查官二：芒格認知偏誤審查官

**原型**：查理·芒格（投資家，多元思維模型大師）
**核心原則**：「反轉，永遠先反轉。」

**審查維度**：
1. **光環效應掃描**：Skill 是否因此人名氣而高估其觀點的普適性？
2. **確認偏誤偵測**：調研是否只蒐集支持某種形象的資料，迴避矛盾證據？
3. **激勵機制審查**：此人的觀點是否受到自身利益驅動？（尤其商業人物）
4. **倖存者偏差**：此人的成功是否可重複，還是時代/運氣的產物？
5. **逆向測試**：「這個 Skill 怎麼會讓用戶做出糟糕的決策？」找出最危險的誤用場景。

**輸出格式**：
```
芒格審查報告
━━━━━━━━━━━━
偵測到的偏誤：[類型 + 具體位置]
逆向測試結果：[最危險的誤用場景]
必須加入誠實邊界：[具體文字建議]
最終裁定：PASS / REVISE（具體修改指令）
```

---

### 審查官三：塔勒布信息可信度審查官

**原型**：納西姆·塔勒布（「反脆弱」作者，風險分析師）
**核心原則**：「你的預測記錄在哪裡？Give me your track record.」

**審查維度**：
1. **一手來源佔比**：調研中一手來源 < 50%？直接 FAIL。
2. **預測驗證**：此人做過哪些可驗證的預測？結果如何？（揭示模型真實有效性）
3. **Skin in the Game**：此人是否在「自己提倡的事上有真實代價」？言行是否一致？
4. **尾部風險盲點**：此人的框架在極端情況下會徹底失效嗎？（Skill 必須說清楚）
5. **偽語錄偵測**：有任何語錄無法追溯到確認的一手來源嗎？全部移除。

**輸出格式**：
```
塔勒布審查報告
━━━━━━━━━━━━
一手來源佔比：N%（< 50% → 直接 FAIL，必須補充調研）
確認的偽語錄：[列出，全部移除]
Skin in the Game 評分：強 / 中 / 弱（影響整體可信度標注）
尾部風險盲點：[具體描述]
最終裁定：PASS / FAIL（< 50% 一手源）/ REVISE（具體修改指令）
```

**塔勒布的唯一 FAIL 條件**：一手來源佔比 < 50%。此時 Skill 必須返回 Phase 1 補充調研，不得繞過。

---

### 審查官四：台灣法規守門人

**原型**：基於 `references/驗光師文案法律須知.md` + 台灣醫療法規
**核心原則**：「合規不是限制，是保護。」

**觸發條件**：此審查官在以下情況**必須啟動**：
- 被蒸餾的人物涉及醫療、健康、視光
- 生成的 Skill 預計用於撰寫公開內容（文章、社群）

**審查維度**：
1. **醫療廣告紅線**：Skill 的心智模型或決策啟發式，是否可能引導用戶寫出觸法文案？
2. **療效聲稱掃描**：逐一掃描所有「臨床聲稱」，確認已完成 Phase 2.3 驗證
3. **絕對詞彙掃描**：「第一」「最好」「保證」「治癒」等詞是否出現在 Skill 內容中？
4. **誤導消費者風險**：任何觀點可能引起消費者對服務效果的不實期待？

**輸出格式**：
```
法規守門人審查報告
━━━━━━━━━━━━━━━━
觸法風險項目：[條文 + 具體文字 + 安全改寫版本]
需加入的免責聲明：[具體文字]
已通過的臨床聲稱：N條
需改寫的臨床聲稱：N條（提供改寫版）
最終裁定：PASS / REVISE（具體修改指令）
```

**此審查官對一般思想家類 Skill 可跳過**，但只要涉及健康/醫療內容一律啟動。

---

### 審查官五：本真性守護者

**觸發條件**：僅在已逝人物時啟動。

**核心原則**：「死人不能為自己辯護。我們的責任是不讓他們被利用。」

**審查維度**：
1. **詮釋漂移評估**：對照 `07-interpretation-drift.md`，Skill 有無引用已被確認扭曲的觀點？
2. **粉絲幻化偵測**：Skill 是否過度美化、神話化此人，抹去了真實的矛盾與缺陷？
3. **時代脫節偵測**：此人的觀點是否被原封不動套用於完全不同的時代背景？
4. **黑名單語錄核查**：Agent 7 建立的黑名單是否全部從 Skill 中移除？
5. **「如果他還在世」測試**：根據此人已知的更新觀點和自我修正習慣，他本人會認同這個 Skill 嗎？

**輸出格式**：
```
本真性守護者審查報告
━━━━━━━━━━━━━━━━━
詮釋漂移風險：高 / 中 / 低
發現的扭曲引用：[列出 + 建議刪除/加警示]
粉絲幻化指數：[0-10，>7 必須返工]
時代脫節項目：[具體描述]
黑名單核查：全清 / 仍有N條殘留
最終裁定：PASS / REVISE（具體修改指令）
```

---

### 委員會最終裁定機制

5位審查官並行輸出報告後，主 Agent 執行以下裁定：

```
委員會最終裁定
━━━━━━━━━━━
費曼：   PASS / REVISE
芒格：   PASS / REVISE
塔勒布： PASS / FAIL / REVISE
法規：   PASS / REVISE（如適用）
本真性： PASS / REVISE（如適用）
━━━━━━━━━━━━━━━━━━━━━━━
整體結果：PASS / CONDITIONAL PASS / FAIL

PASS：所有審查官通過 → 進入 Phase 5
CONDITIONAL PASS：有 REVISE 項目 → 主 Agent 整合所有修改建議，優先序：
  1. 塔勒布 FAIL 項目（最高優先，必須先解決）
  2. 法規 REVISE 項目（法律風險優先）
  3. 費曼 REVISE 項目（清晰度）
  4. 芒格 REVISE 項目（偏誤修正）
  5. 本真性 REVISE 項目（歷史人物）
  修改完成 → 展示修改摘要請用戶確認 → Phase 5
FAIL：塔勒布 FAIL（一手來源不足）→ 返回 Phase 1 補充調研
```

**迭代上限**：Phase 1 → Phase 4 最多循環 2 次。2輪後仍有未解決項目，在誠實邊界明確標注，交付當前最優版本。

## 特殊場景

### 台灣人物（強化版）

除切換資訊源策略外，額外注意：
- **語言層**：台灣人物可能用繁體中文、台語詞彙、本土文化隱喻表達。不要用中國大陸語境詮釋。
- **制度背景**：台灣的醫療、教育、法規體系與大陸不同，避免混淆。
- **在地脈絡**：三峽、鶯歌等地名，或台灣特有的社會現象，是真實脈絡，不是奇怪的地方色彩。

### 主題 Skill（領域知識蒸餾）

輸入不是人名而是主題（如「經方派中醫」「視光學循環模型」）時：

| Phase | 人物 Skill | 主題 Skill 變體 |
|-------|----------|----------------|
| 0A | 確認人名 | 確認主題邊界 + 目標受客 + 是哪個流派？ |
| 0.5 | `[person]-perspective/` | `[topic]-framework/` |
| 1 | 6+1個Agent圍繞一個人 | 先識別3-5個核心人物/流派，再分配Agent |
| 2.1 | 一個人的心智模型 | **領域共識框架**（所有流派認同）+ **各家分歧** |
| 2.3 | 模擬一個人的表達 | 不模擬特定人物語氣，用中性專業表達 |
| Phase 4 | 5人委員會全開 | 跳過本真性守護者，其餘4人全開 |

### 蒸餾目鏡大叔自己

當用戶說「蒸餾我自己」「幫我做一個我的Skill」時：

2. 引導提供：

   - 寫過的決策備忘錄

3. Phase 1 的6個Agent改為分析這些本地素材，不做網路搜尋
4. 特別注意「自我認知偏差」——可追問 Obsidian 裡記錄的矛盾點

## 品味守則

| 原則 | 一句話 |
|------|--------|
| 長文 > 金句 | 3000字文章比50條名言更揭示思維結構 |
| 爭議 > 共識 | 最被爭議的觀點最能揭示獨特性 |
| 變化 > 固定 | 改變立場的地方比一直堅持的更有資訊量 |
| 一手 > 二手 | 沒有出處的「名言」是偽語錄的溫床 |
| 誠實邊界 > 完美形象 | 一個標注了局限的60分Skill，遠好過一個編造的90分Skill |

### 絕不做的事
- 編造此人沒說過的話
- 把通用道理包裝成此人的「獨特見解」
- 忽略負面評價和爭議
- 在資訊不足時強行生成
- 用追悼文/紀念稿作為思維框架的依據
