# Lesson-Prep Research Run Brief

Copy this into a new request when starting a full run.

```text
主題：
目標讀者：
使用場景：上課 / 文章 / 社群 / 門市或診所衛教 / AI Skill Factory / 其他
是否需要 Obsidian 歸檔：是 / 否
是否需要目鏡大叔聲紋版：是 / 否，若是，需先完成專業文章評審

請使用 lesson-prep-research-to-brand-article 工作流，產出：
1. 研究問題與搜尋策略
2. PICO / PECO / PICo（若適用）
3. 文獻/來源表，含 DOI/PMID/官方連結
4. 證據等級與解讀限制
5. 事實 / 推論 / 建議 / 未確認事項分離
6. 過度宣稱防火牆
7. 教學轉譯、簡報架構、內容再利用
8. 約 2000 字繁體中文專業文章
9. 專業文章評審
10. 若通過，再做目鏡大叔聲紋版本與聲紋後安全複審
11. 歸檔到 Obsidian 並互相連結
12. 執行 ad-hoc verification
```
