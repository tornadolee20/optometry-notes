# 大衍筮法互動原型：資訊架構與畫面 Flow

## 產品定位

這不是一般抽卡式占卜頁，而是「互動式大衍筮法儀式介面」。

核心目標：

- 讓使用者參與生成，而不是只等待結果
- 保留大衍筮法的節奏感、收束感、層次感
- 同時支援初學者與想要沉浸體驗的人

## 產品模式

### 1. 教學模式

用途：

- 第一次接觸大衍筮法的人
- 想知道每一步名稱與意義的人

特徵：

- 每一步有一句古法提示
- 再補一句白話說明
- 節奏稍慢

### 2. 儀式模式

用途：

- 已知道流程，想保留專注感的人
- 更重視提問、參與、收束的人

特徵：

- 幾乎不說明
- 留下動作、呼吸感、音效與轉場
- 視覺更安靜

## 參與深度

### 1. 手動參與

使用者主動點選：

- 分堆傾向
- 啟動每一變
- 完成下一爻

### 2. 半自動輔助

使用者只做關鍵選擇：

- 問題
- 模式
- 分堆偏向

系統代完成其餘計算與動畫。

### 3. 觀想模式

系統自動演示整個過程，只保留觀看與切換結果。

## 資訊架構

### A. 入口層

- 標題區
- 問題輸入區
- 一問一卦提示
- 開始按鈕

### B. 設定層

- 模式選擇
- 參與深度選擇
- 節奏切換
- 重置與重新起卦

### C. 儀式工作台

- 當前爻位狀態
- 當前變數狀態
- 分堆選項
- 左右兩堆視覺
- 掛一暫存區
- 餘數顯示
- 三變進度

### D. 成卦區

- 六爻自下而上生成
- 老陰、少陽、少陰、老陽標記
- 變爻高亮

### E. 結果區

- 本卦
- 之卦
- 變爻列表
- 卦義提示
- 處境模型
- 行動建議

## 主要畫面 Flow

### Flow 1：起始

1. 使用者進入頁面
2. 看到一句引導：「請先定一問」
3. 輸入問題
4. 點擊「開始起卦」

### Flow 2：選模式

1. 選擇教學模式或儀式模式
2. 選擇手動參與、半自動、觀想
3. 點擊「進入工作台」

### Flow 3：單爻生成

1. 畫面顯示第幾爻
2. 顯示三變進度
3. 使用者點選分堆傾向
4. 系統演示掛一、揲四、歸餘
5. 完成第一變
6. 重複至三變
7. 畫面生成一條爻
8. 進入下一爻

### Flow 4：六爻完成

1. 六條爻全部生成
2. 顯示本卦與變爻位置
3. 點擊「展開卦象」

### Flow 5：本卦到之卦

1. 預設先看本卦
2. 點擊切換顯示之卦
3. 變爻翻轉動畫
4. 顯示變化方向

### Flow 6：結果閱讀

依序顯示：

- 問題
- 起卦方式
- 本卦 / 變爻 / 之卦
- 經文依據
- 白話解讀
- 處境模型
- 行動建議

## 關鍵互動節點

### 1. 分堆選擇

不是讓使用者直接輸入數字，而是點選傾向：

- 偏左
- 均分
- 偏右

這保留參與感，又不會把操作變成算術遊戲。

### 2. 掛一以象三

必須有獨立動畫，因為這是儀式中的標誌性動作。

### 3. 三變成一爻

每完成三變，畫面要有「收筆感」：

- 線條長出
- 輕聲提示
- 爻名浮現

### 4. 變爻翻轉

結果頁上切換本卦與之卦時，應只翻動變爻，不整頁重置。

## 內容結構原則

### 先結構，後解釋

先讓使用者看到：

- 六爻
- 本卦
- 哪些在變

再進入解讀。

### 先經文，後白話

結果區應保留：

- 經文依據
- 白話解讀

兩者要分開，不混成一段心靈雞湯。

### 先處境，後建議

建議應建立在：

- 這是什麼樣的時
- 是否得位
- 問題在進退、失中、過剛、過柔或失時

## 成功體驗指標

使用者離開頁面時，應該感受到：

- 我有參與這個卦的生成
- 我知道剛才不是亂按
- 我看得懂哪一步在做什麼
- 我拿到的不只是吉凶，而是一種判勢與判斷
