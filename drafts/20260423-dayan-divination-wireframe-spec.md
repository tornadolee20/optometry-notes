# 大衍筮法互動原型：Wireframe Spec

## 交付目標

本 spec 給前端或原型實作者使用，描述頁面區塊、狀態、互動與內容層次。

## 視覺方向

- 氣質：古典、克制、安靜、帶紙感與木感
- 背景：暖紙白、墨灰、竹青、淡金
- 不做：宮廟感紫金風、神怪特效風、抽卡 App 風
- 動作：呼吸式、收束式、由下而上生成

## 頁面結構

### Screen 1：入口

區塊：

- 頂部標題
- 內文引導
- 問題輸入框
- 小提醒
- CTA

內容：

- Title：`大衍`
- Subtitle：`請先定一問，再讓數收束為卦。`
- Input placeholder：`例如：這次工作轉向，現在適合主動推進嗎？`
- Helper text：`一問一卦，不宜雜問。`
- Button：`開始起卦`

狀態：

- disabled：問題為空
- focus：輸入框外發光但不刺眼

### Screen 2：模式選擇

區塊：

- 模式卡片列
- 參與深度卡片列
- 節奏設定
- 進入按鈕

卡片：

- 教學模式
- 儀式模式
- 手動參與
- 半自動輔助
- 觀想模式

互動：

- 單選
- 被選中的卡片有內發光與底色轉換

### Screen 3：儀式工作台

採三欄式。

#### 左欄：狀態欄

- 問題摘要
- 起卦方式
- 目前第幾爻
- 當前變數進度
- 簡短提示語

#### 中欄：操作舞台

- 左堆視覺
- 右堆視覺
- 掛一暫存區
- 分堆選項
- 執行動畫區
- 餘數顯示區
- 按鈕列

#### 右欄：成卦預覽

- 六爻容器
- 目前已生成的爻
- 變爻標記
- 本卦 / 之卦切換預留

## 工作台細部元件

### 1. 分堆選項

元件形式：

- 三枚選擇鈕
- 標示：`偏左` `均分` `偏右`

互動：

- 點擊後觸發分堆動畫
- 選擇鈕在該變完成前鎖定

### 2. 左右堆視覺

建議形式：

- 長條堆疊柱
- 或細籤陣列

需求：

- 能視覺區分左右數量差
- 不需要一根根完全寫實
- 可用群組縮放表示數量

### 3. 掛一暫存區

位置：

- 中央上方

效果：

- 被抽出的那一根獨立懸浮
- 淡金或暖白高亮

### 4. 餘數顯示區

顯示內容：

- 左餘
- 右餘
- 本變取數

格式：

- `左餘 3`
- `右餘 4`
- `本變取數 8`

### 5. 三變進度

形式：

- 三段式進度條
- 或三枚節點

狀態：

- 未開始
- 進行中
- 已完成

### 6. 成爻動畫

要求：

- 三變完成後生成一條爻
- 陰爻應為斷線
- 陽爻應為實線
- 老陰、老陽需額外標示

文案：

- `老陰 6`
- `少陽 7`
- `少陰 8`
- `老陽 9`

## 結果頁

### 結果區塊順序

1. 問題
2. 起卦方式
3. 得卦結果
4. 本卦 / 之卦切換
5. 經文依據
6. 白話解讀
7. 處境模型
8. 行動建議

### 本卦 / 之卦切換

互動：

- 分段切換器
- 點擊後只翻動變爻

### 經文依據區

樣式：

- 較收斂
- 類引文排版
- 可搭配小字標註「卦辭」「爻辭」

### 白話解讀區

樣式：

- 較寬鬆
- 行距大
- 適合閱讀

### 處境模型區

樣式：

- 可做成一張高亮卡
- 摘要這一卦的局面

例如：

- 可進，但不可躁進
- 問題不在能力，而在位置未定

## 狀態管理

### 全域狀態

- question
- mode
- participation
- speed
- currentLine
- currentChange
- lineResults
- currentHexagram
- transformedHexagram

### 單爻狀態

- splitBias
- leftPile
- rightPile
- reservedOne
- leftRemainder
- rightRemainder
- changeValue

## 動畫規格

### 節奏建議

- 分堆：500ms
- 掛一：700ms
- 揲四收束：1200ms
- 本變完成：500ms
- 成爻：900ms

### 全卦時長

- 儀式模式：約 2 到 4 分鐘
- 教學模式：約 3 到 5 分鐘
- 可提供加速模式

## 音效規格

- 預設關閉
- 開啟後只使用輕木質、紙感、敲點音
- 每成一爻有一個輕提示

## 響應式策略

### Desktop

- 三欄完整展開

### Tablet

- 左欄折疊為上方狀態卡
- 中欄保留主舞台
- 右欄為浮動預覽

### Mobile

- 分段切換：
  - 狀態
  - 工作台
  - 卦象

避免在小螢幕上同時塞滿三欄。

## MVP 邊界

第一版必做：

- 問題輸入
- 模式選擇
- 三變互動
- 六爻生成
- 本卦 / 之卦切換
- 結果頁

第一版可不做：

- 真正逐根寫實拖曳
- 完整經文資料庫
- 音效素材管理
- 匯出與分享
