# Paper Note Template

## Purpose

Provide a stable Obsidian-ready structure for paper digestion outputs.

This is a template, not the digest skill itself.

## Template

```markdown
---
title: [Paper Title]
date: YYYY-MM-DD
tags: [paper-digest, research, topic]
source: [journal / URL / DOI / PMID]
evidence_level: C1 / C2 / H
maturity: draft
created: YYYY-MM-DD
last_updated: YYYY-MM-DD
card_type: PaperNote
---

# [Paper Title]

## Summary
[2-5 sentence summary in plain language]

## Key Findings
- 
- 
- 

## Limitations
- 
- 

## Practical Implications
- 
- 

## Cautions
- 
- 

## Teaching Analogy
[Optional explanation for easier recall]

## Related Notes
- [[Related Note 1]]
- [[Related Note 2]]
```

## Use Rule

Use this template when the output needs to become:

- an Obsidian paper note
- a reusable research card
- a structured knowledge asset

Do not force every paper digest into this template if the task only needs a quick answer.
