# Google 商家檔案：眼鏡行 × 驗光所 從零開始建立指南

> 建立日期：2026-03-29
> 適用對象：台灣眼鏡行 / 驗光所 / 眼鏡驗光複合店
> 前置文件：`GBP-Google評論經營策略.md`（策略層）
> 本文聚焦：**實際操作步驟，從無到有**

---

## 先看清楚你是誰：兩種店型的根本差異

| 項目 | 眼鏡行（配鏡零售） | 驗光所（醫療服務） |
|------|-------------------|-------------------|
| Google 主要類別 | **Optical goods store** | **Optometrist** |
| 次要類別 | Optician、Contact lenses supplier | Eye care center、Optical goods store |
| Google 對你的定位 | 零售商店 | 醫療院所 |
| EEAT 強調重點 | 商品多樣、價格透明、服務親切 | 執照資格、臨床經驗、學術引用 |
| 驗證要求 | 標準流程 | 可能要求額外醫療文件 |
| 評論關鍵字 | 「款式多」「價格合理」「配速快」 | 「驗光仔細」「解說清楚」「近視控制有效」 |

> **目鏡大叔的情況**：驗光所 + 眼鏡行複合型 → 主要類別用 **Optometrist**，再加 Optical goods store 為次要類別。

## 第一步：建立商家（Google 帳號 → GBP）

### 1.1 前置準備（建立前先備好）

- [ ] Google 帳號（建議用診所/店家專用，勿用個人私人帳號）
- [ ] 店名的正式寫法（例：自己的眼鏡・自己的驗光所）
- [ ] 統一的電話號碼（固定電話優先，與網站/名片一致）
- [ ] 正式地址（含樓層/室號，與統一編號地址一致）
- [ ] 營業時間（含例假日）
- [ ] 網站 URL（若有）

> ⚠️ **關鍵**：從這一刻起，這組「店名 + 地址 + 電話」就是你的 NAP 標準版本，往後所有平台都要用一模一樣的寫法（全形/半形/標點符號都算）。

### 1.2 建立步驟

1. 前往 `business.google.com` → 「管理商家」→「新增商家」
2. 輸入店名（搜尋看有無重複或舊商家）
3. 選擇主要類別（見上表）
4. 輸入地址
5. 輸入電話、網站
6. 進入驗證流程

## 第二步：驗證商家

### 2025-2026 年的驗證現實

**明信片驗證已基本退場**，現在主流是：

| 方式 | 可用機率 | 說明 |
|------|---------|------|
| **影片驗證** | ★★★（最常見，約 80%） | 錄一段 2 分鐘短片，證明你真的在這個地點 |
| 電話簡訊驗證 | ★★ | 若商家電話已在 Google 資料庫 |
| 即時驗證 | ★（最快） | 需先完成 Google Search Console 網站驗證 |

### 影片驗證拍攝重點

影片必須**一鏡到底、不剪輯**，內容要包含：

1. **店外招牌** — 拍攝招牌（要清楚看到店名）
2. **周邊環境** — 帶到街道、門牌號碼（讓 Google 確認地點）
3. **走進店內** — 進門的過程
4. **店內全景** — 帶到收銀台、設備、陳列
5. **設備/執照** — 帶到驗光設備、執照證書（驗光所加強此項）

> 💡 **技巧**：白天光線充足時拍，解析度 1080p 以上，橫拍。台灣門牌要完整入鏡。

### 驗光所的特殊情況

醫療院所偶爾需要上傳：
- 驗光師執業執照
- 診所開業許可文件

準備好 PDF 掃描檔備用。

## 第三步：填寫商家資訊（開幕後的 72 小時衝刺）

驗證通過後，立刻在 72 小時內完成以下欄位，完整度直接影響能否出現在搜尋結果。

### 3.1 基本資訊（必填）

```
商家名稱：      正式名稱，不要加關鍵字（違反政策）
                ✅ 自己的眼鏡・自己的驗光所
                ❌ 三峽最好的驗光師・自己的眼鏡
主要類別：      Optometrist（驗光所）/ Optical goods store（眼鏡行）
次要類別：      Optical goods store、Eye care center、Contact lenses supplier
地址：          完整地址，含樓層
電話：          主要聯絡號碼（與名片一致）
網站：          https://www.uncle-glasses.net/
```

### 3.2 商家描述（150-750 字）

**結構建議：**

```
[第1句] 你是誰 + 在哪裡
[第2-3句] 提供什麼服務（自然帶入 2-3 個關鍵字）
[第4-5句] 為什麼值得信賴（資歷/執照/特色）
[最後1句] 行動呼籲（歡迎預約/電話洽詢）
```

**範例：**
> 自己的眼鏡・自己的驗光所位於新北市三峽區，由執業驗光師李錫彥主持，提供專業兒童近視控制、角膜塑型片配戴評估、老花多焦點鏡片配鏡及一般視力檢查。擁有超過十年臨床視光經驗，並定期赴大學教授視光學課程。店內備有多款鏡架選擇，鶯歌、土城、樹林民眾亦歡迎預約到診。

### 3.3 服務項目（逐一填寫，別偷懶）

```
視力檢查
兒童近視控制
角膜塑型片（OK片）
老花眼配鏡
多焦點鏡片配鏡
散光矯正
隱形眼鏡驗配
眼鏡維修調整
太陽眼鏡配鏡
工作用眼鏡配鏡
```

### 3.4 屬性設定（AI 回答查詢的直接來源）

```
✅ 可預約
✅ 無障礙空間（若有）
✅ 停車場（若有）
✅ 廁所（若有）
✅ 兒童友善
✅ 接受現金
✅ 接受信用卡
✅ 接受行動支付
```

### 3.5 營業時間

- 填寫每日時間，含休息時間
- **務必設定假日特殊時間**（春節/清明/端午/中秋）
- Google 會在假日前提醒你更新，不要忽略

## 第四步：照片建置（開幕後第一個月）

### 優先順序與數量目標

| 照片類型 | 第一個月目標 | 最終目標 | 拍攝重點 |
|---------|------------|---------|---------|
| 外觀（白天） | 3 張 | 5 張 | 招牌清楚、環境整潔 |
| 外觀（夜間） | 1 張 | 2 張 | 燈光明顯 |
| 內部全景 | 3 張 | 10 張 | 乾淨、明亮、展示空間 |
| 驗光設備 | 2 張 | 5 張 | 儀器現代感（信任感） |
| 鏡架陳列 | 5 張 | 20 張 | 整齊、多樣 |
| 驗光師工作照 | 2 張 | 5 張 | 執照/名牌清楚 |
| 團隊照 | 1 張 | 3 張 | 親切、專業 |
| **第一個月合計** | **17 張** | | |

### 照片規格

- 最小尺寸：720 × 720px（建議 1080p 以上）
- 檔案大小：10KB – 5MB
- 格式：JPG 或 PNG
- **禁止**：AI 生成、過度修圖、誤導性畫面

## 第五步：取得前 10 則評論（最難也最關鍵的一關）

### 心態調整

前 10 則評論是最難拿的，因為沒評論 → 沒有社會認同 → 更難有人主動留。
但這關過了，後面滾雪球。

### 實際操作方法

**方法一：QR Code 放置（最有效）**

1. 進入 GBP 後台 → 「取得更多評論」→ 複製評論連結
2. 用 QR Code 產生器（qr-code-generator.com）轉成 QR 碼
3. 印成小卡片或貼紙，放在：
   - 結帳台
   - 等候區桌上
   - 驗光報告袋內
   - 收據背面

**方法二：口頭邀請（自然版）**

```
時機：配鏡取件、驗光報告說明結束時

話術（選一種，不要生硬）：
「如果今天的服務還算滿意，可以幫我們在 Google 留個評論嗎？
 掃這個 QR 碼就可以，對我們小店很有幫助。」

「不好意思，我們是在地小店，如果您覺得還 OK，
 有空的話幫我們在 Google 寫幾個字，我們會很感激！」
```

**方法三：LINE 官方帳號訊息（適合回頭客）**

```
訊息範例：
「[店名] 感謝您昨天的光臨！
 如果您對這次的驗光/配鏡服務滿意，
 歡迎在 Google 留下評論，讓更多有需要的人找到我們 🙏
 評論連結：[短連結]」
```

> ⚠️ **Google 政策底線**：可以邀請，**不能給任何好處換評論**（折扣/贈品/回扣都算違規）。

### 前 10 則評論的現實時程

| 里程碑 | 預計時間 | 排名效果 |
|--------|---------|---------|
| 0 → 1 則 | 第 1-2 週 | GBP 開始被索引 |
| 1 → 5 則 | 第 1 個月 | 在地圖上開始出現 |
| 5 → 10 則 | 第 2-3 個月 | 明顯排名跳升 |
| 10 → 30 則 | 第 4-6 個月 | 進入競爭 |
| 30 → 50 則 | 第 7-12 個月 | 基本門檻達成 |

## 第六步：設定每週發文節奏

### 貼文類型與模板

**A. 衛教小知識（週一）**
```
圖片：眼睛圖示 or 相關照片
文字：[問題]：[1-2句回答]
       想了解更多？歡迎預約到診，或查看我們的部落格。
       📞 電話 | 📍 地址
```

**B. 診所動態（週三）**
```
圖片：設備/環境/活動照
文字：[動態描述]
       — 自己的眼鏡・自己的驗光所 #三峽 #驗光
```

**C. 一問一答（週五）**
```
圖片：Q&A 設計圖
文字：Q：[家長/顧客常問的問題]
       A：[2-3句直接回答]
       有相同疑問？歡迎來電或預約 📞
```

## 第七步：建立評論回覆模板庫

### 正面評論回覆（3 版本輪替使用）

**版本 A（強調服務）：**
> 謝謝您的評論！很高興這次的[服務/驗光/配鏡]讓您滿意。如有任何後續問題，歡迎隨時聯絡，我們在三峽等您回來 🙏

**版本 B（強調專業）：**
> 非常感謝！每一位顧客對我們來說都很重要，期望能持續為您和家人提供專業的視光服務。有任何視力問題，歡迎預約 📞

**版本 C（帶入關鍵字）：**
> 謝謝您特地留下評論！兒童近視控制（/角膜塑型/老花配鏡）是我們最重視的服務之一，若未來有需要，歡迎再回來找我們。

### 負面評論回覆（流程）

```
① 感謝 + 道歉（不辯解）
② 說明你看到這個問題了
③ 邀請私下聯繫解決
④ 禁止出現病患個資

範例：
「感謝您的回饋，很遺憾這次的體驗讓您不滿意。
 我們已將您的意見記錄下來，歡迎透過電話 [號碼] 直接聯繫，
 讓我們有機會為您處理。謝謝您的指教。」
```

## 常見錯誤（新手必看）

| 錯誤 | 後果 | 正確做法 |
|------|------|---------|
| 店名加關鍵字 | GBP 被停權 | 只用正式店名 |
| NAP 各平台不同 | AI 無法建立實體關聯 | 統一版本先定好再登錄 |
| 驗證後不更新資訊 | 在地圖上「看起來」存在但搜不到 | 驗證後 72 小時衝刺填資料 |
| 求評論給折扣 | 評論被刪 + 可能被懲罰 | 只誠懇邀請，不給回報 |
| 負評不回覆 | 97% 潛在顧客看到會卻步 | 24-72 小時內必回 |
| 相片數量不足 | 低於 10 張視同「不完整」 | 開幕就衝 17 張以上 |
| 建好就放著 | 30 天不更新，可見度自動衰退 | 至少每週一則貼文 |
