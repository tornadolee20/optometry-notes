## §1 Google 評論：數字與策略

### 1.1 評論是排名第二大因子

2025-2026 年最新研究：評論佔 Google 在地搜尋排名因子的 **20%**（2023 年為 16%，持續上升）。
排名第一是 GBP 完整度（品類 + 屬性 + 地點），第二才是評論。

### 1.2 關鍵門檻數字

| 指標 | 建議目標 |
|------|---------|
| 總數 | ≥ 50 則（競爭基本門檻）；頂端業者約 200-250 則 |
| 星等 | ≥ 4.0（才出現在「最佳」查詢）；目標 4.5+ |
| 速度（velocity） | 醫療/高競爭：每週 1-4 則；現實目標：**每月 2-4 則** |
| 新鮮度 | 30 天內的評論有 ~15% 加成；停止 3 週後排名明顯下滑 |
| 最低觸發點 | 累積到 10 則時有明顯排名跳升（案例研究證實） |

> **核心邏輯**：Google 看的是「評論的生命力」，200 則停滯的舊評，輸給每月新增 20 則的 50 則店家。

### 1.3 回覆策略（直接影響排名）

- 回覆率 ≥ 80% → 排名加分 **10-20%**
- 回覆率 100% → 轉換率提升 **16.4%**；營收相關性 **+18%**
- 97% 的消費者會讀業者回覆
- 負評回覆黃金時間：**24-72 小時內**（最晚 7 天）
- 44.6% 的顧客：看到業者專業回應負評後，仍願意光顧

**回覆原則：**
- 負評：道歉 → 具體回應問題 → 邀請私下聯繫 → 絕不防禦性辯解
- 正評：選擇性回覆（不必每則），但回覆時**帶入服務關鍵字**（如「近視控制」「角膜塑型片」），讓 AI 理解你的專業
- 禁忌：絕不在回覆中出現病患個資（台灣法規 + Google 政策雙重禁止）

### 1.4 假評論的風險（2025 嚴格執法）

Google Gemini AI 在 2024-2025 年大規模部署假評偵測：
- 偵測率：**75% 的假評在上線前即被擋下**
- 2025 年 4 月起刪除率翻倍，7 月達高峰（每週刪除）
- **「評論監獄」懲罰**：被判定買假評的商家，**6-8 個月內無法收到任何新評論**
- 已在美英印上線「疑似假評論」標籤（2025 年 5 月起擴展至全球）

**底線**：在三峽這種在地市場，真實口碑遠比買評更可靠。

## §2 Google 商家檔案（GBP）優化

### 2.1 欄位重要性排序

| 優先級 | 欄位 | 說明 |
|--------|------|------|
| ★★★ | **主要類別** | 最關鍵。台灣建議：「驗光師」或「眼鏡行」擇一為主，另一為副 |
| ★★★ | **屬性** | AI 搜尋答案的直接來源：預約制/無障礙/停車/兒童友善 |
| ★★★ | **相片** | 100 張以上：多 42% 路線導航請求、35% 網站點擊 |
| ★★ | **服務項目** | 詳列：近視控制/角膜塑型/兒童視力/配鏡/散光矯正 |
| ★★ | **評論與回覆** | 見 §1 |
| ★★ | **貼文（Posts）** | 每週至少一則；7 天後失效，需持續發 |
| ★ | **Q&A** | 自問自答！建立常見問題庫（看診費用、預約方式、兒童適用年齡） |
| ★ | **商家描述** | 150-750 字，自然帶入三峽/鶯歌/北大特區 + 核心服務 |

### 2.2 照片策略

| 類型 | 目的 | 建議數量 |
|------|------|---------|
| 外觀（日間/夜間） | 讓顧客認得門面 | 5-10 張 |
| 內部環境 | 降低初次來訪焦慮 | 10-15 張 |
| 驗光師工作照 | EEAT 專業信任感 | 5-10 張 |
| 設備儀器 | 展示專業能力 | 5-10 張 |
| 眼鏡商品陳列 | 商品多樣性 | 10-20 張 |
| 顧客（已取得同意） | 社會認同 | 5 張 |
| 團隊合照 | 人情味 | 3-5 張 |

**規格**：最小 720×720px，10KB-5MB，不得使用 AI 生成照片（Google 政策風險）

### 2.3 每週貼文節奏（建議排程）

```
週一：衛教小知識（配合部落格文章摘要）
週三：診所動態 / 新設備 / 活動
週五：「本週一問」—— 模擬家長常見問題，自問自答
（可彈性，但每 7 天至少一則）
```

**貼文不得超過 1500 字；加上行動呼籲（預約/電話）效果最佳。**

### 2.4 Q&A 自問自答題庫（建議先建）

```
Q: 兒童幾歲可以開始驗光？
Q: 角膜塑型片（OK片）適合幾歲的孩子？
Q: 需要預約嗎？可以走進來嗎？
Q: 停車方便嗎？
Q: 健保有給付驗光費用嗎？
Q: 配鏡後多久可以取件？
Q: 有賣哪些品牌的鏡架？
```

## §3 AI 時代的 EEAT 優化

### 3.1 三大 AI 引擎的推薦邏輯

根據 6.8M+ 引用數據分析（2025-2026）：

| AI 引擎 | 主要依賴來源 | 對你的含義 |
|---------|------------|-----------|
| **Gemini** | 品牌自有網站（52%）+ GBP | 網站結構化資料（Schema）要完整 |
| **ChatGPT** | 第三方目錄（49%）+ Yelp 類平台 | 台灣在地目錄 + iNEWS / 痞客邦曝光 |
| **Perplexity** | 產業專業目錄 + 評論 | 醫療相關討論串、PTT 眼鏡版提及 |

**結論**：三個引擎同時覆蓋，需要「自有 + 第三方 + 社群」三管齊下。

### 3.2 AI 時代 EEAT 四層實作

| 層次 | 定義 | 驗光所實作方式 |
|------|------|--------------|
| **Experience（親身經驗）** | 你有沒有親自做過？ | 診所案例、臨床觀察（匿名化）、門診故事 |
| **Expertise（專業知識）** | 你懂不懂？ | 國際論文引用、PMID 標注、元培/學會頭銜 |
| **Authoritativeness（權威性）** | 別人說你懂嗎？ | 媒體引用、學會職位、被其他網站連結 |
| **Trustworthiness（可信度）** | 你可以信賴嗎？ | HTTPS、驗光師執照顯示、真實地址電話、免責聲明 |

> 醫療類別（YMYL）EEAT 標準最嚴格，2025 年演算法更新後，不達標的診所網頁平均流失 **15% 搜尋曝光**。

### 3.3 Entity 優化：讓 Google 認識「目鏡大叔」這個實體

Google 的知識圖譜把每個真實存在的事物定義為「實體（Entity）」。你的目標是讓 Google 把「目鏡大叔李錫彥 = 三峽/鶯歌驗光權威」這個關聯固化。

**實體信號清單：**
- [ ] 網站加入 `LocalBusiness` + `MedicalBusiness` Schema
- [ ] 網站加入 `Person` Schema（李錫彥的完整資料）
- [ ] NAP（名稱/地址/電話）在所有平台**完全一致**（含全形/半形差異）
- [ ] GBP 商家名稱 = 網站名稱 = 發票抬頭（完全一致）
- [ ] 在台灣在地目錄登錄（見 §3.4）

### 3.4 台灣在地引用平台清單（NAP 一致性）

**優先處理（對 Google 影響大）：**
- Google 商家檔案（GBP）← 已有，持續優化
- 104 黃頁
- 台灣 Yahoo 在地（Yahoo 奇摩地圖）
- Yelp Taiwan
- Apple Maps（透過 Apple Business Connect 申請）

**醫療/健康類：**
- 台灣醫事查詢系統（衛福部官方）
- 各縣市驗光師公會官網名錄
- FindDoc / 醫院 101

**社群/口碑類（間接影響 ChatGPT）：**
- PTT Glasses 板被提及
- Mobile01 眼鏡版討論串
- Dcard 地區板

### 3.5 AI Overviews 出現機率

- 2025 年 4 月數據：**40.2% 的搜尋查詢**出現 AI 概覽
- 關鍵差異：AI 概覽不像傳統地圖包強調「距離」——**品質信號比距離更重要**
- 這對三峽這種非市中心的位置是**大利多**：只要 EEAT 夠強，不怕被台北市診所壓制

## §4 行動優先順序

### 第一階段（立即，1 個月內）

- [ ] GBP 相片補到 100 張以上（分類：外觀/內部/設備/團隊）
- [ ] 建立 Q&A 自問自答題庫（至少 7 題）
- [ ] 確認 NAP 在網站 + GBP + Line 官方帳號完全一致
- [ ] 設定每週固定一則 GBP 貼文（可連動部落格）
- [ ] 建立評論邀請 SOP（看診結束時如何自然引導）

### 第二階段（1-3 個月）

- [ ] 網站加入 `LocalBusiness` + `MedicalBusiness` + `Person` Schema
- [ ] 在台灣主要在地目錄登錄（104黃頁、Apple Maps、Yahoo在地）
- [ ] 申請/完善衛福部醫事查詢資料
- [ ] 建立評論回覆模板庫（正評 × 3 版本、負評 × 2 版本）

### 第三階段（3-12 個月）

- [ ] 每季進行一次 NAP 一致性稽核
- [ ] 目標評論速度：每月 2-4 則新評論
- [ ] 在 PTT/Mobile01 建立自然口碑（不買廣告，提供真實解答）
- [ ] 追蹤 AI 概覽（Google AI Overviews）中的在地推薦是否出現診所名稱

## §5 常見地雷

| 地雷 | 後果 |
|------|------|
| 買假評 | 「評論監獄」6-8 個月無法收新評 |
| GBP 商家名稱加入關鍵字（「三峽最好的驗光師」）| 違反政策，可能暫停 GBP |
| 在評論回覆中提及病患病情 | 違反個資法，可能遭申訴 |
| NAP 各平台不一致 | AI 引擎無法建立實體關聯，排名受損 |
| 貼文超過 1 個月不更新 | 可見度自動衰退 |
| AI 生成照片上傳 GBP | 可能被系統偵測移除 |
