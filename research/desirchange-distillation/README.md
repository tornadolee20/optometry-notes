# Desirchange 蒸餾索引

這一包不是單純的網站摘要，而是把 `desirchange.com` 的文章群整理成可直接複用的寫作系統。

## 檔案

- `desirchange-writing-system.md`
  主系統。整理這個網站最核心的寫作邏輯、文章流程與說服方式。

- `desirchange-article-archetypes.md`
  文章原型地圖。拆成幾種常見文章類型，方便之後直接套用。

- `desirchange-title-formulas.md`
  標題公式庫。抽出高頻標題結構與可改寫模板。

- `desirchange-style-dna.md`
  文風 DNA。整理段落節奏、開頭方式、句型習慣、收尾做法與不該盲學的部分。

- `desirchange-for-uncle-glasses.md`
  轉譯版。把 Desirchange 的優勢轉成適合叔系內容、視光衛教、門市信任寫作的操作版本。

- `desirchange-uncle-glasses-template-pack.md`
  第 2 層實戰模板。直接給文章骨架、開頭示範、收尾示範。

- `desirchange-uncle-glasses-title-batch.md`
  叔系標題批次。可直接拿去當選題池。

- `desirchange-uncle-glasses-prompt.md`
  可複用 prompt。把蒸餾結果變成穩定可調用的寫作指令。

## 使用順序

1. 先讀 `desirchange-writing-system.md`
2. 再看 `desirchange-article-archetypes.md`
3. 寫標題時搭配 `desirchange-title-formulas.md`
4. 寫內文時對照 `desirchange-style-dna.md`
5. 真正要落地到叔系內容時，用 `desirchange-for-uncle-glasses.md`
6. 要直接開寫時，用 `desirchange-uncle-glasses-template-pack.md`
7. 要快速出題時，看 `desirchange-uncle-glasses-title-batch.md`
8. 要交給模型穩定生成時，用 `desirchange-uncle-glasses-prompt.md`

## 判讀提醒

這份蒸餾故意聚焦在「可移植的方法」而不是全文模仿。

要學的是：

- 怎麼讓人願意看下去
- 怎麼把抽象概念翻成具體感受
- 怎麼把教學寫得不枯燥
- 怎麼把商業導向藏進閱讀體驗裡

不要直接照抄的是：

- 每篇都硬掛品牌尾註
- 過度 SEO 化的關鍵字堆疊
- 不必要的編號感
- 缺少第一手案例時仍假裝自己很懂
