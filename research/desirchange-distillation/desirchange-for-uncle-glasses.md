# Desirchange for Uncle Glasses

## 先講結論

Desirchange 最值得你借的，不是它那種電商文案口氣，而是這 3 個能力：

1. 把抽象專業翻成白話
2. 先理解人，再講方案
3. 把文章寫成「信任階梯」

對叔系內容來說，這非常有用。

## 你最該拿來用的部分

### 1. 教學文的拆解力

這很適合用在：

- 漸進多焦點怎麼選
- 兒童近視控制有哪些方案
- 老花眼鏡、閱讀眼鏡、漸進鏡片怎麼分
- 為什麼明明有配鏡，還是看不舒服

適合套用的骨架：

1. 先說讀者最常卡在哪
2. 再分幾種類型
3. 每種類型講適合對象
4. 優勢與限制都講
5. 最後給判斷建議

### 2. 場景寫法

這很適合用在：

- 長輩看近看遠的生活困擾
- 家長看孩子用眼行為
- 客人第一次戴多焦點的適應期
- 門市驗配時的焦慮與猶豫

叔系版本不要寫太滿，可以更克制：

- 少一點過度抒情
- 多一點生活真實感
- 多一點照護語氣

### 3. 品牌理念寫法

這很適合放在：

- 關於我們
- 為什麼我們重視驗配流程
- 為什麼不是每個人都適合同一種鏡片
- 為什麼你不想做只會推銷的門市

## 你不要直接照抄的部分

### 1. 過度 SEO 尾註

叔系內容如果每篇都拖一長串品牌尾註，會破壞信任感。

### 2. 太像電商老師的語氣

叔系內容更適合：

- 穩
- 真
- 有照顧感
- 有臨床與生活之間的橋接感

### 3. 沒證據卻很肯定

視光內容跟電商不同，不能靠順口就下判斷。

涉及效果、風險、適應、兒童控制時，要特別注意：

- 不誇大
- 不亂保證
- 不偷換概念
- 不用假數據

## 最適合叔系的 4 種轉譯模板

## 模板 1：選擇型教學文

適合主題：

- 漸進鏡片 vs 兩副眼鏡
- 控制近視方案怎麼選

骨架：

1. 你可能正在猶豫什麼
2. 常見有哪幾種選法
3. 每種適合誰
4. 每種常見誤解
5. 我會怎麼建議你判斷

## 模板 2：痛點翻譯文

適合主題：

- 為什麼度數明明沒差很多，還是覺得不舒服
- 為什麼長輩常說眼鏡有了卻不想戴

骨架：

1. 說出讀者的挫折
2. 翻譯背後真正原因
3. 說明常見誤會
4. 提出比較合理的理解方式

## 模板 3：場景信任文

適合主題：

- 孩子第一次做近視控制
- 長輩第一次配多焦點

骨架：

1. 先寫真實場景
2. 點出焦慮點
3. 說明這件事不是誰的錯
4. 提出照顧式建議

## 模板 4：品牌立場文

適合主題：

- 為什麼我們重視追蹤
- 為什麼不是越貴越好
- 為什麼你要先理解生活需求再決定鏡片

骨架：

1. 我們看見什麼問題
2. 我們為什麼不想用某種做法
3. 我們更相信什麼
4. 這對客人有什麼差別

## 叔系版文風守則

如果把 Desirchange 轉成 Uncle Glasses 版本，我會這樣定義：

- 少一點「行銷感」
- 多一點「陪你釐清」
- 少一點「衝動行動」
- 多一點「安心做選擇」
- 少一點「我很會」
- 多一點「我知道你在怕什麼」

## 可以直接套的句子方向

- 很多人不是不知道要不要配，而是不知道自己真正需要的是哪一種。
- 問題通常不在你不夠認真，而在於前面沒有人幫你把差異講清楚。
- 如果你最近也正在猶豫，不妨先把自己放進這幾種情況裡看。
- 先別急著選最貴的，先選最適合你生活的。

## 一句話最終轉譯

Desirchange 幫你看到的是：

`把專業內容寫成讓人願意相信、願意理解、也願意採取下一步的文字。`

叔系版本要做的是：

`把這套力量，從電商文案改造成高信任的視光溝通。`
