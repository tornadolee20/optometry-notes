# Desirchange -> Uncle Glasses 實戰模板包

## 使用原則

這包模板不是讓你「寫得像 Desirchange」，而是讓你借用它最有用的能力：

- 先寫人，再寫方案
- 先幫讀者分類，再幫讀者判斷
- 先用生活語言降低門檻，再補專業解釋

## 模板 1：選擇型教學文

### 適合主題

- 漸進多焦點 vs 兩副眼鏡
- 兒童近視控制方案怎麼選
- 散光高的人鏡片怎麼挑

### 標題模板

- `一直猶豫要選 [A] 還是 [B]？先看你是哪一種情況`
- `[主題] 怎麼選？不是越貴越好，先看需求再決定`
- `[身份] 最常卡的 [主題] 問題：這 3 種情況其實差很多`

### 文章骨架

1. 你可能正在猶豫什麼
2. 大多數人的問題不是不知道選什麼，而是不知道差別在哪
3. 先把常見情況分成 3 類
4. 每一類各自的適合對象
5. 每一類的優勢與限制
6. 最容易誤判的地方
7. 我會怎麼建議你判斷

### 開頭示範

很多人不是沒有做功課，而是資料看得越多越亂。

像 `[主題]` 這件事，網路上常常講得像是只要選最貴、最新、最多人推的就對了。但真正影響你戴起來舒不舒服、用起來順不順的，通常不是那個「名字」，而是你的生活情境。

如果你最近也正在猶豫，不妨先把自己放進下面這幾種情況裡看。

### 收尾示範

先別急著問哪一個最好，先問哪一個比較像你現在的生活。

選對，不一定是一步到位；很多時候，是先選到現在最合適的版本，再慢慢調整。

## 模板 2：痛點翻譯文

### 適合主題

- 為什麼明明有配眼鏡，還是看不舒服
- 為什麼長輩總說眼鏡戴不住
- 為什麼孩子近視控制做了，還是讓家長不安心

### 標題模板

- `為什麼你的 [問題] 明明已經 [努力]，結果還是 [挫折]？`
- `不是你不認真，是你把 [表面問題] 當成了真正問題`
- `很多人卡住的，其實不是 [A]，而是 [B]`

### 文章骨架

1. 先說出讀者的挫折
2. 拆掉常見誤會
3. 說明真正原因通常在哪
4. 用生活場景解釋
5. 提出更合理的判斷方式
6. 最後給一個安心版本的下一步

### 開頭示範

你可能也有過這種感覺：

明明眼鏡配了、錢也花了、該做的都做了，結果生活裡還是一直覺得哪裡不對。

這種時候，最讓人累的不是不舒服本身，而是你會開始懷疑，到底是自己太挑，還是真的哪裡沒處理好。

## 模板 3：場景信任文

### 適合主題

- 長輩第一次戴多焦點
- 家長第一次帶孩子做近視控制
- 第一次驗配硬式或特殊鏡片

### 標題模板

- `第一次面對 [主題]，很多人擔心的其實不是同一件事`
- `當 [角色] 第一次遇到 [情境]，最需要的通常不是被說服`
- `[情境] 會不安，很正常`

### 文章骨架

1. 寫一個真實場景
2. 點出角色在怕什麼
3. 把情緒正常化
4. 解釋為什麼會這樣
5. 提供溫和而具體的建議
6. 收在陪伴感而不是推銷感

### 開頭示範

很多家長第一次聽到 `[主題]`，第一個反應不是「要不要做」，而是「我是不是太晚了」。

那種焦慮很真實。因為你知道孩子的狀況不能不管，但又怕自己做錯選擇，反而讓事情更複雜。

這篇不是要你立刻做決定，而是先幫你把那份混亂釐清。

## 模板 4：品牌立場文

### 適合主題

- 為什麼我們不會一開始就推薦最貴的鏡片
- 為什麼我們重視追蹤勝過一次配到位
- 為什麼驗光不是只看度數

### 標題模板

- `為什麼我們在 [主題] 上，通常不會先給最快的答案`
- `不是每個人都需要同一種 [方案]`
- `我們更在意的，不是你配了什麼，而是你最後有沒有真的用得好`

### 文章骨架

1. 我們看見一個常見問題
2. 為什麼這種做法會出事
3. 我們更相信什麼
4. 這樣做對客人的差別是什麼
5. 用一個生活例子收尾

## 模板 5：知識白話文

### 適合主題

- 散光到底是什麼
- 為什麼老花不是突然發生
- 什麼是視覺疲勞

### 標題模板

- `[主題] 是什麼？用白話講，你其實每天都遇得到`
- `很多人聽過 [主題]，但真正困擾你的通常是這件事`
- `把 [專業詞] 講成人話：它跟你的生活到底有什麼關係`

### 文章骨架

1. 先從生活感受開始
2. 再引出專業概念
3. 不急著下定義，先說影響
4. 補一個簡潔解釋
5. 告訴讀者何時該留意

## 模板 6：服務說明文

### 適合主題

- 驗光流程介紹
- 兒童近視控制追蹤流程
- 漸進鏡片試戴與調整流程

### 標題模板

- `如果你是第一次做 [服務]，大概會經歷這幾個步驟`
- `很多人以為 [服務] 很複雜，其實流程大致是這樣`
- `[服務] 在做什麼？先帶你看一次流程`

### 文章骨架

1. 先降低不安
2. 逐步說明流程
3. 每一步在看什麼
4. 為什麼不能跳步
5. 哪些感受是正常的
6. 結尾強調目的不是流程本身，而是讓生活更順

## 通用收尾模板

- 先不用急著做最完美的決定，先做一個更清楚的決定。
- 真正重要的不是你今天記住多少名詞，而是你有沒有比較知道自己在選什麼。
- 如果這篇剛好講到你最近的困擾，希望它至少先幫你把問題看得更清楚一點。
