# Desirchange -> Uncle Glasses Prompt

把下面這段當成寫作提示詞使用。用途不是模仿措辭，而是穩定調出「先理解人，再拆解問題，再給溫和可行建議」的文章結構。

## Prompt

你現在要替 Uncle Glasses 寫一篇文章。

請借用這套寫法：

- 先寫讀者當下的困擾或猶豫，不要一開始就講大道理
- 把模糊問題拆成幾種常見情況，幫讀者找到自己在哪一類
- 用白話解釋，不要用過重的術語堆疊
- 盡量用生活情境、真實感受、常見誤會來說明
- 如果有方案比較，請同時講優勢與限制，不要只講好處
- 結尾要幫讀者收斂，而不是只停在資訊堆疊

但請保持 Uncle Glasses 的版本，不要變成電商行銷口氣。

語氣要求：

- 穩定
- 有照顧感
- 有專業，但不壓人
- 像在陪讀者一起看清楚，而不是在推銷

請避免：

- 過度誇大
- 沒根據的保證
- 過度 SEO 感標題
- 冗長品牌尾註
- 太模板化的行銷腔

文章請包含：

1. 一個能讓目標讀者立刻代入的開場
2. 明確的小標結構
3. 2-4 個最關鍵的拆解段落
4. 一段重點整理
5. 一個溫和、不強推的收尾

如果主題涉及配鏡、兒童近視控制、視覺不適、老花、多焦點、功能型鏡片，請特別注意：

- 不要把個別情況講成放諸四海皆準
- 要承認不同人適合的方案不同
- 要把「生活需求」放進判斷裡

## 可直接替換的輸入欄位

- 主題：
- 目標讀者：
- 想解決的核心問題：
- 想帶出的品牌立場：
- 文章類型：
  - 選擇型教學文
  - 痛點翻譯文
  - 場景信任文
  - 品牌立場文
  - 知識白話文
  - 服務流程文

## 最短指令版

請用「Desirchange 的結構力 + Uncle Glasses 的信任感」寫這篇文章：

- 先同理讀者
- 再拆解問題
- 再給具體但不武斷的建議
- 不要寫成推銷文
