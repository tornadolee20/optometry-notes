# Desirchange 文章原型地圖

## 1. 教學拆解型

### 目標

把一個看起來很麻煩的商業問題，拆成可以理解、可以比較、可以行動的內容。

### 常見標題特徵

- 問題句
- 數字
- 新手 / 必學 / 必讀 / 懶人包
- `A vs B`
- `3 種 / 5 個 / 一次搞懂`

### 內文骨架

1. 先講讀者的困惑
2. 定義今天要拆的選項
3. 每個選項分別講
4. 適合對象
5. 優點
6. 缺點
7. 重點整理
8. 延伸閱讀

### 功能

- 建立專業
- 累積搜尋流量
- 降低詢問門檻
- 篩選適合的客戶

## 2. 文案範例型

### 目標

展示「我們會寫」，但不是直接炫技，而是透過情境與氛圍讓人感受到文字質地。

### 常見標題特徵

- `產業文案 | 一句情境鉤子`
- `品牌 / 空間 / 房地產 / 藝術`
- 情感或畫面導向，而不是知識導向

### 內文骨架

1. 一句濃縮主題
2. 以人生階段、場景、時段切入
3. 描寫情緒與空間
4. 再轉向設計、配置、特色
5. 收在品牌價值或文案說明

### 功能

- 展示風格能力
- 提升品牌美感定位
- 讓潛在客戶看到「如果是我的品牌，也可以這樣被寫」

## 3. 產品利益型

### 目標

把產品從「功能清單」改寫成「對不同人有什麼好處」。

### 常見標題特徵

- `產品文案 | 提供好處`
- `服務文案`
- `測驗文案`
- 聚焦一個具體痛點與利益

### 內文骨架

1. 指出痛點
2. 同理讀者當下狀態
3. 說明產品怎麼解決
4. 給證據或保證
5. 補優惠
6. CTA

### 功能

- 寫銷售頁
- 寫一頁式
- 幫產品找到不同受眾切角

## 4. 品牌理念 / 公司介紹型

### 目標

建立信任，說明品牌為什麼存在、在乎什麼、和誰站在一起。

### 常見標題特徵

- `品牌故事`
- `品牌理念`
- `公司理念`
- `關於我們`

### 內文骨架

1. 為什麼開始
2. 想解決什麼問題
3. 對誰有感
4. 相信什麼
5. 希望帶來什麼改變

### 功能

- 幫陌生訪客快速建立好感
- 替品牌找價值觀同盟
- 替後續轉單打底

## 5. 網站 / 電商策略型

### 目標

幫正在做品牌或做官網的人做方向判斷。

### 常見標題特徵

- 平台、官網、SEO、品牌曝光、電商
- `怎麼選`
- `為什麼`
- `低成本`
- `新手`

### 內文骨架

1. 先描述常見情境
2. 拆方法或路線
3. 分析差異
4. 說明適用階段
5. 提出建議組合

### 功能

- 把服務做成前置顧問內容
- 讓讀者先被教育，再願意詢問

## 6. 標題 / 文案技巧教學型

### 目標

把文案這件事從神祕的創意能力，拆成可學的結構和套路。

### 常見標題特徵

- `如何寫`
- `怎麼寫`
- `標題`
- `文案技巧`
- `案例拆解`

### 內文骨架

1. 丟出問題
2. 說明核心原理
3. 用範例拆解
4. 分情境應用
5. 重點整理

### 功能

- 讓品牌被視為老師型專家
- 建立長期內容權威

## 最值得優先複製的 3 個原型

1. `教學拆解型`
   最容易變成長期流量與信任資產。

2. `產品利益型`
   最容易直接連到商業轉換。

3. `品牌理念 / 公司介紹型`
   最適合高信任決策情境。

## 不同原型的閱讀心情

- 教學拆解型：我想搞懂
- 文案範例型：我想感受
- 產品利益型：我想判斷值不值得
- 品牌理念型：我想知道你是誰
- 網站策略型：我想知道怎麼選
- 文案技巧型：我想學會怎麼做
