# 固視視差分析 (Fixation Disparity: Ogle's Curves)

**核心學者：** Ogle, Sheedy, Saladin, Mallett

## 1. 什麼是固視視差 (Fixation Disparity, FD)？
在視光學的「最後一哩路」中，傳統的隱斜視 (Phoria) 測量存在一個致命缺點：**隱斜視是在「打破雙眼視覺 (Dissociated)」的狀態下測量的**（例如遮蓋法或 Maddox 桿）。這並不反映病患在真實世界、雙眼睜開看東西時的狀態。

**「固視視差 (FD)」則是在「維持雙眼融合 (Associated)」的狀態下測量的微小眼位偏差（通常小於 10 弧分）。** 
它測量的是大腦在真實用眼狀態下，肌肉控制的「殘留誤差」。測量 FD 所需的稜鏡量，稱為「聯動性隱斜 (Associated Phoria)」，這通常是**開立處方稜鏡最精準的指標**。

## 2. Ogle 的四大固視視差曲線 (Ogle's 4 Curve Types)
透過儀器 (如 Sheedy Disparometer 或 Saladin Card)，我們在病患眼前不斷加入 BO 與 BI 稜鏡，並畫出固視視差的變化曲線。這條曲線的形狀，直接決定了病患的命運（是否會眼疲勞、該給訓練還是給稜鏡）。

### Type I 曲線 (正常 S 型 / 佔 60%)
*   **圖形：** S 型曲線，中間（零稜鏡區）非常平緩，兩端陡峭。
*   **臨床意義：** 這是**最健康**的視覺系統。平緩的中心代表病患對外界的視覺壓力有極強的「適應力 (Vergence Adaptation)」。
*   **處置：** Type I 的人很少有症狀。若有症狀，他們對 **視覺訓練 (Vision Therapy)** 的反應極佳。

### Type II 曲線 (內斜視傾向型)
*   **圖形：** 曲線下半部（外斜/BI區）平坦，但一遇到 BO 稜鏡就直接直線上升，沒有 S 型的下半部。
*   **臨床意義：** 常見於**內隱斜 (Esophoria)** 患者。他們的神經系統對「向外放鬆」毫無適應能力。
*   **處置：** Type II 患者通常非常痛苦且伴隨頭痛。他們對視覺訓練反應較差，**首選處置是給予 BO 稜鏡 或 加入正鏡片 (+ Add)** 來緩解神經張力。

### Type III 曲線 (外斜視傾向型)
*   **圖形：** Type II 的反轉。曲線遇到 BI 稜鏡就直線下降。
*   **臨床意義：** 常見於高度**外隱斜 (Exophoria)** 患者，無法適應向內聚合的壓力。
*   **處置：** 雖然可給 BI 稜鏡，但這類患者如果配合視覺訓練，預後通常比 Type II 好。

### Type IV 曲線 (不穩定/平坦型)
*   **圖形：** 幾乎是一條平線，無論加 BI 還是 BO，固視視差幾乎不變。
*   **臨床意義：** 這是極為罕見且異常的系統。代表大腦與眼球肌肉已經「放棄」了微調，通常伴隨間歇性斜視、弱視或極度不穩定的雙眼狀態。
*   **處置：** 患者症狀嚴重，處理難度極高，常需要轉介神經視光或眼科手術評估。

## 3. 臨床結論
Sheedy 的研究指出，決定病患是否頭痛/視疲勞的最關鍵因素不是隱斜視度數大小，而是 **FD 曲線的「斜率 (Slope)」**。
斜率越陡，代表大腦的適應力越差、越容易疲勞。這補足了單純「21 點分析」或「圖形分析法」中無法窺見的大腦融合動態變化。
