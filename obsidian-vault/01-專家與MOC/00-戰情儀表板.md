# 🛡️ 戰情儀表板 Dashboard
*大叔，早安！這裡是您的第二大腦戰情中心。*

---

> [!important] 🔴 砲火填裝區：草稿與內容部隊 (Content Pipeline)
> 列出 `content-planning` 資料夾下，最近 14 天內修改過且帶有 `#草稿` 標籤的文章。
> 看看有哪些彈藥準備好可以發布了！
```dataview
TABLE 
  date AS "排定期程",
  file.mtime AS "最後修改"
FROM "07-長篇專欄與企劃" AND (#草稿 OR #企劃)
SORT file.mtime DESC
LIMIT 10
```

---

> [!warning] 🟡 戰略專屬區：活躍專案與企劃 (Active Projects)
> 列出 `projects` 目錄下，您目前正在推動的案子。
> 這裡會自動計算檔案內勾選的 checkbox `[x]` 佔全部 `[ ]` 的比例，變成進度條！
```dataview
TABLE WITHOUT ID
  link(file.link, title) AS "專案名稱",
  "<progress value='" + (length(filter(file.tasks.completed, (t) => t = true)) / length(file.tasks)) * 100 + "' max='100'></progress>" + " " + round((length(filter(file.tasks.completed, (t) => t = true)) / length(file.tasks)) * 100) + "%" AS "執行進度",
  file.mtime AS "最後更新"
FROM "08-視力保健手冊推廣計畫"
WHERE length(file.tasks) > 0
SORT file.mtime DESC
LIMIT 10
```

---

> [!success] 🟢 智庫補給區：最新知識卡片 (Recent Knowledge)

TABLE
