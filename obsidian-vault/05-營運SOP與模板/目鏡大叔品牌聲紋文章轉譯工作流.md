# 目鏡大叔品牌聲紋文章轉譯工作流

> 用途：將已通過 validated 的嚴謹專業文章，轉譯成更像目鏡大叔本人會寫的品牌文章。  
> 核心原則：**專業不能被文風改壞，聲紋不能凌駕證據。**

---

## 1. 輸入

```yaml
source_article: [[專業嚴謹版文章]]
review_report: [[文章評審報告]]
voiceprint_card: [[目鏡大叔文字聲紋卡]]
target_reader: 家長 / 驗光師 / 一般消費者 / 學生
publish_channel: 部落格 / 社群 / 講義 / 官網 / 短影音腳本
```

---

## 2. 前置條件

文章必須先符合：

- [ ] 已完成文獻搜尋與來源註記。
- [ ] 已通過過度宣稱防火牆。
- [ ] 已有專業評審團評分。
- [ ] review_status 至少為 `validated`。
- [ ] 若為醫療 / 驗光 / 視覺健康主題，需保留風險提醒。

---

## 3. 轉譯流程

### Step 1：抽出不可改壞的專業骨架

保留：

- 核心事實
- DOI / PMID / 來源註記
- 不保證語氣
- 風險提醒
- 轉介 / 專業評估提醒
- 事實、推論、建議的界線

### Step 2：套入目鏡大叔聲紋

依 [[目鏡大叔文字聲紋卡]] 轉換：

- 加入真實場景或顧客一句話開場。
- 先接住焦慮，再給專業解釋。
- 使用「不是 A，而是 B」句型。
- 使用煞車、教練、港口、光學輔助等比喻。
- 加入「大叔小提醒」或「大叔筆記」。
- 結尾自然回到「先聊聊 / 先檢查 / 帶資料來一起看」。

### Step 3：刪除 AI 感

避免：

- 「此外、總結來說、值得注意的是」連續堆疊。
- 過度條列。
- 像論文摘要。
- 像銷售頁。
- 空泛的「重要、關鍵、核心」但沒有具體場景。

### Step 4：聲紋後安全複審

檢查：

| 檢查項 | 通過 | 備註 |
|---|---|---|
| 是否保留主要來源 |  |  |
| 是否保留「不保證」語氣 |  |  |
| 是否避免零副作用 / 所有人適用 |  |  |
| 是否仍符合專業倫理 |  |  |
| 是否比原文更像目鏡大叔 |  |  |
| 是否有讀者情境與情緒承接 |  |  |
| 是否有白話比喻 |  |  |
| 是否可以重新送專業評審團 |  |  |

---

## 4. 輸出格式

請產出：

1. 目鏡大叔品牌版文章
2. 修改對照表
3. 保留的證據與風險句
4. 新增的聲紋元素
5. 聲紋後安全複審結果
6. 是否建議送回專業評審團再審
