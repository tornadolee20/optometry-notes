# 自主研究任務模板：備課前研究版

這份模板用於「備課前」啟動 AI 自主研究。目的不是只拿到摘要，而是先把主題整理成可教學、可社群化、可產品化、可收進 AI Skill Factory 的材料。

---

之後可以直接對 AI 說：

> 用「目鏡大叔版自主研究任務模板」，幫我研究：＿＿＿

## 7. 文獻搜尋與證據分級要求

如果主題涉及驗光、眼科、近視控制、雙眼視、老花、鏡片設計、視覺訓練、AI、教育、SEO/GEO 或零售策略，請主動加入文獻搜尋與證據分級。

### 優先搜尋的文獻類型

請優先找：

1. Systematic review
2. Meta-analysis
3. Clinical guideline
4. Consensus statement
5. Randomized controlled trial, RCT
6. Large cohort study
7. Professional association statement
8. 官方文件、白皮書或技術文件

### 文獻整理表

請用表格輸出核心文獻：

| 文獻 / 來源 | 作者 / 機構與年份 | 研究類型 | DOI / 連結 | 一句話結論 | 對備課的用途 | 證據強度 | 小心解釋 |
|---|---|---|---|---|---|---|---|

### 證據強度標記

請用以下方式標記：

- **高**：systematic review、meta-analysis、高品質 guideline、多個 RCT 一致支持
- **中**：單一 RCT、良好 cohort study、專業共識、較穩定的產業資料
- **低**：case report、專家意見、小型研究、未重複驗證的初步結果
- **趨勢判斷**：目前資料不足，但從多個跡象推論可能發展

### 文獻轉譯要求

請另外整理：

1. 這些文獻共同支持什麼？
2. 哪些地方仍有爭議？
3. 哪些內容適合放進簡報？
4. 哪些內容適合講給學生聽？
5. 哪些內容適合講給家長 / 消費者聽？
6. 哪些內容需要避免過度宣稱？
7. 哪些內容可以變成課堂討論題？

## 8. 產出格式

請用以下格式輸出研究結果。

### A. 一頁式總結

- 這個主題是什麼？
- 為什麼現在重要？
- 對目標聽眾有什麼關係？
- 最值得教的 3–5 個重點

### B. 主題架構圖

請整理成分層架構：

```text
主題
├── 核心概念
├── 背景脈絡
├── 重要技術 / 知識
├── 實務應用
├── 案例
├── 風險與限制
└── 教學切入點
```

### C. 重點整理表

請用表格整理：

| 面向 | 重點 | 說明 | 可教學角度 | 備註 |
|---|---|---|---|---|

### D. 關鍵名詞表

請整理：

| 名詞 | 白話解釋 | 專業解釋 | 教學比喻 |
|---|---|---|---|

### E. 案例整理

請整理 3–5 個案例：

| 案例 | 背景 | 做法 | 成果 | 可用於教學的重點 |
|---|---|---|---|---|

### F. 備課建議

請根據研究結果，提出：

1. 適合的課程標題
2. 適合的課程目標
3. 適合的課程大綱
4. 哪些地方適合用故事講
5. 哪些地方適合用圖解
6. 哪些地方適合設計互動問題
7. 哪些地方可能需要提醒學生不要誤解

### G. 事實、推論、建議分離

請清楚分成：

#### 事實

有資料來源支持的內容。

#### 推論

根據資料合理推導，但不一定已被完全證實。

#### 建議

根據研究結果，給我的教學 / 商業 / 內容策略建議。

### H. 來源列表

請列出主要參考來源，並簡短說明每個來源的價值。

### I. Obsidian 收納規則

請把研究結果拆成適合 Obsidian 長期累積的筆記資產，而不是只輸出一份一次性報告。

請建議可拆成：

| 筆記類型 | 建議標題 | 內容重點 | 建議資料夾 | 可連結到哪些筆記 |
|---|---|---|---|---|
| MOC 主題索引 |  | 主題總覽、導航、延伸閱讀 | 00-索引 / MOC |  |
| 核心知識卡片 |  | 一個概念一張卡 | 04-知識卡片 |  |
| 文獻卡片 |  | DOI、研究設計、結論、限制 | Evidence / 文獻卡 |  |
| 教學卡片 |  | 課堂講法、比喻、互動問題 | 05-營運SOP與模板 / 教學 |  |
| 案例卡片 |  | 情境、做法、教學重點 | 案例庫 |  |
| 社群素材卡 |  | 貼文、短影音、標題鉤子 | 內容素材庫 |  |
| AI Skill Factory 候選模組 |  | skill / workflow / template / prompt | AI Skill Factory |  |
