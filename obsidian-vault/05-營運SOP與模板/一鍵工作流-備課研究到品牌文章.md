# 一鍵工作流：備課研究到品牌文章

這份 SOP 是把已實測打通的「自主研究 → 備課 → 專業文章 → 評審 → 目鏡大叔聲紋 → 安全複審 → Obsidian 歸檔」流程，整理成之後可以重複呼叫的工作流入口。

對應 Hermes Skill：

```text
lesson-prep-research-to-brand-article
```

> 使用方式：之後只要給主題，請 Hermes 載入這個 skill，並依照本 SOP 輸出完整資產包。

---

## 1. 啟動指令

```text
請使用 lesson-prep-research-to-brand-article 工作流，針對「<主題>」產出：
1. 研究問題與搜尋策略
2. PICO / PECO / PICo（若適用）
3. 文獻/來源表，含 DOI/PMID/官方連結
4. 證據等級與解讀限制
5. 事實 / 推論 / 建議 / 未確認事項分離
6. 過度宣稱防火牆
7. 教學轉譯、簡報架構、內容再利用
8. 約 2000 字繁體中文專業文章
9. 專業文章評審
10. 若通過，再做目鏡大叔聲紋版本與聲紋後安全複審
11. 歸檔到 Obsidian 並互相連結
12. 執行 ad-hoc verification
```

---

## 2. 輸入欄位

| 欄位 | 說明 | 範例 |
|---|---|---|
| 主題 | 要研究與備課的核心題目 | 兒童近視控制、AI 驗光所內容策略 |
| 目標讀者 | 學生、家長、患者、門市人員、專業人士 | 家長與驗光學生 |
| 使用場景 | 上課、文章、社群、衛教、內訓、商品化 | 課堂與品牌文章 |
| 風險等級 | 健康/醫療、商業、AI、一般教育 | 健康/醫療高風險 |
| 是否聲紋轉譯 | 是否要做目鏡大叔品牌版 | 是，但需先通過專業評審 |
| 是否歸檔 | 是否寫入 Obsidian 第二大腦 | 是 |

## 4. 品質閘門

### 4.1 研究品質

- 至少有 3–5 個研究問題。
- 有搜尋策略：中英文關鍵字、排除詞、平台、納入/排除標準。
- 健康/臨床題目需使用 PICO / PECO / PICo。
- 專業或醫療主張需有 DOI / PMID / 官方連結，找不到時要明確標註。

### 4.2 證據與安全

- 分離事實、推論、建議、未確認事項。
- 明確標示 High / Medium / Low / Trend judgment。
- 必須有過度宣稱防火牆。
- 不可把低風險寫成零風險。
- 不可把平均效果寫成保證有效。
- 不可把 AI 或工具寫成取代專業判斷。

### 4.3 文章與發布

- 專業文章需約 2000 個中文字。
- 需保留來源註記與風險限制。
- publish-ready 之前必須通過專業文章評審。
- 聲紋轉譯後必須做聲紋後安全複審。
