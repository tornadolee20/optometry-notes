# 專業文章評審團評分機制模板

> 用途：所有由「自主研究任務模板」產出的專業文章，在進入 publish-ready 或 flagship 之前，都必須經過本評審團機制。  
> 原則：文章不是寫完就算完成，而是通過證據、實務、風險、教學、讀者、品牌與 SEO/GEO 多角度審查後，才成為高品質第二大腦資產。

---

## 1. 適用範圍

適用於：

- 驗光 / 眼科 / 視覺健康專業文章
- 家長衛教文章
- 教學講義文章
- SEO / GEO pillar article
- AI Skill Factory 可產品化內容
- 任何可能對外發布、上課使用或轉成顧問素材的長文

---

## 2. 評審團角色

| 評審角色 | 主要任務 | 分數欄位 |
|---|---|---|
| 文獻證據評審 | 檢查來源品質、DOI/PMID、研究類型、引用是否支撐主張 | evidence_score |
| 臨床 / 驗光實務評審 | 檢查臨床合理性、台灣實務、轉介、禁忌與安全界線 | clinical_score |
| 過度宣稱與風險評審 | 檢查保證有效、零副作用、所有人適用、AI 取代專業等紅旗 | overclaiming_score |
| 教學設計評審 | 檢查文章是否能轉成課程、講義、互動問題與學習路徑 | teaching_score |
| 讀者理解評審 | 檢查一般讀者是否看得懂，專有名詞是否有轉譯 | clarity_score |
| 品牌與信任感評審 | 檢查是否符合目鏡大叔：專業、白話、有信任感、不廉價行銷 | brand_score |
| SEO / GEO 資產評審 | 檢查標題、語意實體、搜尋意圖、FAQ 潛力、可拆解性 | seo_geo_score |

---

## 3. 權重

| 面向 | 權重 |
|---|---:|
| 文獻證據品質 | 20% |
| 臨床 / 驗光實務合理性 | 20% |
| 過度宣稱安全性 | 20% |
| 教學價值 | 10% |
| 讀者理解度 | 10% |
| 品牌信任感 | 10% |
| SEO / GEO 資產價值 | 10% |

加權公式：

```text
weighted_score =
  evidence_score * 0.20
+ clinical_score * 0.20
+ overclaiming_score * 0.20
+ teaching_score * 0.10
+ clarity_score * 0.10
+ brand_score * 0.10
+ seo_geo_score * 0.10
```

---

## 4. 通過等級

| 等級 | 條件 | 用途 |
|---|---|---|
| draft | 總分 < 75 | 只能內部存放，不可公開 |
| reviewed | 總分 75–84 | 可內部備課，不建議正式發布 |
| validated | 總分 85–91，且 overclaiming_score ≥ 90，evidence_score ≥ 80 | 可作為高品質第二大腦資產與課程基礎 |
| publish-ready | 總分 ≥ 92，且 overclaiming_score ≥ 95，evidence_score ≥ 85，clinical_score ≥ 85 | 可發布部落格、講義、品牌內容 |
| flagship | 總分 ≥ 95，且所有關鍵項目 ≥ 90 | 可作為品牌代表作、pillar content、付費產品核心素材 |

---

## 5. Red Flag Gate：硬性退回條款

只要出現以下任一項，文章不得通過 publish-ready：

- [ ] 沒有主要來源。
- [ ] 缺 DOI / PMID / 官方來源，且主張屬於專業或醫療健康範圍。
- [ ] 把初步研究講成定論。
- [ ] 把產品效果講成保證。
- [ ] 把藥物、治療或介入講成所有人適用。
- [ ] 把低風險講成零風險。
- [ ] 把 AI 講成可取代專業判斷。
- [ ] 未區分事實、推論、建議。
- [ ] 涉及醫療或健康決策但沒有風險提醒。
- [ ] 引用來源與文章主張不相符。
- [ ] 文章整體像廣告，而不是專業衛教。
