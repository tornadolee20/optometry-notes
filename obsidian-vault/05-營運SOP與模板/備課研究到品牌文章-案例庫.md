# 備課研究到品牌文章：案例庫

這份案例庫是用來保存每一次「備課研究到品牌文章」工作流的真實執行結果。  
目的不是多存一份流水帳，而是讓系統越跑越準：知道哪些輸入有效、哪些輸出有價值、哪裡容易踩雷、哪些段落可以複用、哪些案例值得商品化。

對應 Hermes Skill：

```text
lesson-prep-research-to-brand-article
```

---

## 1. 案例庫要保存什麼

每一個案例至少保存：

- 主題與 slug
- 主題輸入表
- 使用模式：minimal / brand / complete
- 產出資產連結
- 驗證結果
- 踩雷點
- 修正方式
- 可複用段落 / 表格 / prompt
- 可商品化程度
- 下一步

---

## 2. 案例檔名規則

案例紀錄放在：

```text
05-營運SOP與模板/case-library/
```

檔名：

```text
YYYY-MM-DD-<slug>-案例紀錄.md
```

範例：

```text
05-營運SOP與模板/case-library/2026-07-08-兒童散瞳驗光與家長溝通-案例紀錄.md
```

---

## 3. 案例狀態

| 狀態 | 說明 |
|---|---|
| sandbox | 人工測試或流程測試，不是真實內容案例 |
| draft | 真實案例已開始，但尚未完整驗證 |
| validated | 已通過必要驗證 |
| publish-ready | 已通過文章評審與安全閘門 |
| archived | 保留參考，不再主動維護 |

---

## 7. 使用時機

每次完成以下任一情況，就應建立案例紀錄：

- 完成一個真實主題研究。
- 完成一篇專業文章與評審。
- 完成一篇目鏡大叔聲紋版。
- 發現重要踩雷點。
- 產出可重用模板 / 表格 / prompt。
- 發現可商品化素材。
- 做完 sandbox / dry-run 測試且值得保存。
