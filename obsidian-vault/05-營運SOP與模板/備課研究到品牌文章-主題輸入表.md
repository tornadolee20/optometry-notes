# 備課研究到品牌文章：主題輸入表

這份輸入表是為了讓每次啟動「備課研究到品牌文章」工作流時，不要只丟一句模糊主題，而是先把最重要的決策欄位固定下來。

白話講：  
**輸入越清楚，後面的研究、文章、評審、聲紋與歸檔就越穩。**

對應 Hermes Skill：

```text
lesson-prep-research-to-brand-article
```

---

## 1. 最小必填欄位

| 欄位 | 說明 | 範例 |
|---|---|---|
| topic | 主題原文 | 兒童散瞳驗光與家長溝通 |
| slug | 檔名用主題 slug | 兒童散瞳驗光與家長溝通 |
| target_audience | 主要讀者 | 家長、驗光學生、門市人員 |
| primary_use_case | 主要用途 | 上課、專業文章、社群內容、門市衛教 |
| output_depth | 產出深度 | minimal / brand / complete |
| risk_level | 風險等級 | low / medium / high |

---

## 2. 研究範圍欄位

```yaml
research_scope:
  domain:
    - optometry
    - eyewear-retail
    - clinical-education
    - AI-workflow
    - SEO/GEO
    - business-operation
  geographic_context: Taiwan | global | mixed | null
  needs_literature_search: true
  preferred_sources:
    - PubMed
    - Cochrane
    - clinical guideline
    - professional association
    - official documentation
  must_include_doi_pmid: true
  time_range: last 5 years preferred, older landmark sources allowed
  framing_method: auto | PICO | PECO | PICo | none
```

## 3. 內容輸出欄位

```yaml
content_outputs:
  research_run_note: true
  moc: false
  evidence_map: false
  overclaiming_firewall: true
  teaching_card: false
  professional_article_2000_zh: true
  article_review_report: true
  brand_voice_article: false
  post_voiceprint_safety_review: false
  seo_geo_assets: false
  social_content_breakdown: false
```

### 建議對應

| output_depth | 建議輸出 |
|---|---|
| minimal | 研究工作流筆記、專業文章草稿、文章評審報告 |
| brand | 目鏡大叔品牌版、聲紋後安全複審 |
| complete | MOC、證據地圖、過度宣稱防火牆、教學卡、文章、評審、品牌版、安全複審 |

---

## 4. 文章偏好欄位

```yaml
article_preferences:
  tone: professional, plainspoken, Traditional Chinese, Taiwan usage
  reader_level: educated layperson | professional | student | mixed
  brand_voice: none | 目鏡大叔
  must_avoid:
    - 保證有效
    - 零風險
    - 人人適用
    - AI/工具取代專業判斷
  required_caveats:
    - 證據限制
    - 個體差異
    - 專業評估
    - 轉診/醫師評估邊界 when relevant
```

---

## 5. 商業化與 Skill Factory 欄位

```yaml
commercialization:
  reusable_asset_type: skill | workflow | template | prompt | example | case-library | none
  commercial_value: low | medium | high | unknown
  maintenance_cost: low | medium | high | unknown
  public_publish_candidate: false
```

用途：

- 判斷這次產出是不是值得變成案例庫。
- 判斷是否可包裝成課程、模板、顧問素材。
- 判斷後續維護成本。

---

## 6. 執行欄位

```yaml
execution:
  create_asset_pack_first: true
  run_validation_after_creation: true
  save_to_obsidian: true
  dry_run_first: true
  overwrite_existing_files: false
```

安全原則：

- 預設先 dry-run。
- 預設不覆蓋既有檔案。
- 不確定欄位填 `null`，不要腦補。
- 醫療/視光題目預設 high 或 medium risk，不可亂降風險。
