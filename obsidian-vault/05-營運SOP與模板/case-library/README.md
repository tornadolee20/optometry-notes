# 備課研究到品牌文章案例庫

這個資料夾保存 `lesson-prep-research-to-brand-article` 工作流的案例紀錄。

檔名格式：

```text
YYYY-MM-DD-<slug>-案例紀錄.md
```

案例狀態：

```text
sandbox | draft | validated | publish-ready | archived
```

每個案例至少應包含：

- Input snapshot
- Asset pack links
- Verification result
- What worked
- Failure points / fixes
- Reusable materials
- Commercialization potential
- Next actions
