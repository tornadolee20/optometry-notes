# 雙眼機能分析三層整合教學框架

> 為什麼驗光師在學校努力學了雙眼視覺，卻在診間幾乎不用它？
> 問題不是知識不足，而是缺乏一張**整合地圖**。

---

## 核心診斷：三道牆

| 牆 | 問題 | 解法 |
|----|------|------|
| 記憶牆 | Morgan norms、Sheard、Percival 各自孤立 | 三層架構統一記憶節點 |
| 邏輯牆 | 測了數值，不知下一步往哪走 | 決策樹 + 8分鐘篩查流程 |
| 解釋牆 | 患者聽不懂術語 | 白話比喻話術（見下） |

---

## 三層整合架構（雙眼機能分析樹）

```
雙眼視覺症狀
│
├─ 🔵 系統一：聚散系統（Vergence）
│   ├─ 斜位（遠距 / 近距）
│   ├─ 融像儲備（BI / BO Break & Recovery）
│   ├─ Sheard's Criterion：BO ≥ 2 × 外斜量
│   ├─ Percival's Criterion：小儲備 ≥ 大儲備 / 2
│   └─ NPC（近點集合）
│
├─ 🟡 系統二：調節系統（Accommodation）
│   ├─ AA（調節幅度）— Hofstetter 均值 = 18.5 − 0.3 × 年齡
│   ├─ NRA / PRA — 鬆弛上限 / 施力上限
│   ├─ MEM（動態視網膜鏡）— 當下調節位置
│   └─ Flipper（調節靈活度）— 12 cpm 正常
│
└─ 🔴 系統三：雙眼協調（Binocular Coordination）
    ├─ AC/A 比（Gradient 法：正常 3/1 ~ 5/1）
    └─ 決定處置方向（稜鏡 vs 訓練 vs ADD）
```

> **關鍵原則**：三個系統彼此制衡，改動一個，另兩個都會變。

---

## Morgan Norms 速查

| 測試 | 正常均值 | 異常閾值 |
|------|---------|---------|
| 遠距斜位 | 正位 ± 2Δ | > 5Δ exo 或 > 2Δ eso |
| 近距斜位 | 6Δ exo ± 3Δ | > 9Δ exo 或任何 eso |
| 近距 BO Break | 21 ± 6Δ | < 15Δ |
| 近距 BI Break | 21 ± 4Δ | < 12Δ |
| NPC（破裂） | ≤ 5cm（< 40歲） | > 7cm |
| NRA | +2.00 ± 0.50D | < +1.50D |
| PRA | −2.37 ± 1.00D | > −1.50D |
| MEM | +0.25 ~ +0.75D | < 0D 或 > +1.00D |
| Flipper | 12 ± 5 cpm | < 8 cpm |

---

## 三大異常模式快速識別

### 🔴 集合不足（Convergence Insufficiency）
- 近距外斜 > 9Δ（遠距正常）
- NPC > 5cm（三次平均）
- BO Break < 15Δ
- CISS ≥ 21 分
- 處置：**視覺訓練優先**（Pencil Push-up、Brock String）

### 🟡 調節不足（Accommodative Insufficiency）
- AA 低於 Hofstetter 均值 ≥ 2D
- MEM > +1.00D（調節落後）
- PRA < −1.50D
- Flipper < 8 cpm
- 處置：**調節訓練** + 排除系統性疾病

### 🔵 基本外斜（Basic Exophoria）
- 遠近斜位相近（均為外斜）
- 需計算 Sheard / Percival
- 儲備足 → 觀察；不足 → 稜鏡或訓練

---

## 8 分鐘臨床篩查流程

```
1. CISS 問卷（候診填 QR code）——2 分鐘
   ≥ 21 分 → 進入完整評估

2. 遠近斜位——1 分鐘
   > 9Δ exo near → 加測 NPC

3. NPC × 3 次取後兩次——1 分鐘
   > 5cm → 高度懷疑 CI

4. 近距 BO Break——2 分鐘
   < 15Δ → Sheard 計算

5. NRA / PRA——2 分鐘
   PRA < −1.50D → 調節不足懷疑
```
