# 📖 TL;DR
這是一份由貝克菜撰寫的 OpenClaw (龍蝦) 深度安裝指引，核心觀點在於：**AI 的強大不只在於模型，更在於「環境配置」與「記憶架構」。** 透過 Discord 的多頻道機制實現多 Agent 協作與專案記憶隔離，並強調餵食大量個人/公司數據以達到真正的「去 AI 感」與「深度了解」。

# 📊 數據亮點與高精度事實 (Layer 1)

### 1. 核心安裝指令
- **Claude CLI**: `sudo curl -fsSL https://claude.ai/install.sh | bash`
- **OpenClaw**: `sudo curl -fsSL https://openclaw.ai/install.sh | bash`
- **權限開啟**: 修改 `.openclaw/openclaw.json` 中的 `"tools": { "profile": "full" }` 以開啟完整工具權限。

### 2. Discord Bot 必要設定
- 必須開啟 **Server Members Intent** 與 **Message Content Intent**。
- Bot 權限建議設定為 **Administrator** 以確保工具調用順暢。

### 3. 多 Agent 協作模型配置 (貝克菜推薦)
- **主腦 (思考/決策)**: Claude Opus
- **手腳 (程式/設計)**: Claude Sonnet 或 Gemini Nano
- **品管 (測試)**: Claude Sonnet
- **節奏**: 你 -> 主腦 -> 手腳 (實作) -> 品管 (測試) -> 通過則回報。

# ⚠️ 盲區與衝突處理 (Layer 2)

### 1. 記憶碎片的處置
- **問題**: AI 的輸入方式是將 Session 內所有內容上傳，雜亂的對話會稀釋 Context。
- **解決方案**: 每個專案建立獨立的 Discord 頻道，並為其設立專屬記憶檔。這利用了 Discord 的物理結構來強制進行「視覺化記憶隔離」。

### 2. 數據餵食的重要性
- 通過餵食 15 年份的 Facebook 數據 (8GB) 或公司官網/素材，解決 AI 「不了解你」的問題。AI 的聰明取決於它對你個人脈絡的掌握厚度。

# 💡 大叔風格插件 (7 大思考框架)

### 1. 核心模型 (Core Model)
- **「指揮官-作業員-稽核員」模型**：主腦不直接動手，而是負責分派任務。開發者不需要精通程式，只需要精通「流程設計」與「品管標準」。

### 2. 祖母測試 (Grandmother Test)
- **比喻**: 就像請了一群外籍實習生來辦公室，主腦是那個英文最好、最聰明的領頭羊。你只需要在 Discord 特定的辦公桌（頻道）放一張這份專案的說明書（記憶檔），他們就不會把別區的公事搞混。

### 3. 靈魂拷問 (Soul Question)
- 如果 AI 已經擁有了你 15 年的記憶、能幫你自動掃描海內外動態、還能分身成程式與設計，**那麼你原本「因為怕累、怕麻煩、怕學不完」而擱置的那個億元級企劃，現在為什麼還不動手？**
