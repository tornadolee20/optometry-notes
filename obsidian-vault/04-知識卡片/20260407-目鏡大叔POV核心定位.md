# 📖 目鏡大叔核心 POV 定位

## 🧠 核心 POV Statement

> **「驗光師是視力健康最被低估的專家——我要讓大眾看見這件事，也讓同行活得更好。」**

用更白話說：驗光師比大多數人以為的更懂你的眼睛，但沒人幫他們說清楚。目鏡大叔要做兩件事：對外教育大眾，對內幫同行用系統賺到應得的收入。

---

## ⚙️ POV 背後的底層邏輯

### 三個輸入決定這個 POV

| 維度 | 內容 |
|------|------|
| 變現優先順序 | SaaS → 門市 → 諮詢 → 數位產品 |
| 產業不滿（立場來源）| 眼科醫師持續蠶食驗光師的專業領域與執業權益 |
| 讀者目標 | 建立正確視力衛教認知，對保護視力有基本認識 |

### 為什麼這個 POV 有力量

- **身分稀缺性**：元培企管碩士 ＋ 視光臨床 ＋ 同時經營眼鏡店和驗光所 ＋ 建 SaaS，這個組合在台灣視光圈幾乎是孤例
- **兩個戰場同時打**：對外（大眾衛教）建立信任，對內（同行工具）創造商業價值
- **有立場不是中立派**：對眼科蠶食驗光師有明確立場，這讓內容有稜角、有記憶點

---

## 🎯 為什麼重要

對大眾：大多數人不知道驗光師和眼科醫師的差異，容易被誤導或過度依賴醫療端。正確衛教能建立長期信任，也能讓門診客戶更有品質。

對同行：台灣驗光師長期在商業面處於弱勢，缺乏系統化工具。POV 連接到 SaaS 產品，形成「教育 → 信任 → 工具採用」的完整漏斗。

---

## 📊 內容策略三階段

```
短期（建信任）→ 中期（吸同行）→ 長期（SaaS 暖身）
    大眾衛教           產業立場           系統工具
```

### 10 個核心內容題目

**衛教方向（對大眾）**
1. 驗光師 vs 眼科醫師：你的眼睛問題到底該找誰？
2. 配眼鏡為什麼不能只靠電腦驗光？
3. 視力 1.0 不代表眼睛健康——這件事沒人跟你說
4. 小孩近視，家長最常做的 3 個錯誤決定

**產業立場（對同行＋有意識的大眾）**
5. 為什麼台灣驗光師一直在退讓？
6. 驗光師開店，為何用技術賣命卻賺不到應得的錢？
7. 用 MBA 邏輯重新設計視光門市之後，發生了什麼事

**系統＆工具（SaaS 暖身）**
8. 我怎麼同時跑眼鏡店＋驗光所還有時間做數位產品
9. 驗光師也可以建 SaaS：從門診痛點到解法的過程
10. 小型眼鏡行的經營盲點：你賣的是眼鏡，還是信任？

## ⚖️ 實戰應用

- **每篇文章發佈前**：檢查是否符合「大眾衛教」或「同行升級」兩個戰場之一
- **SaaS 行銷文案**：從「驗光師被低估」切入，讓同行感同身受後再介紹工具
- **社群貼文開頭**：直接挑戰常見誤解（如「眼科 = 比較專業」）

### 禁忌（違反 POV 的做法）
- 對眼科 vs 驗光師的爭議保持「兩邊都對」的中立態度
- 只寫技術硬知識，沒有連結到讀者的生活情境
- 賣弄學術名詞而不解釋實際意義
