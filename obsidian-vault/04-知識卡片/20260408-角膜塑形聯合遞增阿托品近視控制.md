## 核心發現

《Scientific Reports》2025 年發表研究，針對角膜塑形術（OK 鏡）聯合**遞增濃度阿托品**的療效進行評估：

- OK 鏡 + 0.01% 阿托品：年均眼軸增長減少 **28.4%**
- OK 鏡 + 0.025% 阿托品：年均眼軸增長減少 **31.4%**
- OK 鏡 + 0.05% 阿托品：年均眼軸增長減少 **39.4%**

關鍵前提：當 OK 鏡 + 0.01% 阿托品已無法有效控制近視進展時，依序升級阿托品濃度是有實證支持的「第二線策略」。整體安全性良好，無嚴重副作用。

另一 2025 年 JAMA Ophthalmology 隨機臨床試驗（PMC）顯示，0.04% 阿托品單獨使用在近視控制效果上優於 0.01% 阿托品或 OK 鏡單獨使用，但畏光副作用較高。

## 臨床意義

1. **個人化階梯療法有了實證基礎**：過去遇到 OK 鏡 + 0.01% 阿托品效果不足時，臨床缺乏升級指引；本研究填補了這個空白。
2. **濃度與效果呈正相關**：阿托品從 0.01% → 0.025% → 0.05% 的遞增，效果確實逐步提升，且耐受性尚可。
3. **組合優於單一療法**：多項 RCT 已確認，OK 鏡 + 阿托品的組合眼軸增長（0.17 mm）顯著低於 OK 鏡單用（0.34 mm）。

## 目鏡大叔的觀點（AI草稿）

這篇研究讓我想到臨床上常遇到的情境：家長帶著孩子回診，說「戴了 OK 鏡度數還是繼續深」，我們的下一步是什麼？過去答案有點模糊，現在有了比較明確的路線圖：先加 0.01% 阿托品，不夠就往上調，而且有數據支撐這樣做有效且安全。

不過要注意的是，0.05% 阿托品的畏光問題對台灣戶外強光的孩子來說仍是實際考量，需要告知家長做心理準備。

這也再次提醒：近視控制是「動態管理」，不是「配完鏡片就好」，定期追蹤眼軸長度才是核心。
