# 顧客旅程 × 內容策略框架

> **核心洞察**：文章不只是「主題」的集合，每篇文章應對應顧客從陌生人到熟顧客的特定旅程位置。不同階段的文章，功能、CTA、SEO 策略都不同。

---

## 五階段旅程模型

### Stage 1｜問題覺察（陌生人）

| 項目 | 內容 |
|------|------|
| **顧客狀態** | 覺得眼睛有問題，但還沒想到要配鏡 |
| **搜尋心態** | 「為什麼眼睛會…」「孩子近視怎麼辦」 |
| **文章功能** | 引流入站、問題意識啟蒙 |
| **SEO 策略** | 症狀關鍵字、衛教科普、長尾搜尋 |
| **CTA 方向** | 軟性：「了解更多」「這篇也值得看」 |
| **典型格式** | 科普文、迷思破解、症狀分析 |

**已有代表作**：孩子視力求救訊號 / 糖化反應 / 腸眼軸 / 近視惡化真相 / 散光夜間駕駛

---

### Stage 2｜評估比較（潛在客）⚠️ 最大缺口

| 項目 | 內容 |
|------|------|
| **顧客狀態** | 決定要來配鏡了，在評估「要去哪裡、要怎麼選」 |
| **搜尋心態** | 「驗光所 眼鏡行 差別」「鏡片品牌比較」「配鏡流程」 |
| **文章功能** | 降低決策焦慮、建立專業信任、讓人敢預約 |
| **SEO 策略** | 比較型關鍵字、選購指南、FAQ Schema |
| **CTA 方向** | 明確：「預約視覺健檢」「來店了解」 |
| **典型格式** | 比較文、指南、流程圖解、FAQ |

**缺口清單（全部待寫）**：
- [ ] 配鏡流程圖解（P0）
- [ ] 驗光所 vs 眼鏡行（P0，現有版本太淺）
- [ ] 第一次配眼鏡 FAQ（P0）
- [ ] 鏡框選擇完全指南（P1）
- [ ] 鏡片品牌比較（P1）
- [ ] 眼鏡價格大解密（P1）

---

### Stage 3｜進店意圖（準顧客）

| 項目 | 內容 |
|------|------|
| **顧客狀態** | 考慮去「自己的眼鏡」，需要最後一推 |
| **搜尋心態** | 「三峽驗光推薦」「目鏡大叔」「自己的眼鏡評價」 |
| **文章功能** | 社交證明、品牌溫度、消除疑慮 |
| **SEO 策略** | 在地關鍵字（三峽/鶯歌/土城）、品牌名稱、顧客故事 |
| **CTA 方向** | 強硬：「現在預約」「LINE 聯繫大叔」 |
| **典型格式** | 顧客故事、門市介紹、推薦文 |

**已有代表作**：17 年老眼鏡 / 鶯歌上班族 / 三峽配鏡故事系列 / 邀請函

---

### Stage 4｜新顧客留存（回流培養）⚠️ 空白

| 項目 | 內容 |
|------|------|
| **顧客狀態** | 已配鏡，使用中，需要被提醒回來 |
| **搜尋心態** | 「眼鏡多久換一次」「眼鏡保養方法」「度數穩定了嗎」 |
| **文章功能** | 維繫關係、延伸服務、創造回診理由 |
| **SEO 策略** | 使用情境關鍵字、售後知識 |
| **CTA 方向** | 召回：「帶眼鏡來健檢」「幫長輩預約」 |
| **典型格式** | 保養指南、檢查時機、升級建議 |

**缺口清單**：
- [ ] 眼鏡保養與維修指南（P2）
- [ ] 什麼時候該換眼鏡（P1，但功能更偏 Stage 4）
- [ ] 隱形眼鏡 vs 框架（P2）

---

### Stage 5｜口碑傳播（熟顧客）⚠️ 空白

| 項目 | 內容 |
|------|------|
| **顧客狀態** | 成為粉絲，想推薦給朋友但不知道怎麼說 |
| **搜尋心態** | 主動分享、轉傳、截圖 |
| **文章功能** | 提供「轉傳武器」，讓粉絲有理由分享 |
| **SEO 策略** | 次要，以社群傳播為主 |
| **CTA 方向** | 分享：「把這篇傳給家人」「帶朋友來一起檢查」 |
| **典型格式** | 容易截圖的清單文、情感故事、驚喜知識 |

**規劃方向**：
- [ ] 「你身邊有這種眼鏡使用習慣的人嗎？」（轉傳型）
- [ ] 帶長輩來檢查的 SOP（實用工具型）

---

## 文章屬性標籤規範

在每篇文章的 YAML frontmatter 加入 `journey_stage` 欄位：

```yaml
journey_stage: S1  # S1 覺察 / S2 評估 / S3 意圖 / S4 留存 / S5 傳播
```

---

## 選題優先級決策樹

```
新主題出現時 → 問：顧客在哪個 Stage？
         ↓
    S2 評估期？ → 優先寫，因為這是最大缺口
         ↓
    S1 覺察期？ → 確認有沒有類似文章，避免重複
         ↓
    S3 意圖期？ → 確認本月是否已有顧客故事
         ↓
    S4/S5？    → 季度性補充，不急於發布
```

## 現有文章庫 Stage 分布（2026-04 快照）

| Stage | 篇數 | 評估 |
|-------|------|------|
| S1 覺察 | ~35 篇 | ✅ 充足，暫不需加碼 |
| S2 評估 | ~2 篇（偏淺） | 🔴 **嚴重不足，最高優先** |
| S3 意圖 | ~25 篇 | ✅ 充足 |
| S4 留存 | ~3 篇 | 🟠 不足，次優先 |
| S5 傳播 | 0 篇 | 🟡 待規劃 |

> **結論**：67 篇文章中，扮演「決策橋梁」的 S2 文章幾乎空白。陌生人看了衛教文有興趣，卻沒有文章把他們推進門。
