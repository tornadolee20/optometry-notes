# 雙眼視病例判讀報告模板

建立日期：2026-04-13  
用途：把雙眼視 skill 轉成可重複使用的病例分析模板。

## 輸入欄位

### 基本資料

- 年齡
- 主訴
- 症狀多久
- 最明顯的觸發任務
- 是否有紅旗

### 屈光與視力

- 目前配鏡
- 視力
- refraction relevant findings

### 眼位

- distance cover test
- near cover test
- distance phoria / tropia
- near phoria / tropia
- incomitance if any

### 融像

- distance PFV / NFV
- near PFV / NFV
- vergence facility
- NPC

### 調節

- accommodative amplitude
- MAF
- BAF
- accommodative response
- NRA / PRA

### 感覺功能

- stereopsis
- suppression / Worth 4 Dot / Bagolini

### 特殊背景

- concussion / TBI
- pediatric learning concerns
- strabismus history
- amblyopia history

## 輸出模板

### 1. Case Summary

用 3-6 句話整理主訴與最關鍵數據。

### 2. Primary Pattern

最可能的 pattern 是什麼。

### 3. Why This Fits

列出支持這個 pattern 的檢查發現。

### 4. Differential Considerations

還需要留意的 1-3 個替代可能。

### 5. Missing Data That Matter

哪些缺失資料會明顯影響判讀。

### 6. Red Flags

有沒有需要升級分流的地方。

### 7. Confidence Level

- High confidence
- Moderate confidence
- Preliminary

### 8. Clinical Next Step

下一步最值得做的 1-3 件事。

### 9. Prism Conversation Status

- prism not indicated from current evidence
- prism may be considered but only after confirmation
- prism conversation is reasonable now

### 10. Patient Explanation

把上面的專業判讀翻成病人聽得懂的話。

## 快速版

如果只想快速判讀，可壓成四行：

1. likely pattern
2. why it fits
3. what is missing
4. next step

## 可直接貼給 AI 的指令

```text

案例資料：
[貼上資料]
```
