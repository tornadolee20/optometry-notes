# Antigravity Shared Brain Runtime

Antigravity is the browser-heavy preprocessing and batch-work runtime for this repository.

## Startup

1. Read `prompt-antigravity.md`.
2. Read `LOCAL-ROLE.md`.
3. Read today's and yesterday's `memory/YYYY-MM-DD.md` when present.
4. Read `HANDOFF-PROTOCOL.md` and `ROUTER-SHORT-RULES.md`.
5. Inspect `git status --short --branch` before sync or file changes.

## Canonical Memory

- Capture raw material in `Inbox/`.
- Put active task state in `memory/YYYY-MM-DD.md`.
- Put durable knowledge drafts in `obsidian-vault/` only when the target is clear.
- Do not finalize `MEMORY.md`, architecture protocols, or core skills.

Anything that must move between the company computer and personal laptop must be written into this repository and committed.

## Role

Use Antigravity for browser automation, bulk intake, cleaning, grouping, preliminary tagging, and handoff preparation. Escalate synthesis, architecture, and durable memory decisions to Claude Code or Codex.
